四大底层机制（图中的隐含协议）

① 状态机 · 四道闸门（4-Gate Pipeline）

  • G1 三图试金石 → G2 资产扩展 → G3 样板首帧 → G4 全集放行：任一闸失败回上一闸修正重测，严禁跳闸批量
  • 三级用户裁决位：0.0 项目立项（NARR-00 两层参数收口＋方案骨架轮＋一页式立项书拍板·R9-20261007-17）→ 0.5 剧本大纲（一页式放行）→ 0.6 分镜图生产单（R10 开工令）
  • 细则 0 剧本闸（N 三查：转场动机链/钩子回收/登场必要性）——0.0 管"宪法级"、0.5 管"法律级"，粒度分明
  • 每条 Prompt 独立过门禁，不搞整集平均分——一镜不合格即该镜打回
  • 阶段切换主动释放上一阶段挂载（上下文预算：≤1 平台插件＋2 KB＋3 技法）

② 双擎门禁（L1 ＋ L2 双签定稿制）

  • L1 机检：python scripts/qc_linter.py——禁词/变量外壳/句首媒介/画幅/details 零空行/时间轴/注册表对账，0 错误才进 L2
  • L2 智检：R7 按 KB_10 G/V 双扣分表＋KB_09 崩坏题库语义核验 ≥9.0
  • 评分行统一双签：「L1机检: PASS ｜ L2智检得分: 9.X / 10（通过）」
  • ＜9.0 强制打回并下发修改指令，最多 3 轮 → 升级人工裁决（记录在案）

③ 冷热记忆隔离（Token 防滚雪球）

  • 阶段Ⅲ 只读热记忆：资产注册表（外貌锁定摘要/音色ID）＋跨集状态快照
  • 严禁全文读取冷归档：示范剧集模板 / 往集产出 / workspace/＜剧名＞/_archive/
  • memory/projects/＜剧名＞/ 目录纯洁性：永久只允许三件套
  • 单集超 8 分镜按每批 4~6 镜分段产出，逐批过门禁

④ 自进化双环（EVO-01 · 单点即时＋全局连坐）

  • Micro 环：用户每生成一张/段即填「Prompt 实际产出复盘」（不等整批）
  • Macro 环：批末汇总归档；下一轮对话总控扫描非空复盘字段自动激活 R9
  • R9 四步：归因 → 三层根因（L1/L2/L3）→ 全局防偏三问沙盘 → 连坐刷新黑名单/KB_09/KB_10/plat_*/PACK
  • 高频崩坏（同类 ≥3 次）→ 自动升级为 KB_10 一票否决题
