06 / QUICKSTART

    
团队新成员 5 步快速上手 SOP

    
从零到产出第一条过审提示词的完整路径——按顺序执行，任何一步不达标都会被门禁拦下，这正是框架"工业级"的含义。

    

      
读总控 · 建记忆
通读 AGENTS.md 路由协议与 skills/SKILL_INDEX.md 索引；新剧先在 memory/projects/[剧名]/ 建三件套：剧集圣经（含 @画风锁）、资产注册表、跨集状态快照。

      
剧本 → 分镜
编剧产出钩子与情绪曲线（前 3 秒定生死）；导演拆分镜并标注 S/A/B 算力分级，台词镜头先做声画先行秒数精算；场记写轴线声明与空间分区。

      
资产先行 · 零光影
美术出人物/场景/道具设定卡；生图专家按 KB_06 铁律产出三视图 + 表情矩阵 + 面部特写/全身立绘衍生图（防三人同框）；登记 @纯中文 资产名与音色卡。

      
编译提示词 · 过门禁
生图走八层全量公式；视频走 20% 锚点 + 80% 动态 差分公式 + 秒级节点 + 口型排他锁 + 模式 A/B 声明；每条 Prompt 送评分官，<9.0 打回 改到过审为止。

      
实测 → 复盘 → 进化
到豆包/即梦/可灵等平台跑图跑片；把翻车现象填进 Prompt 实际产出复盘；复盘引擎自动归因 17 崩坏库并修订词典与插件——框架越用越强。
