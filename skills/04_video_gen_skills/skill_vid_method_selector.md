# 视频技法选择器（VID-02）

## 技法速查表

| 技法 | 原理 | 最佳平台 | 适用镜头 | 风险点 |
|---|---|---|---|---|
| 首帧图生视频（I2V） | 首帧锚定 90% 外观 | 全平台通用 | A 级常规 | 首帧逆光过曝（崩坏10） |
| 首尾帧控制 | 双图锚定起止 | 可灵（强项） | S 级奇观/大幅动作 | 运镜幅度须匹配差异 |
| 分镜图转视频 | 多宫格逐格驱动 | ComfyUI Wan | 同场次连拍 | 格间一致性依赖垫图 |
| 多图参考融合 | 人物图+场景图+道具图同挂 | 即梦 Seedance（最多50素材） | 多资产复合镜头 | 参考图权重失衡串色 |
| 尾帧截取接力 | 上镜尾帧→修复→下镜首帧 | 全平台 | 突破5秒长镜头 | 累积漂移（每接力1次风险+） |

## 选择决策树

1. 镜头等级 S → 大幅动作/奇观？→ 可灵首尾帧；多资产复合 → 即梦多图参考。
2. 等级 A → 标准 I2V（首帧基准图 + 差分 Prompt）。
3. 等级 B → 不生成视频：超高清静态图 + 后期 Lip-Sync + 剪映关键帧缓推与粒子特效。
4. 需要 >5 秒连续长镜 → 尾帧接力：`截尾帧 → 高清修复/局部重绘微调 → 作下一镜首帧 → Prompt 只写增量变化（锚点可压至1词）`；接力 ≤2 次防累积漂移，第 3 段起重锚全量首帧。
5. 对白镜头 → 模式A选即梦/MiniMax H3（原生音画）；模式B选 ComfyUI Wan2.1 + LatentSync/剪映对口型。

## 长镜头接力示例

```text
镜A（5s）：[推近] … → 导出尾帧F1
F1 处理：高清修复 + Inpainting 微调（衣摆角度/光斑位置）→ 首帧F1'
镜B（5s）：首帧=F1'，Prompt：@林烬（锚点1词）+ [02-05s]新增动作增量
```

## 输出格式

```
【视频生成技巧】技法：…｜平台推荐：…｜模型：…｜原因：…
【接力链】（如适用）镜A尾帧 → 修复 → 镜B首帧
【Prompt】```prompt … ````（VID-01 编译，R7 评分 ≥9.0）
```

## 正反例

✅ 正确：8 秒打斗 = 镜A（可灵首尾帧 5s）+ 尾帧接力镜B（3s，锚点压至1词只写增量）。
❌ 错误：单条 Prompt 要求 8 秒连续打斗且中途转场——超时长+隐含切镜（V3）+动作漂移三重崩坏。
