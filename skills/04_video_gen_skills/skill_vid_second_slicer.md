# 视频秒级切片器（VID-01 · 视频提示词核心）

## 执行步骤

1. **取输入**：分镜表行（镜号/景别机位构图/运镜/时长/等级/@资产/台词精算结果/口型模式）。
2. **差分编译**（KB_08 二节公式）：
   - 锚点层 ≤20%：`@资产名`+最多 2 个骨相词
   - 动态层 ≥80%：1 个镜头运动（KB_11 词典+幅度）+ 1 主动作 + 1 次级微动作 + 材质动态（衣摆/发丝/热气/光斑）
3. **秒级节点**：`[00-02s]…；[02-05s]…`，节点 ≤3、间隔 ≥1 秒、一镜一主动作。
4. **口型处理**：
   - 模式A（原生音画同出）：写台词文本+语气+说话者张嘴动作+**倾听者闭嘴锁**
   - 模式B（后期对口型）：写"嘴唇保持自然闭合或极轻微闭合微动（预留后期Lip-Sync口型合成干净基底）"
5. **多人镜头**：空间分区句式（KB_07 二节）必挂。
6. **末尾挂载**：@画风锁（逐字）。
7. 代码块封装 → 送 R7 评分（V 表）→ ≥9.0 入档。

## 编译模板

```prompt
[锚点层：黑衣长发@林烬（2词封顶）]立于@玄天宗比武台中央，[00-02s]镜头低角度缓慢推近（运镜1种+幅度），衣摆与额前碎发被罡风掀起轻扬（材质动态）；[02-05s]他缓缓抬眼扫视四周（主动作），指节在剑柄上收紧一下（次级微动作），雷云天光在剑刃上流动一道银白反光（光影变化可选），周围人群保持静立，@画风锁
```

## 台词镜头模板（模式A · 例子1镜头1）

```prompt
米白针织衫母亲@李梅与天蓝卫衣孩童@张三行于@光大街边：画面左侧三分之一为成年女性@李梅（身高约一米六五），右侧三分之二为孩童@张三（身高约一米一），两人牵手间距一臂；[00-00.8s]镜头远景缓慢推近，@张三仰头拽动母亲衣角，梧桐树影与美食摊白雾轻晃；[00.8-3.0s]@张三抬头张嘴说话，嘴唇随台词自然开合："妈妈，我要吃莽莽"（奶声奶气、尾音拖长）；一旁的@李梅保持双唇闭合、嘴角含笑低头倾听，@画风锁
```

## 正反例

✅ 正确：上例——锚点 2 词、动态占八成、分区+口型排他锁齐备、单主动作、秒级节点 2 段。
❌ 错误：`@李梅（鹅蛋脸柳叶眉杏眼栗色齐肩微卷发米白针织开衫浅杏连衣裙…50字外貌）牵着@张三走在街上聊天，先全景再特写`——堆砌外貌（V2）+隐含切机位（V3）+口型无锁（V5），三重否决打回。
