# 美术风格与穿搭道具技能（VIS-02）

## 执行步骤

1. **定画风**：KB_05 流派表选型 → 按 `@画风锁` 结构公式（流派质感+细节颗粒度+光影氛围+影调色温+画质词缀）拼装定稿 → 登记资产注册表常量区。
2. **色彩脚本**：每场景出 60-30-10 配比（主 60%基调/辅 30%层次/点缀 10%钩子），编译成可挂进 Prompt 的中文句式（KB_04 六节）。
3. **人物穿搭**：KB_03 题材表选套装编号 → 四件套补齐（版型+面料+配色+工艺）→ 配饰 ≤3 件 → 写入人物视觉卡。
4. **场景设定**：空间布局（前景/中景/远景三段）、光源方向与色温、关键陈设 3 件记忆物 → 场景卡。
5. **道具设计**：KB_06 七节结构分解词 + KB_04 材质索引 + 记忆点 → 道具卡。
6. **音色视觉转听觉**：为每位人物出音色设定基线（音色特征/语速档/情感倾向），交 AUD-01 落地克隆卡。
7. 全部结构化移交 R5（生图策划）与 R6（视频编译）。

## 输出格式

```
【@画风锁】…
【色彩脚本】场景：…｜60%…｜30%…｜10%…
【人物视觉卡】@名｜套装编号…｜四件套：…｜配饰：…
【场景卡】@场景｜空间三段：前景…中景…远景…｜光源：…｜陈设记忆物：…
【道具卡】@道具｜结构：…｜材质：…｜记忆点：…
【音色基线】@人物｜特征…｜语速档…｜情感倾向…
```

## 正反例

✅ 正确：`@光大街边｜前景馄饨摊白雾虚化｜中景人行道与梧桐树影｜远景居民楼暖黄窗灯｜光源：西斜黄昏金橙 60%｜陈设记忆物：白雾热气、灯串、梧桐`。
❌ 错误：`街道很有烟火气，氛围温暖`——无数值配比、无空间三段、无光源方向，无法编译进 Prompt，连续性无从核查。
