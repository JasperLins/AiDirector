# 导演分镜拆解技能（VIS-01）

## 执行步骤

1. **定画幅**：单集顶部声明 `画幅制式：16:9 横屏 / 9:16 竖屏`；竖屏即启用 KB_07 第四节三类构图（纵深叠压/高低对角/紧凑过肩），禁用横向铺开（防崩补丁2）。
2. **拆场次**：按场景+时空单元切场次，每场先写`轴线声明`（KB_07 七节）。
3. **拆镜头**：一镜一主动作；台词镜头先过 NARR-03 精算时长再定镜长。
4. **标等级**（S/A/B 算力路由）：
   - **S 级**：黄金前3秒/核心奇观/高潮爆发 → 首尾帧精控+顶级模型（可灵/即梦精调）
   - **A级**：常规动作交互 → 标准首帧图+图生视频
   - **B 级**：纯对白反应/空镜/停顿 → 超高清静态图+对口型 Lip-Sync+剪映关键帧缓推与粒子特效（零崩坏降本）
5. **排缓冲镜（Cutaway）**：每 2~3 个主镜头插 1 个 1~2 秒特写插入镜/反应镜（手部握拳、道具特写、倾听者眼神、街边热气），并标注供 R8 做 J/L-Cut 遮瑕。
6. **填分镜总表**（KB_11 八节格式），核对 180 度轴线与景别递进。

## 分镜总表字段

`镜号｜场次｜景别｜机位｜构图｜运镜(1种+幅度)｜时长秒｜等级S/A/B｜@资产清单｜台词(口型模式)｜秒级节点摘要｜Cutaway标记`

## 正反例

✅ 正确（例子1拆解）：
- 镜头1（3s，A）：远景缓推，@李梅左@张三右走于@光大街边，张三台词模式A（李梅闭嘴锁）
- 镜头2（1.5s，B-Cutaway）：美食摊白雾特写（供 L-Cut 遮瑕）
- 镜头3（4s，A）：过肩近景，@李梅抚头说台词（张三闭嘴锁）

❌ 错误："一个 10 秒镜头里母子边走边说两句话再摸头"——多主动作+多台词+隐含切镜，触发 V3/V5 否决。

## 交棒

分镜总表 + 轴线声明 → R4 场记核查 → R5/R6 提示词生产；S 级镜头同步知会 R8 预留卡点位。
