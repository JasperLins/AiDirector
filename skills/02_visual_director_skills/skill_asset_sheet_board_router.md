# 资产设定板式路由器技能（VIS-05 · R9-20261006-7 立 · R9-20261006-9 订：按需触发+备用抽卡）· 工业级完整版

## 一、核心职责与工业级法则（6 条硬核铁律）

1. **按需触发铁律（R9-20261006-9 订 · 废除 S/A 级人物等级触发）**：**传统单视图五件套（母版①~⑦）为默认主流产出体系，本技能永不自动替代**——仅当 VIS-03（Step 2 查表定图集）识别**复杂度命中**时才主动调用（同 IMG-02 4.3 多宫格分镜垫图的适用判定范式，按需使用）：①人物资产且**头部记忆点 ≥3 项并发**（发饰+瞳色+疤痕/泪痣/骨相标志等同时存在）**或服饰层次 ≥3 层且部件记忆点密集**；②**非人形资产**（怪兽/灵宠/机甲/法器）；③**大型道具**或表情精度需求（wink/口型格）。复杂度未命中 → 传统五件套直行，本技能不介入。
2. **多格板参考位禁入铁律（红线）**：头身分区板/分区轮转板均为**多格板**，与三视图/表情矩阵同源红线（VIS-03 铁律 5）——**只用于锁定设定（存档/LoRA 训练/Inpainting 参考），严禁直接喂视频模型或作单镜首帧**（多格=多头怪高危，崩坏 05/06）。视频参考仍走 VIS-03 ④⑤单人参考图。
3. **母版唯一权威源铁律（去重）**：板式 A/B 的编译母版⑨⑩本体只存在于 `KB_06` 第四节；本技能只存指针、格位分配表与适用判定——严禁在任何 Skill 内抄写母版（防两处版本漂移，VIS-03 4.2 同款铁律）。
4. **格间一致性铁律**：头身分区板＝**上排同一颗头**（三头像骨相同源）+**下排同一套服饰**（人台三视角部件一致）；轮转板＝**六格同一生物同一比例**。编译时一致性约束句逐字必写（母版内已内置），验收时逐格比对——任一格跨格矛盾＝该格废弃局部重绘（同 KB_10 宫格核查族处置）。
5. **平台版式锁铁律**：多格板平台首选**豆包 Seedream**（组图写法有表情矩阵实测——plat_01 四节组图规格行与"组图九宫格表情矩阵"实测条；**组图主路径＝单画布多角度宫格**——豆包 App 实测支持（2026-10-06 用户验证·场景机位库 3x3 九格无崩坏），"生成N张图"多图输出仅作单机位补产备选，plat_01 六节 9·R9-20261006-11）；**ChatGPT 平台强制版式锁**（单幅约束+显式格数声明）——黑名单前科"ChatGPT 擅自三视图拼图"（2026-10-05 归档），无版式锁的多格请求会被擅自拼改。
6. **Gate 1 实测转正铁律**：头身分区板（无头人台写法）与分区轮转板均为**零实测新板式**——新剧绑定 PACK 后按场景机位库先例（R9-20261006-6）在 Gate 1 阶段**各先试一张**，实测格间漂移率与版式遵从度后填复盘占位转正；实测前一切触发结论均为建议级非强制（含备用抽卡模式的"优于正视图"假设）。

## 二、标准执行 SOP（Step-by-Step）

**Step 1 · 路由判定（R9-20261006-9 订）**：按 4.4 决策树表输入「资产类型×细节焦点×复杂度」→ 得路由结论（板式 A / 板式 B / 板式 C 增强 / 备用抽卡模式 / 维持传统五件套——后者为默认，未命中不介入）。

**Step 2 · 板式分流**：板式 A（人物头身分区板）→ 4.1；板式 B（非人形/大型道具轮转板）→ 4.2；板式 C（表情矩阵增强格位）→ 4.3；无命中 → 退回 VIS-03 传统五件套流程。

**Step 3 · 格位分配表**：按对应板式专节模板列"格位分配表"（每格视角/内容/词源节次），标注裁切用途（上排头像格→微表情参考位候选/下排服饰格→Inpainting 锁服参考——**均须裁切+回填 IMG-01 补高清重绘 0.3 后方可入参考位**，整板禁入见铁律2）。

**Step 4 · 指针取母版编译**：到 `KB_06` 第四节复制母版⑨/⑩逐字填空——头部区槽位取 `KB_02` 二节（骨相）/四节（眼部）/六节（发型发饰）注册表锁定摘要原词；服饰区槽位取 `KB_03` 二节（部件剪裁）+套装四件套；严禁现场自造同义词（VIS-03 4.3 填空校验同款）。`KB_02/KB_03` 仅按槽位取词时翻对应节，不常驻全册（防与 VIS-03 并发挂载时突破"≤2 KB"上下文预算）。

**Step 5 · 送检**：全部 Prompt 送 R7 评分（G 表 + KB_10 宫格资产附加核查族）；≥9.0 写入《重要资产图片提示词.md》，生图策略行注明"多格板·设定锁定件·禁入参考位"。

## 四、专项工具箱

### 4.1 板式A 人物头身分区设定板（指针：KB_06 母版⑨ · R9-20261006-7）

**解决的问题**：传统母版②正侧背全身三视图把头部等比缩小至约 1/8 画幅——发丝/瞳色/发饰/疤痕级记忆点细节全灭；本板式把头部拆出单独占上排三格满分辨率，下排以无头人台（Fashion Mannequin）承载服饰三视角。

**适用判定（R9-20261006-9 订 · 复杂度触发，废除人物等级触发）**：人物资产 + **头部记忆点 ≥3 项并发**（如：特殊瞳色+标志性发饰+疤痕/泪痣同时存在）**或服饰层次 ≥3 层且部件记忆点密集**。传统母版②正侧背三视图为**默认主流**（所有人物必产）；板式 A 仅复杂度命中或用户点名时按需产出（可与母版②并行生成择优，见 4.5 备用抽卡模式）；按铁律 6 实测转正前均为建议级。

**格位分配表**：

| 区位 | 格位 | 内容 | 词源 |
|---|---|---|---|
| 上排（头部三角度高精度特写） | 左 | 左侧正侧面头像 | KB_02 二节骨相+六节发型发饰 |
| 上排 | 中 | 正面头像 | KB_02 四节眼部（瞳色记忆点必写） |
| 上排 | 右 | 右侧正侧面头像 | 同左格（镜像侧发饰走向） |
| 下排（无头人台服饰三视角） | 正/侧/背 | 等距水平排列无头人台 | KB_03 二节部件剪裁+四件套 |

**裁切用途**：上排任一头像格 → 表情矩阵母版③的"同一张脸"验收基准候选 + Inpainting 锁脸参考；下排背格 → 背饰/包带走向唯一高清源。裁切子图不另立资产名，且**须回填 IMG-01 补高清重绘 0.3 后方可使用**（4K 六格裁后单格仅约 1/6 画幅，直用分辨率不足——对齐母版⑧④ 补高清铁律）；垫图指引按"@资产名 分区板上排中格"式自然语言引用。

### 4.4 板式路由决策树

| 资产类型 | 细节焦点/复杂度 | 路由结论 |
|---|---|---|
| 人物 | 头部记忆点≥3项并发 或 服饰层次≥3层（复杂度高） | 板式 A 可选（⑨，按需产出） |
| 人物 | 常规（复杂度未命中） | 维持传统五件套（母版②默认主流，本技能不介入） |
| 人物 | 表情精度需求（wink/口型戏） | 板式 C 增强（母版③格位扩展） |
| 非人形（怪兽/灵宠/机甲/法器） | 形体结构+头部记忆点 | 板式 B（⑩）+形态矩阵 |
| 大型道具 | 头部结构/形态复杂 | 板式 B（⑩） |
| 常规道具 | 结构展示 | 维持道具两件套（母版⑦） |
| 兽人/精怪（人格化非人形） | 头部表情+形体双需求 | 板式 B + 上排头部格加人格化表情注记 |
| 任意资产 | 用户点名/择优需求（不看复杂度） | 备用抽卡模式（4.5） |

### 4.5 备用抽卡模式（R9-20261006-9 立 · 可选，非默认）

**定位**：不看复杂度的**可选项**——任何资产可在《重要资产图片提示词.md》中与正统单视图/三视图**并行**追加一条宫格板 Prompt（母版⑨/⑩/③任一），同批次跑图抽卡择优。

**原理（待实测假设）**：宫格一次生成＝格间同源互锚（同脸同服同画风同光位强制绑定），裁切上排中格（正面头像）可能比单独文生图的主图/三视图更稳——正视图抽卡 3 次不稳时，宫格备选池可能一击命中；此为实战假设，须填复盘占位实测验证后转正（铁律 6）。

**择优规则**：正视图（母版①/②）为**主选产出**，宫格裁切图为**备选池**——两案并跑对比，**裁切格须回填 IMG-01 补高清重绘 0.3 后**方可择优入注册表基准位（六格裁后单格分辨率不足以直入基准位）；未对比前默认正视图为主。**V2 参考图增强（R9-20261006-11）**：宫格 Prompt 垫本角色主图达标图作参考+首句改"参考图中的人物形象，…"（官方参考图生图两部式，plat_01 六节 8）——格间同脸率显著提升，主图已锁定时必用；主图未锁定时退纯文生图。

**成本提示**：每追加一条宫格 Prompt＝多一次生成成本，默认不追加；仅正视图连续抽卡 ≥3 次不稳、或用户点名时启用。

## 五、常见错误示范 vs 满分工业级示范

### 对比组：头部细节保留

❌ **Bad Case**：
> @沈小满 三视图：正面、左侧面、背面三视角等距水平排列，全身完整入画，脸部清晰。

**扣分点**："全身完整入画"= 头部被等比压缩至约 1/8 画幅，浅琥珀瞳色/马尾发绳等记忆点细节全灭；"脸部清晰"无机制支撑——这正是板式 A 立法要解决的问题本身。

✅ **Good Case**：
> 复杂度判定：头部记忆点 3 项并发（浅琥珀瞳+束高马尾黑发绳+右眼下泪痣）命中 → 板式 A 按需产出（传统②仍并行主选，可并跑择优 4.5）：上排三角度头像满分辨率特写（浅琥珀瞳色/柳叶眉/束高马尾黑色发绳逐字入格）+ 下排无头人台正侧背服饰三视角（素青交领襦裙四件套+部件剪裁词）；上排三头像骨相同源、下排同一套服饰、上排与下排为同一角色同一套服饰，格间留白；豆包组图写法+ChatGPT 版式锁。生成后上排中格作表情矩阵"同一张脸"验收基准。
> ——9.X 分放行（G 表+宫格附加核查族双检）。

## 六、边界情况处理（Edge Cases）

1. **兽人/精怪类人格化非人形**：走板式 B，上排头部三格追加人格化表情注记（眉骨情绪/瞳孔收缩）；表情控制需求强时另出形态矩阵加表情维度。
2. **竖屏（9:16）剧集**：分区板/轮转板总幅仍 1:1（多格板恒用方幅利于格间均质），裁切后单格按 16:9 安全区出（与 IMG-02 宫格裁切规范一致）；首帧直出需求走 VIS-03 ④⑤ 单人参考图，不从分区板裁切直出首帧。
3. **与场景机位库（R9-20261006-6）的边界**：机位库＝**场景**多机位垫图弹药库（空间轴·可垫图）；本技能板式＝**人物/非人形**设定锁定件（禁垫图）——服务对象、垫图准入相反，严禁混用。
4. **头部记忆点与服饰记忆点双弱资产**：无显著细节焦点 → 不触发本路由器，维持传统五件套（板式是细节焦点的放大器，不是所有资产的必需品）。
5. **分区板实测失败回退**：无头人台写法生成不稳（人台长出头/双排比例漂移）→ 回退方案＝母版②传统三视图 + 母版④独立面部特写补头部精度（等效细节覆盖，两张图成本略高）；回退结论填复盘占位触发 EVO-01。
