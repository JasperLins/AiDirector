# 连续性轴线守卫技能（VIS-04 · 防穿帮守门员）

## 执行步骤

1. **轴线核查**：每场次读取轴线声明（如"@李梅画面左行进向右—@张三画面右"），逐镜检查机位是否都在轴线同侧半圆；越轴镜头必须配中性镜/骑轴镜/动作剪辑点三选一补救。
2. **左右站位核查**：人物在画面的左右位置跨镜一致（对白正反打尤甚）；不一致=穿帮上报导演。
3. **持物手别核查**：道具左右手跨镜一致（@焚天断剑始终右手）；换手必须写显式过渡动作。
4. **服装战损核查**：对照最新跨集快照，战损只增不减，除非剧本写明更换/治疗。
5. **时空核查**：同场次时间天气光效连续（烟火线锁定黄昏金橙；苍穹线锁定雷云冷青）。
6. **快照生成**：每集定稿输出 `### 本集结束状态快照（State Diff）`：人物五项表（服装/伤势/情绪刻度/持物/位置）+ 场景表（时间/天气/陈设变化）+ 道具流向 + 叙事钩子遗留 + 音色状态 → 同步 memory/projects/[剧名]/跨集状态快照_StateDiff.md。
7. **开拍前继承核查**：下一集任何提示词引用前，五项全对齐最新快照才放行。

## State Diff 模板

```
### 本集结束状态快照（Episode State Snapshot）
| @人物 | 服装 | 伤势 | 情绪刻度 | 持有道具 | 位置 |
| @场景 | 时间 | 天气/光效 | 陈设变化 |
道具流向：…
叙事钩子遗留：…
音色状态：…
```

## 正反例

✅ 正确：镜头1母子"母左子右"行进向右，镜头3过肩维持"子右前母左后"不越轴，轴线声明写在分镜总说明。
❌ 错误：镜头1母左子右，镜头3突然变母右子左且无中性镜过渡——观众方向感崩塌，穿帮退回重拆。
