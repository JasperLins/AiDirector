# 纯中文零光影资产技能（VIS-03 · 核心）

## 执行步骤

1. **命名（纯中文铁律）**：`@2~6个汉字`，严禁英文/数字/下划线/符号；先查资产注册表查重 → 登记 → 才可引用。派生按 `@母资产+状态词`（如 `@林烬战损`）。
2. **确定图集五件套**（人物）：主图、正侧背正交三视图、表情矩阵（3x3）、独立面部特写、独立全身立绘。场景两件套：全景图+空镜基准图。道具两件套：三视图+特写基准图。
3. **编译零光影铁律**（KB_06 一节逐字挂载）：`360度环形无影棚拍柔光，均匀漫射平光，漫反射固有色贴图质感（Flat Lit Albedo），正交投影相机零透视畸变，中性18%灰背景，A-Pose双臂自然微张`。
4. **按 KB_08 生图全量编译公式**拼装（主体/服饰/动作/空间/环境→替换光学层/镜头→画风锁但光影词被 KB_06 覆盖/规格）。
5. **单镜参考防呆**：文档中必须注明"三视图仅用于锁定设定；喂视频模型前先裁切独立全身立绘或面部特写，防止三视图被识别为三人同框"。
6. 送 R7 评分（G4 零光影为否决级），≥9.0 方可写入产出文档。

## 三视图编译模板（人物）

```prompt
角色设定三视图（Turnaround Sheet）：@资产名，[骨相锁定摘要5~8词]，[套装四件套]，A-Pose双臂自然微张约30~45度，正面、左侧面、背面三视角等距水平排列，同一角色三个视角比例严格一致，360度环形无影棚拍柔光，均匀漫射平光，漫反射固有色贴图质感（Flat Lit Albedo），正交投影相机零透视畸变，中性18%灰背景，@画风锁（光影词替换为平光），16:9，4K
```

## 正反例

✅ 正确：`@李梅、@张三、@光大街边`——纯中文、可跨平台引用解析。
❌ 错误：`@LiMei_v2、@street-01、@张三3`——含英文数字符号，G1 否决级扣分，打回。
