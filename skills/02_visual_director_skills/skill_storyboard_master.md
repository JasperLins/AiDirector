# 分镜图总控技能（SBM-01 · R9-20261007-14 立）· 工业级完整版

## 一、核心职责与工业级法则（7 条硬核铁律）

1. **生产单前置铁律**：本技能产出的《分镜图生产单》是 R5 逐镜生图的**唯一合法开工令**——生产单未产出且未经 R7 核验前，R5 不得开始逐镜生图（防"逐镜独立抽卡"旧范式回潮；IMG-02 铁律6 的执法前置位，黑名单 38 立法背景）。
2. **镜组优先铁律**：镜组划分先于单镜评估——先按"同场次×构图变化×机位族"聚类分组，再对每组路由四模式；**默认倾向成组生产**（同源宫格/共享锚链的跨镜一致性远高于独立抽卡，且抽卡预算减半以上），单镜独立生产是例外且须说明理由。
3. **一致性链先行铁律**：每组必须先写"一致性链声明"（锚点传递路径：参考图分配→组内同源→跨组锚复用）再写 Prompt——没有一致性链的生产单=未完成（KB_14 二节六法选型）。
4. **「按叙事设计、按上限分段」铁律（长视频宪法）**：设计层时长完全服从叙事（10s/20s/30s 自由设计——未来模型适配长视频是趋势，框架定位长视频提示词生成）；生产层按平台**实测**上限自动切接力链分段：**分段公式＝镜时长÷平台上限，余数进位=段数；段间锚＝首尾帧（相邻段）+中帧锚（≥3 段链）**（KB_14 三节）。平台上限=生产参数，**不是设计约束**——禁止为迁就上限砍叙事时长；上限须实测校准一次（证据位阶铁律），校准后入注册表平台档案。
5. **四模式互斥铁律**：一个镜组只路由一个主模式（A/B/C/D），辅助技法（尾帧锚/机位库垫图）作为组内增强挂载——禁止双主模式混跑（宫格组内又塞接力链=管线打架）。
6. **证据位阶执法铁律**：本技能引用的一切平台能力（时长上限/参考图数量/宫格支持度）按 AGENTS 〇节9 位阶标注——用户实测＞本项目档案＞官方文档＞外部教程；KB_14 平台矩阵中未经本项目实测的条目只作参考值，生产单引用时标注"待实测"。
7. **三查执法铁律**：生产单落盘前自跑 IMG-02 铁律9 三查（①S 级双锚齐备②超上限镜有分段方案③运镜渐变已评估或显式标注"固定=叙事选择"）——任一不过自打回，R7 复核再验。

## 二、标准执行 SOP（Step-by-Step）

**Step 1 · 读入**：R2 分镜表全镜（镜号/场次/景别机位/等级/时长/@资产）+ 资产图集就位状态 + 目标平台实测上限（未实测则标注并预排校准镜）。

**Step 2 · 镜组划分**：按"同场次 × 构图变化小 × 同机位族/同景别族"聚类（跨场/景别跳级大的镜独立成组）；输出镜组清单（组号+镜号+共同特征）。

**Step 3 · 组模式路由**（决策树见 4.1）：
- 同场 ≥3 连续镜+构图变化小 → **A 多分镜宫格组**（2x2~5x4 规格，IMG-02 4.3 V2 极简模板）；
- S 级关键镜（黄金前3秒/奇观/高潮）→ **B 单帧+尾帧锚**（首尾双锚独立精出，IMG-02 4.1/4.2）；
- 单镜时长＞平台上限 → **C 接力链**（分段公式切 N 段，首尾帧+中帧锚，R6 拆解重组法联动）；
- 长镜内多机位渐变/多主体轨迹 → **D 多图参考组**（机位库子图作轨迹关键帧锚，R6 多图参考联动）。

**Step 4 · 一致性链设计**：逐组写参考图分配表（图1=人物主图@资产/图2=场景参考·机位库对应格或空镜基准/图3=前镜尾帧或共享锚图）+锚点传递路径声明（组内同源方式/跨组锚复用点）。

**Step 5 · 分段方案**：对超上限镜按分段公式出段数与段间锚清单（中帧锚按"首帧同源改三点"预列）。

**Step 6 · 三查自检**（铁律7）→ 产出《分镜图生产单》交 R7 核验 → ≥9.0 放行 → 下发 R5 执行指令（每组一条执行指令：模式+参考图位+宫格 Prompt 指针/单镜 Prompt 指针+抽卡预算）。

## 四、专项工具箱

### 4.1 镜组四模式路由决策树

| 条件 | 路由 | 规格与联动 |
|---|---|---|
| 同场 ≥3 连续镜 + 构图变化小 + 时长均 ≤上限 | **A 多分镜宫格组** | 2x2(≤4镜)/3x3(≤9镜)/5x4(≤20镜·KB_14 四节20镜实例)；IMG-02 4.3 V2 极简模板（开放列表/零量化锚/≤150字）；垫机位库格或空镜基准+人物主图多图融合；成图后看图回填格位表 |
| S 级关键镜（任何条件） | **B 单帧+尾帧锚** | 首帧+尾帧双锚独立精出（IMG-02 4.1/4.2 同源改三点）；宫格组内的 S 级镜=组内出首帧+独立补尾帧（A+B 复合，B 为主导） |
| 单镜时长＞平台上限 | **C 接力链** | 分段公式：时长÷上限余数进位=段数；≤2 段=纯尾帧接力；≥3 段=必须中帧锚（R6 一镜到底拆解重组法/VID-02 接力链）；段间锚图先行产出 |
| 长镜内运镜渐变跨机位 / 多主体轨迹控制 | **D 多图参考组** | 机位库子图作多图参考关键帧锚（起点格+终点格，长 trajectory 加中点格）；R6 首尾帧/多图参考技法；一镜到底长镜首选 |

### 4.2 一致性六法选型矩阵（KB_14 二节精编·证据位阶标注）

| 方法 | 适用 | 位阶/实测状态 |
|---|---|---|
| ①统一资产 DNA（人物主图/三视图/机位库先行锁定） | 一切生产的前提 | 本项目已实测✓（资产-01/04 基准锁定流程） |
| ②多分镜宫格一次生成 | 同场连续镜组 | 本项目实测中（E02 正门组登记待跑）；外部验证✓（20镜宫格实例·KB_14 四节） |
| ③首尾帧链（前镜尾帧=后镜首帧/描述前镜末状态） | 相邻镜衔接/接力段间锚 | 本项目部分实测（E01 02R 接力）；外部验证✓ |
| ④关键帧续写（分段视频提示词+关键帧） | 超上限长镜/整集串联 | 外部资料（即梦实测案例 12-15s 拼 50s）·未经本项目实测 |
| ⑤多素材参考（多图融合·参考图数量按平台） | 复杂多主体/多机位轨迹 | 本项目已实测✓（豆包多图融合人物+场景）；50张上限系即梦外部资料 |
| ⑥局部重绘/编辑修补（单镜穿帮就位修图） | 抽卡仍不达标的残镜 | 外部资料（即梦局部编辑）·未经本项目实测 |

### 4.3 分段公式与段间锚规范（KB_14 三节执法版）

`段数 = ⌈镜时长 ÷ 平台实测上限⌉`（余数进位）；段长按叙事节拍切分（不机械平分——切在动作节拍/台词句读处）；段间锚：2 段链=尾帧接力（A 段尾帧高清修复后作 B 段首帧底图）；≥3 段链=加中帧锚（动作中间态/机位中间位/光影中间档，"首帧同源改三点"产出）；**全链同光源同色温同画风**（改三点法保证）。上限校准：新平台首用先跑一个校准镜（建议取 S 级长镜）实测最大可出时长，校准值入注册表平台档案——此后按值分段，不再逐镜试探。

## 五、常见错误示范 vs 满分工业级示范

### 对比组：E02 正门系（黑名单 38 教材）

❌ **Bad Case**：拿到 18 镜分镜表 → 直接逐镜出首帧 Prompt → 逐镜独立抽卡垫同一张全景图 → 背景/机位/构图三失控（实测：背景锁死正门+机位错配+18 镜×3-5 抽卡预算爆炸）。
**扣分点**：无镜组划分（9 个可成组镜全部独立跑）、无一致性链（垫图一刀切）、S 级无双锚、逐镜抽卡成本最大化——正是 R10 立法前 的真实翻车现场。

✅ **Good Case**：R2 分镜表定稿 → R10 生产单：G1[镜01/01-A/01-B]=A 宫格组（垫机位库门钉格+小满主图，一次 3 帧同源）｜G2[镜02]=B 双锚（首帧+尾帧改三点）｜G3[镜05/06/07]=A 宫格组（正反打连续瞬间）｜镜04=单帧（构图跳变大独立）｜超上限镜分段方案齐备｜三查通过 → R5 按组执行 → 抽卡预算从 ~60 次压到 ~20 次。
> ——生产单 9.X 分放行（R7 核验+三查单双签）。

## 六、边界情况处理（Edge Cases）

1. **与 R2 的边界**：R2 产分镜表（拍什么），R10 产分镜图生产单（怎么出图保一致）——R10 不改分镜；发现分镜层一致性问题（如相邻镜机位跳变无叙事理由）退回 R2 附修改建议。
2. **与 IMG-02 的边界**：IMG-02=单镜前置资源策划技法库（模板/铁律的权威源），R10=总控调度层（镜组路由/一致性链/分段的总决策）——R10 引用 IMG-02 模板产出生产单，不复制母版（防版本漂移，同 VIS-03 4.2 去重铁律）。
3. **与 R6 的边界**：C/D 模式的段间锚设计与 R6 接力链/多图参考技法联动——R10 定"分几段+锚在哪"，R6 定"视频 Prompt 怎么写"。
4. **资产未就位**：机位库/人物主图缺项 → 生产单退回 Gate 2 补资产（不带着缺项跑宫格组——参考图缺位=一致性链断链）。
5. **平台上限漂移**（实测 10s 实际只能 8s）→ 重跑分段公式更新段数，校准值刷新注册表平台档案（单点校准全局生效）。
6. **竖屏（9:16）剧集**：宫格组改 1x4 竖排条或 2x2 留竖向安全区（IMG-02 六节3 同款）；分段公式不变。
