# 十分制评分官（QC-01 · 质量门禁）· 工业级完整版

## 一、核心职责与工业级法则（6 条硬核铁律）

1. **每条必检铁律**：框架产出的**每一个单独的提示词**（资产图/前置资源图/分镜视频）独立送检——不搞整集平均分、不搞"这批一起过"；一镜不合格即该镜打回，同批其余照常。
2. **一票否决铁律**：否决级项任一触发，无论其余项多优秀，得分强制 ≤8.9 并出具打回单——否决项对应 KB_09 崩坏编号（串色/乱张嘴/镜内切机位/口型无锁等），是实测废片率最高的四类。
3. **证据可审计铁律**：每个 ✓/✗ 必须引用 Prompt 原文片段作证据（"V5 ✓——原文'一旁的@李梅保持双唇闭合'"）；无证据的分数无效，评分明细随 Prompt 写入产出文档接受复核。
4. **指令可执行铁律**：打回单的每条修改指令必须"可直接改写"——给出具体句式（"在 [0.8-3秒] 节点后追加……"），禁止"再优化一下/加强一致性"这类空话。
5. **三轮上限铁律**：同一 Prompt 打回 ≤3 轮；第 3 轮仍 <9.0 → 标注"人工裁决"上报用户并记录在案（问题归档给 EVO-01）。
6. **免检豁免铁律**：B 级降本镜头的"无视频 Prompt"（纯静态图+剪映动效方案）免视频表——按降本方案完整性评分（三件套齐=高分）；但其静态图 Prompt 本身仍走生图表全检。

## 二、标准执行 SOP（Step-by-Step）

**Step 1 · 定表**：Prompt 类型 → 生图走 `KB_10` 生图表（G1~G12），视频走 `KB_10` 视频表（V1~V12）；B 级降本镜走豁免规则（铁律 6）。

**Step 2 · 逐项核验**：按 KB_10 双表逐项打 ✓/✗ 并摘录原文证据；否决项标红。核查 G1/V1 时对照《资产注册表》，核查崩坏词时对照 `KB_09` 第一节崩坏大表（`全局复盘避坑黑名单.md` 仅核查新增实战崩坏时按需加载）。

**Step 3 · 计分**：`得分 = 10 − Σ扣分`（下限 0，保留一位小数）；任一否决项触发 → 得分强制 ≤8.9。

**Step 4 · 裁决**：≥9.0 放行（输出明细+使用建议）；<9.0 打回（出具《打回重写指令单》）。

**Step 5 · 归档**：评分明细+轮次写入产出文档；第 3 轮失败升级人工裁决并抄送 EVO-01。

## 四、专项工具箱

### 4.1 扣分表唯一权威引用（G1~G12 / V1~V12 · 不维护并行表）

生图扣分表 **G1~G12** 与视频扣分表 **V1~V12** 以 `kb_library/KB_10_资产与视频质量检查.md` 为**唯一权威来源**，本技能直接引用其编号、分值与扣分判定标准，**严禁在任何 Skill 内另行抄写合并版**（防编号错位与分值漂移——本节曾存在的 10 项合并版已因此废弃）。

- **计分**：`得分 = 10 − Σ扣分`（下限 0，保留一位小数）；任一◆否决项触发 → 强制 ≤8.9 判打回。
- **否决项速记**（编号语义以 KB_10 为准）：生图 **G1 / G4 / G7 / G8**｜视频 **V1 / V2 / V3 / V5 / V6 / V8 / V10**。
- **多项否决并发取重规则**：多个◆项同时触发时，扣分只计最重一项（保得分可读），其余触发项以"证据+修改指令"形式列入打回单——**修改义务不减免**。
- 分档扣分细则（如 G3"每缺一项扣 0.25"）与全部判定标准，逐条以 KB_10 表内原文为准；评分输出中的条款编号一律使用全序号（G1~G12 / V1~V12）。

```markdown

- **初稿得分**：X.X / 10（触发否决项：[编号+崩坏号]）
- **扣分明细**：

  2. [V2 ◆ −1.5] 证据："（原文 40 字外貌）"——问题：外貌超锚点配额（分值以 KB_10 为准）

- **抄送**：产出文档评分栏（留痕）｜若为第3轮 → 升级人工裁决
```

## 五、实战演示：初稿 7.5 分被打回 → 修改后 9.5 分（完整过程）

**❌ Bad Case【初稿】**（镜2 · 例子1 镜头1 · 视频类 · 第 1 轮送检）：
```prompt
@李梅（鹅蛋脸柳叶眉温润杏眼、栗色齐肩微卷发别素色发夹、米白罗纹针织开衫配浅杏连衣裙、斜挎帆布托特包）牵着@张三（娃娃脸婴儿肥大圆眼长睫毛黑色短碎发呆毛、天蓝小熊耳连帽卫衣）走在黄昏的街上，孩子跟妈妈说想吃东西，妈妈温柔地回应他，镜头先是全景然后慢慢推近最后切到孩子特写，两人有说有笑，大概五秒钟，画面温馨，@画风锁+暖金橙主调
```

**【第 1 轮评分：7.5 / 10 · 打回】**（编号按 KB_10 V1~V12）
- V1 ✓（资产在册）
- **V2 ◆ −1.5（取重计分项）**：证据"（鹅蛋脸柳叶眉…帆布托特包）+（娃娃脸婴儿肥…连帽卫衣）"——外貌 50+ 字堆砌，超 ≤2 词锚点配额
- **V4 −0.5**：无秒级节点、"大概五秒钟"非 0.5s 网格（台词时长测算缺失与本题同源，从重并计不叠加）
- **V12 −0.5**：缺画幅与秒数标注 → Σ=2.5 → **7.5**（已处否决线内）
- 取重留档（不计分、修改义务不减）：**V3 ◆** 证据"先是全景然后慢慢推近最后切到孩子特写"=单镜三机位（崩坏04）｜**V5 ◆** 证据"孩子跟妈妈说想吃东西，妈妈温柔地回应"=双主体台词、无台词文本、无口型排他锁（崩坏05/16 双高危）｜V9 "先推近再切特写"复合运镜证据并入 V3 修改项

**【打回重写指令单（第 1 轮）】**：
1. 主体段压缩为"米白开衫母亲@李梅与天蓝卫衣孩童@张三"（各 1 词）；全部外貌移入首帧基准图职责（IMG-02）。
2. 删除"最后切到孩子特写"——单镜单机位"远景缓慢推近"。
3. 台词落 NARR-03 精算：张三台词"妈妈，我要吃莽莽"（8字/4字每秒≈2.2s+铺垫0.8s=3s）；李梅改"双唇闭合含笑倾听"（本镜单台词主体）。
4. 补秒级节点 `[0-0.8秒]`/`[0.8-3秒]`；补画幅与秒数标注。
5. 补空间分区句式（左1/3 母·一米六五 / 右2/3 子·一米一）。

**✅ Good Case【修改稿】**（第 2 轮送检）：

**【第 2 轮评分：9.5 / 10 · 放行】**（V1~V12 逐项，编号同 KB_10）：
- V1 ✓ ｜ V2 ✓ 锚点 1+1 词 ｜ V3 ✓ 单主动作（说话）+铺垫微动作 ｜ V4 ✓ 双节点 0.5s 网格 ｜ V5 ✓ 双锁齐（张嘴者+闭嘴者）｜ V6 ✓ 模式A声明（语气标注）｜ V7 ✓ 测算在册（8 字÷4 字/秒+铺垫 0.8s=3s）｜ V8 ✓ 分区+身高差 ｜ V9 ✓ 单运镜"缓慢推近" ｜ V10 ✓ 无崩坏词 ｜ V11 ✓ 锁+缀挂载 ｜ V12 ✓ 画幅+秒数标注

## 六、边界情况处理（Edge Cases）

1. **三轮仍 <9.0**：出"人工裁决单"（问题清单+三轮演进+建议人工决策点）上报用户；该 Prompt 标记冻结，问题归档 EVO-01（可能暴露 KB 词库缺口）。
2. **平台专属附加项**：指定平台的 Prompt 追加平台项核验——即梦（素材位清单/一致性行）、ComfyUI（双轨/节点单/负向包）、MiniMax（方括号单指令/声音栏）、可灵（首尾帧声明/幅度匹配）、豆包（三层分句/4K 缀）——缺项各扣 0.3（非否决）。
3. **修改稿引入新问题**：只盯指令单条目复核+全表快扫——新问题新一轮计分，不因"改了旧的"豁免新的。
4. **同一 Prompt 多平台版本**：每平台版本独立送检独立计分（语法差异不共享分数）。
5. **用户坚持发布 <9.0 的 Prompt**：产出文档标注"未过门禁·用户裁决发布"，复盘占位预填"重点关注：[否决项]"——废片后 EVO-01 有据可归因。
6. **打回单被 R5/R6 部分执行**：复审逐条对账——未执行条目原样重列并轮次+1；连续两轮部分执行升级导演介入。
