# 维度核查官（QC-01 · 质量门禁）· 维度制完整版

> **2026-10-25 用户裁决立法**：废 10 分自评与逐条复盘占位（自评分数无外部效度）——本技能由"十分制评分官"重写为"维度核查官"，唯一权威表＝`KB_10` V3（视频 8 维核查表/生图八层核查表）。文件名沿用 `skill_qc_prompt_scorer_10pt.md` 防引用断链，名称不再代表十分制。

## 一、核心职责与工业级法则（7 条硬核铁律）

1. **每条必检铁律**：框架产出的**每一个单独的提示词**（资产图/前置资源图/分镜视频）独立送检——不搞整集平均、不搞"这批一起过"；一镜缺维即该镜打回，同批其余照常。
2. **双擎联审铁律（L1 先行）**：核查启动前**必须先运行 `python scripts/qc_linter.py`**——L1 机检报错未清零时，本技能（L2）**强制打回**，严禁越权放行；L1 `PASS` 后，本技能 100% 聚焦维度取证（人设三要素与关系色／单镜动作机位纯度与蒙太奇B计划挂载／空间象限口型排他锁／20/80 差分纯度／光位轴线跨镜连续性——KB_10 〇节）；核查行统一双签 `L1机检: PASS ｜ L2维度核查: 8/8 通过（视频）／ 8层齐（生图）`。
3. **缺一即不通过铁律**：视频任一维缺失／生图任一层缺失，无论其余维度多优秀，即刻打回——高频崩坏位（串脸/乱张嘴/镜内切机位/口型无锁）对应 ③⑧⑦ 维，是实测废片率最高区位。
4. **证据可审计铁律**：每个 ✓/✗ 必须引用证据位——Prompt 原文片段、镜头卡字段值或注册表行（例："③ ✓——原文'画面左侧三分之一为成年女性@李梅，右侧三分之二为孩童@张三'"）；**无证据的 ✓ 无效，直接判该维缺失**；核查明细随 Prompt 写入产出文档接受复核。
5. **指令可执行铁律**：打回单的每条修改指令必须"可直接改写"——给出具体句式（"在 [0.8-3秒] 节点后追加……"），禁止"再优化一下/加强一致性"这类空话。
6. **三轮上限铁律**：同一 Prompt 打回 ≤3 轮；第 3 轮仍有缺维 → 标注"人工裁决"上报用户并记录在案。
7. **免检豁免铁律**：B 级降本镜的"无视频 Prompt"（纯静态图+剪映动效方案）免 8 维表，但**必须有时长声明**；其静态图 Prompt 本身仍走八层表全检。

## 二、标准执行 SOP（Step-by-Step）

**Step 1 · 定表**：先跑 `python scripts/qc_linter.py`（L1 机检，非 0 错误即打回并终止）；Prompt 类型 → 生图走 `KB_10` 一节八层表，视频走 `KB_10` 二节 8 维表；B 级降本镜走豁免规则（铁律 7）。

**Step 2 · 逐维取证**：按 KB_10 对应表逐层/逐维 ✓/✗ 并摘录证据。核查 ⑤维/③层 时对照《资产注册表》；核查 ⑦层/①⑧层 时读注册表第五节 `PACK-XX` 绑定信息（维度③轨道+维度④禁词表）执行多轨与六维合规执法；核查横切项时对照 `KB_09` 第一节崩坏大表（`全局复盘避坑黑名单.md` 仅核查新增实战崩坏时按需加载）。

**Step 3 · 汇总缺维清单**：视频目标 8/8、生图目标 8/8；列出全部缺失项（维名+一句原因+证据引用）——多项并发时**全部列出，不取重**（修改义务不减）。

**Step 4 · 裁决**：全过 → 放行（输出明细+使用建议）；有缺 → 打回（出具《打回重写指令单》）。

**Step 5 · 落盘**：核查行+轮次写入产出文档；第 3 轮仍有缺 → 升级人工裁决。

## 四、专项工具箱

### 4.1 维度表唯一权威引用（KB_10 V3 · 不维护并行表）

生图**八层核查表**与视频**8 维核查表**以 `kb_library/KB_10_资产与视频质量检查.md` 为**唯一权威来源**，本技能直接引用其层/维编号与缺失判定标准，**严禁在任何 Skill 内另行抄写合并版**（防编号错位与判定漂移）。

- **判定**：缺一即不通过；不打总分、不写分；无证据=判缺失。
- **⑦层多轨兼容执法**：先读项目《资产注册表》第五节绑定的 `PACK-XX` → 按其维度③对应轨道逐字判——PACK-01 项目 B 轨词组逐字在＝过；误用 A 轨"无影棚/正交相机/Albedo"任一词＝⑦层缺失（PACK-02 误用 B 轨绘画语、PACK-03/04 跨轨混用同判）。
- **①⑧层六维合规执法**：①句首媒介词就位且时代匹配；②尾锁矩阵正确挂载；③全文零命中维度④排斥禁词——命中任一禁词＝①⑧层均缺失，强制打回（执法依据＝注册表第五节禁词表）。
- 全部层/维判定细则以 KB_10 表内原文为准；核查输出中的编号一律使用层号（①~⑧）/维号（①~⑧）。

### 4.2 《打回重写指令单》标准格式（维度版）

```markdown
## 🔴 打回重写指令单（第 N 轮）
- **被评对象**：[镜号/Prompt编号] · [生图/生视频] · 目标平台[…]
- **核查结论**：L1机检: PASS ｜ L2维度核查: X/8（第 N 轮）
- **缺维清单（逐项含证据）**：
  1. [⑧ 维] 证据："（引用初稿原文）"——问题：多人台词无倾听者闭嘴锁（崩坏05）
  2. [⑤ 维] 证据："（原文 40 字外貌）"——问题：外貌超 ≤2 锚点配额
```

## 五、实战演示：李梅母子例（金标准② · 初稿 5 维缺失打回 → 修改稿 8/8 放行）

**❌ Bad Case【初稿】（镜2 · 视频类 · 第 1 轮送检）**：
```prompt
@李梅（鹅蛋脸柳叶眉温润杏眼、栗色齐肩微卷发别素色发夹、米白罗纹针织开衫配浅杏连衣裙、斜挎帆布托特包）牵着@张三（娃娃脸婴儿肥大圆眼长睫毛黑色短碎发呆毛、天蓝小熊耳连帽卫衣）走在黄昏的街上，孩子跟妈妈说想吃东西，妈妈温柔地回应他，镜头先是全景然后慢慢推近最后切到孩子特写，两人有说有笑，大概五秒钟，画面温馨，@画风锁+暖金橙主调
```

**【第 1 轮核查：3/8 · 打回——5 维缺失】**
- ①镜头规格 ✗ 证据"大概五秒钟"——无秒级规格句、无画幅标注
- ③人物站位 ✗ 证据"牵着@张三…走在黄昏的街上"——无象限分区句、无体型差句（崩坏06 风险）
- ⑤一致性 ✗ 证据"（鹅蛋脸柳叶眉…帆布托特包）+（娃娃脸婴儿肥…连帽卫衣）"——外貌 50+ 字堆砌，超 ≤2 词/人锚点配额（①层职责被侵占）
- ⑦动作与时间 ✗ 证据"先是全景然后慢慢推近最后切到孩子特写"——单镜三机位（崩坏04）＋无秒级节点＋"大概五秒钟"非 0.5s 网格
- ⑧台词音色口型 ✗ 证据"孩子跟妈妈说想吃东西，妈妈温柔地回应"——双主体台词：无说话者区分/无台词原文/无起止节点/无语气语速停顿/无口型排他锁（崩坏05/16 双高危）
- ②构图 ✓（黄昏街景中景可推断）｜④透视与空间 ✓｜⑥连续性 ✓（单镜无跨镜矛盾）

**【打回重写指令单（第 1 轮）】**：
1. 主体段压缩为"米白开衫母亲@李梅与天蓝卫衣孩童@张三"（各 1 词）；全部外貌移入分镜图（原分镜图·2026-10-18 更名）职责（IMG-02）。
2. 删除"最后切到孩子特写"——单镜单机位"远景缓慢推近"。
3. 台词落 NARR-03 精算：张三台词"妈妈，我要吃莽莽"（8字/4字每秒≈2.2s+铺垫0.8s=3s）；李梅改"双唇闭合含笑倾听"（本镜单台词主体）。
4. 补秒级节点 `[0-0.8秒]`/`[0.8-3秒]`；补画幅与秒数标注。
5. 补空间分区句式（左1/3 母·一米六五 / 右2/3 子·一米一）。

**✅ Good Case【修改稿】（第 2 轮送检）**：
```prompt
米白开衫母亲@李梅与天蓝卫衣孩童@张三行于@光大街边：画面左侧三分之一为成年女性@李梅（身高约一米六五），右侧三分之二为孩童@张三（身高约一米一），两人牵手间距一臂；[00-00.8s]远景镜头缓慢推近，母子缓步前行，@张三仰头拽动母亲衣角，梧桐树影斑驳、馄饨摊白雾轻晃；[00.8-03.0s]@张三抬头张嘴说话，嘴唇随台词自然开合："妈妈，我要吃莽莽"（奶声奶气，尾音拖长，渴望语气）；一旁的@李梅保持双唇闭合、嘴角含笑低头倾听，不发一言，@画风锁+暖金橙主调黄昏柔焦光晕，16:9，3秒
```

**【第 2 轮核查：8/8 通过 · 放行】**（逐维取证一行版）：
- ①✓ 卡列=规格句（"16:9，3秒"）｜②✓ 中景纵深构图｜③✓ 象限+体型差+间距句在｜④✓ 三层分句（树影/母子/馄饨摊）｜⑤✓ 锚点 1+1 词+锁挂载｜⑥✓ 单镜无跨镜矛盾｜⑦✓ 双节点 0.5s 网格+测算在册（8 字÷4 字/秒+铺垫 0.8s=3s）+单主动作（说话）｜⑧✓ 说话者/原文/节点/语气语速/尾音停顿五要素齐+双锁（张嘴者+闭嘴者）
- **使用建议**：即梦素材位 3 位（双立绘+空镜）；抽卡 3 次取"双脸同真+李梅全程闭嘴"；尾帧可复用作镜 4 前参考。

## 六、边界情况处理（Edge Cases）

1. **三轮仍有缺维**：出"人工裁决单"（缺维清单+三轮演进+建议人工决策点）上报用户；该 Prompt 标记冻结（可能暴露 KB 词库缺口，直接开任务修库）。
2. **平台专属附加证据位**：指定平台的 Prompt 追加平台证据位核验——即梦（素材位清单/一致性行）、ComfyUI（双轨/节点单/负向包）、MiniMax（方括号单指令/声音栏）、可灵（首尾帧声明/幅度匹配）、豆包（三层分句/4K 缀）——缺项计入对应维（①镜头规格/⑤一致性）判缺失。
3. **修改稿引入新问题**：只盯指令单条目复核+全表快扫——新问题新一轮核查，不因"改了旧的"豁免新的。
4. **同一 Prompt 多平台版本**：每平台版本独立送检独立判定（语法差异不共享结论）。
5. **用户坚持发布有缺维的 Prompt**：产出文档标注"未过门禁·用户裁决发布"。
6. **打回单被 R5/R6 部分执行**：复审逐条对账——未执行条目原样重列并轮次+1；连续两轮部分执行升级导演介入。
