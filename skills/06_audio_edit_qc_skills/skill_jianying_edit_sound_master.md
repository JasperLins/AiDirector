# 剪映剪辑调音技能（EDT-01）

## 执行步骤（单镜建议）

1. **变速**：按镜头情绪选 6 种真实曲线变速预设之一（`蒙太奇/英雄时刻/子弹时间/跳接/闪进/闪出`）；常规镜头用"常规变速 1.0~1.2x"。
2. **动画与关键帧**：入场/出场动画（渐显、向右上飞入等）；B 级静态镜用关键帧做"缓推/缓摇"（模拟运镜零崩坏）+ 粒子特效图层（光斑/尘埃）。
3. **转场**：相邻镜头选真实转场名（基础：`叠化/闪黑/闪白`；运镜：`推进/拉远/左移/右移/旋转/模糊`；氛围：`漏光/故障/燃烧`）；叠化建议 0.2~0.3 秒。
4. **J/L-Cut 落位**：Cutaway 缓冲镜覆盖主轨，标明声画错位切入秒点（如"镜3 台词尾音延入镜4 前 0.5 秒 L-Cut"）。
5. **音效**：Foley 搜索词 + 卡点秒数（动作顶点帧对齐重拍）；环境音底噪铺底。
6. **人声指导**：语速/语气/声调（联动 AUD-01 克隆参数）。

## 整集指南（集末汇总）

- 节奏曲线：钩子(0-3s)→升压→小爆点→压抑→大爆点→钩尾。
- 粗剪 SOP：按分镜顺序串片段 → 对白轨先行（声画先行）→ 裁掉崩坏帧换 Cutaway。
- 精剪 SOP：曲线变速卡点 → 转场统一风格（同场次同转场族）→ 字幕安全区（竖屏底部 15%）。
- 混音规范：人声 -6dB ＞ Foley -12dB ＞ BGM -18~-20dB ＞ 环境底噪 -24dB；对白段 BGM 手动压低 30%。
- TTS 人声导入流程：克隆音频入人声轨 → 智能降噪 → 人声美化 → 对口型（模式B）→ 音画对齐微调。

## 输出格式（单镜）

```
- **本镜头剪辑与调音建议**：
  - 剪映剪辑手法：曲线变速「英雄时刻」于剑指顶点帧；出场动画渐显0.3s；与下一镜间转场「叠化」0.2s
  - 人声与配音指导：@李梅 4字/秒温柔降调尾音（克隆卡参数）；孩童台词重音"吃"
  - 音效与环境音：音效库搜「街道嘈杂」铺底-24dB；「炒菜锅铲」于白雾特写入点+0s；BGM 暖钢琴于0.5s渐入-20dB，台词段压至-26dB
```

## 正反例

✅ 正确：菜单名全部来自 KB_12 真实词典（英雄时刻/叠化/漏光），dB 值与秒点齐备。
❌ 错误：使用"时光倒流特效""梦幻星轨转场"等 KB_12 未收录的编造名（违反真实菜单铁律，直接打回）。
