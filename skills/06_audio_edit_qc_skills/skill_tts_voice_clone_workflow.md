# 音色克隆工作流技能（AUD-01）

## 执行步骤

1. **定音色特征**：从剧集圣经音色基线出发——音色质感（低沉清冽/温软治愈/奶萌）+ 语速档（KB_12 1.5 节）+ 情感倾向。
2. **选平台**：
   - Fish Audio：真人克隆（10 秒起，15~30 秒佳；ComfyUI 节点总时长 <270 秒）
   - MiniMax：情绪标签内嵌（`<#>` 情绪、`( )` 停顿）、儿童声预设
   - CosyVoice：本地批量 + instruct 副语言指令（`<|HAPPY|>` 等全大写头部标记）
3. **备参考音频**：干声要求（发音清晰/情绪平稳/背景干净）；给出录制或选样建议与时长。
4. **台词注音方案**：逐句标注——副语言标签 `(softly)` `(breath)` `(sigh)` + 语速 + 重音字 + 停顿位 + 多音字/儿化注音（如"莽莽"轻声宠溺）。
5. **产出克隆卡**（KB_12 五节模板）写入资产文档，登记注册表音色ID。
6. **交付剪映**：音频文件 + 建议轨位（人声轨 -6dB）+ 对口型流程（模式B 时走 LatentSync/剪映对口型）。

## 台词注音示例（例子1）

```
@张三："妈妈，我要吃莽莽"
→ (excited)语速4字/秒 ｜ 重音"吃" ｜ "莽莽"读 mǎng-mǎng 轻声、尾音拖长带奶音
@李梅："张三，上次我们才吃了，等爸爸回来给你买"
→ (softly)语速4字/秒 ｜ "等爸爸"前 (breath) 轻换气 ｜ "买"字尾音降调收温 ｜ 句间停顿0.3秒
```

## 输出格式（克隆卡）

```
### @人物 音色克隆卡
- 目标平台：… ｜ 音色特征：… ｜ 语速档：…
- 参考音频要求：…秒干声，含…语气样本，背景干净
- 克隆参数：…（平台真实参数，严禁编造）
- 情感标签示例：…（逐句注音）
- 发音指导：多音字/儿化/专有名词读法
```

## 正反例

✅ 正确：`Fish Audio 上传 20 秒干声（总<270秒），S2 词级控制在"莽莽"两字加拖音标签`。
❌ 错误：`把音色调成温柔一点就好`（无参数无标签不可执行）；编造不存在的参数如"情感强度 87%"（KB_12 未收录，禁止）。
