# 复盘自进化技能（EVO-01）

## 执行步骤

1. **采集**：扫描 workspace 产出文档中所有非占位的 `Prompt 实际产出复盘` 字段（含 Prompt 编号、平台模型、现象描述）。
2. **归因**：对照《全局复盘避坑黑名单》17 类逐条匹配；无法匹配 → 立新编号（从 18 起编）记录触发条件与根因假设。
3. **定策**（按影响面选动作）：
   - 个案 → KB_09 修正速查表补一行修正写法
   - 高频（同类 ≥3 次）→ 升级为 KB_10 一票否决题 + 黑名单实战区归档
   - 平台特有 → 修订对应 `plat_*` 插件的"正反例"或参数基线
   - 词库缺口 → KB_02/03/04/11 补词
4. **执行写入**：按上表目标文件修订（保留修订日期注释）。
5. **汇报**：输出优化清单（改了什么/为什么/下次如何避免），并提示受影响的存量 Prompt 复测。

## 归因输出格式

```
【复盘归因】复盘#镜2-视频 ｜ 崩坏05（多人乱张嘴）｜ 平台：即梦2.0
【触发片段】"…@李梅与@张三边走边聊，台词：…"
【根因】未写口型排他锁（当时版本 Prompt 缺失倾听者闭嘴句）
【优化动作】① KB_10 V5 已为否决级（确认有效）② plat_jimeng 正例补素材位+闭嘴锁完整句 ③ 黑名单实战区归档本例
【复测提示】镜2 按新模板重编译后请再跑 2 次验证
```

## 黑名单归档格式（写入 memory/global/全局复盘避坑黑名单.md 实战区）

```
【2026-10-01】即梦 Seedance 2.0 ｜ 崩坏05 ｜ "母子同框双台词无闭嘴锁" ｜ 全员张嘴 ｜ 已升级 KB_10 V5 否决+plat_jimeng 正例修订
```

## 正反例

✅ 正确：归因到编号、动作落到具体文件具体节、给出复测闭环。
❌ 错误："下次注意点，提示词写得保守些"——无编号、无文件修订、无复测，问题必然复发。
