# 单集剧本与脚本转化器（NARR-04 · 剧本 vs 脚本三层边界）· 工业级完整版

## 〇、理论与格式底座（权威来源，严禁自造非标野路子）

本技能的一切格式规范均锚定 `memory/global/权威工作流与影视知识库.md` 已核实的权威结论，禁止自创格式：

1. **huobao-drama 小说改剧本管线（知识库 1.2 节）**：`小说原文导入 → AI 改写为可拍摄剧本（按集拆分、标注场景与角色）→ 资产提取 → 分镜拆解 → 提示词生成`。本技能负责该管线的第二环——"改写为可拍摄剧本"：按集拆分、每场标注场景与角色（`@资产`），为下游资产引用与分镜拆解供给结构化原料。
2. **HKUDS/ViMax 职责解耦（知识库 1.3 节）**：Screenwriter（编剧）与 Shot Planner（分镜规划）是**两个独立智能体**——编剧只产出故事层文本，分镜规划只消费编剧产物做视听切分。本框架对应 R1（本技能）与 R2（VIS-01）；职责解耦的物理表现就是"文学剧本里绝不出现运镜术语，分镜脚本里绝不新增故事内容"。
3. **好莱坞标准剧本格式 / Fountain 纯文本规范**：一场戏 = **Slugline 场景头**（`INT./EXT. 地点 - 日/夜`）→ **Action 外化动作行**（只写镜头拍得到的东西，现在时态）→ **对白块**（角色名提示行 + 台词 + 括号语气注）；画外音标 **V.O.**（Voice-Over）、画外音源标 **O.S.**（Off-Screen）。本框架汉化映射见 4.2 表——概念与骨架照搬国际标准，仅做中文表达本地化。

## 一、核心职责与工业级法则（6 条硬核铁律 + N 三查剧本结构门禁）

1. **三层边界·概念严禁混淆铁律**：全框架只有三层文本产物，单向流转、严禁越层——
   - **【文学剧本（Literary Script）】（R1 产出）**：纯故事与戏剧叙事层。按 `【第X场 · 场景名 · 日/夜 · 内/外】` 编写连贯的故事画面、人物动作博弈、神态反应、完整台词与 `【画外OS】`。**文学剧本内严禁出现"推近、拉远、特写、慢镜头、ControlNet、I2V、首帧、垫图、LoRA"等一切机器与摄影机术语**——专心把故事爽点、潜台词与人设张力写透。
   - **【分镜脚本（Shooting Script / 镜首切片）】（R2 产出）**：视听调度与执行层。将文学剧本切分为具体镜号，输出 14 字段分镜总表（VIS-01 规范），且必须在每个分镜 `## 镜 XX` 标题正下方输出 **2 行高浓度镜首脚本切片**（`> 📜 本镜脚本` + `> 🎙️ 台词 / OS`），作为连接文学剧本与 AI 提示词的桥梁。
   - **【生成提示词（AI Prompts）】（R5/R6 产出）**：机器编译层。严格按 KB_08 公式由分镜脚本编译为 ```prompt 代码块，严禁跳层把剧本散文直译成提示词。
2. **场头 Slugline 汉化铁律**：每场以 `【第X场 · 场景名@资产 · 日/夜(可细化时段：清晨/午后/黄昏/入夜/深夜) · 内/外】` 开场，对齐好莱坞 Slugline 与 Fountain 规范；**一场一景一时段**，时段变更必须新起场头并剧本明写（对应场记"时间天气锁定"铁律，供 @光位常量 派生）；双时空剧集在场头尾加"（现代·地球）/（沧澜·某国）"界别缀防串界。一集内有大场景位移时可下设子场头（第1场A/第1场B），但顶级场次数保持与剧本头信息的场次列表一致。
3. **小说改剧本去心理化铁律**：将原著/大纲改编为单集文学剧本时，所有心理描写要么**外化为可见肢体动作与神态反应**（写"指尖攥皱衣角、喉头滚动"，不写"她很紧张"），要么转化为女主专属的 `【画外OS】` 吐槽台词。Action 行只写"摄影机拍得到的东西"；原文对白必须按剧集圣经版权红线原创化改写（禁原著专名/原句/情节链复刻）。
4. **台词双轨物理隔离铁律**：文学剧本和分镜切片中每句台词必须显式标注轨别——`【画面口型】`（角色在画面内张嘴说话，编译进视频 Prompt 口型层，受口型排他锁约束）与 `【画外OS·不张嘴】`（内心吐槽或旁白，**严禁编译进视频张嘴动作**，仅走后期音频轨）；无台词镜标 `【纯静默】`。轨别一旦判定，R5/R6/R8 三方不得串轨——OS 张嘴、台词闭嘴，都是一票否决级崩坏。
5. **标准音频文件名预埋铁律**：每句台词/OS 在剧本总表与镜首脚本切片中必须同步分配标准音频保存文件名 `[音频ID: E集数_S镜号_角色_台词前四字.wav]`（前四字=去标点后台词的前四个汉字），供 TTS 批量生成命名与剪映素材池一键对齐；同镜同人双台词靠"台词前四字"天然去重，角色名取 `@资产名` 去 @ 符号。
6. **声画先行交接铁律**：剧本正文完成 ≠ 阶段Ⅰ完成——必须交 NARR-03 按字数/语速/气口精算每句时长与重音秒位，回填"台词与OS声画先行总表"（轨别/语速档/时长/重音秒位/音频ID 五要素齐全），连同剧本正文一并写入分镜文档顶层折叠区；R2 拆分镜后逐一核对镜首切片台词与总表**逐字一致**——分镜可以删节台词（删节须在总表标注、对应音频ID 作废回收），**严禁改写或新增**。

## 二、标准执行 SOP（Step-by-Step）

**Step 1 · 读记忆承状态**：读剧集三件套（圣经/资产注册表/StateDiff），确认本集起点状态（上集遗留在场人物、伤势服装、道具、时间天气）；涉及 `@资产` 引用时只使用注册表已注册名。

**Step 2 · 定钩子与曲线**：以 NARR-01 产出的市场痛点、黄金前 3 秒钩子、情绪曲线节点表为输入，确定本集"悬→暖→恨→痛→燃→…"的节拍骨架与集末钩子。

**Step 3 · 排场次**：把大纲切分为场（一场一景一时段），逐场写 Slugline 场头；核对场次列表与场景 `@资产`、人物 `@资产` 的对应；一次性未注册场景（如"MCN 办公室"）标注"未注册一次性场景"，交 R4 查重决议。

**Step 4 · 写正文**：逐场撰写 Action（外化、现在时态、可视化）与台词（双轨标签 + 语气·语速括注）；全篇扫描禁词表（推近/拉远/特写/镜头/ControlNet/I2V/首帧/垫图……），命中即改写为故事语言。

**Step 5 · 预埋音频ID**：为每句台词/OS 分配 `[音频ID: E集数_S镜号_角色_台词前四字.wav]`；镜号未定时分场预分配，R2 定镜后回填精确镜号。

**Step 6 · 交 NARR-03 精算**：每句台词/OS 过秒数精算（字数÷语速+气口，0.5s 取整），回填声画先行总表的时长与重音秒位列。

**Step 6.5 · N 三查自审（R9-20261006-4 · 剧本层结构门禁）**：定稿前逐项自审并在输出契约附审查记录——①**转场动机链查**：逐场问『观众能回答人物为什么在这儿吗』（省略过程合法，省略动机非法；被胁迫/被诱导/主动前往必须可从台词或动作推断）；②**S 级场钩子回收查**：每个 S 级登场/奇观场登记钩子台账（钩子内容→集内回响镜号 或 显式标『跨集钩』）；③**人物登场必要性查**：新人物首登场必须以台词/道具/事件勾连主线。任一不过→就地补写动机锚/钩子，禁止带病下交（剧本缺陷会被 R2~R8 全链路高保真放大）。

**Step 7 · 交 R2 并回检**：剧本正文+总表交 R2 拆分镜；R2 产出后逐镜核对镜首切片（📜/🎙️ 两行）与总表逐字一致，删节台词回收音频ID；分歧上报总控裁决。

## 四、专项工具箱

### 4.1 三层产物对照表（谁产出 / 写什么 / 禁什么）

| 层 | 产出角色 | 内容 | 严禁 |
|---|---|---|---|
| 文学剧本 | R1（本技能） | 场头+外化动作+双轨台词+OS | 摄影机/机器术语、心理描写直译 |
| 分镜脚本 | R2（VIS-01） | 14字段总表+镜首2行切片（📜/🎙️） | 新增/改写台词、新增故事内容 |
| 生成提示词 | R5/R6（KB_08） | ```prompt 代码块 | 跳层直译散文、混入他平台语法 |

### 4.2 好莱坞/Fountain → 本框架汉化映射表

| 国际规范 | 本框架汉化 | 说明 |
|---|---|---|
| Slugline `INT. 房间 - 日` | `【第X场 · 房间@资产 · 日 · 内】` | INT/EXT→内/外；地点挂 `@资产` |
| Action 行 | 动作行（现在时态、只写拍得到的） | 心理描写禁入，改 OS 或外化 |
| 角色名提示行 | `**@角色**【轨别】：` | 双轨标签为本土增强项 |
| `TOM (V.O.)` 画外音 | `【画外OS·不张嘴】` | 严禁编译进视频张嘴动作 |
| `TOM (O.S.)` 画外音源 | `【画外OS·不张嘴】`（同轨处理） | 画面外声源，走后期轨 |
| `(parenthetical)` 括注 | `（语气·语速档）` | 供 NARR-03 定语速档 |
| `CUT TO:` / `FADE OUT.` | 不使用（剪辑术语归 R2/R8） | 场头切换由排版自然承担 |

### 4.3 OS 写作三原则

1. **人格专属**：OS 默认只给"穿越/重生/现代灵魂"型主视角（其他角色的内心一律外化为动作神态）；密度每集 ≤5 处，S 级泪点镜与伏笔特写镜禁 OS。
2. **吐槽即爽点**：OS 用现代语汇对冲古代情境的沉痛（痛感+幽默同帧），但遵守圣经网梗铁律（沧澜本土角色禁现代词汇）。
3. **留声不留口**：OS 文本一律标注 `【画外OS·不张嘴】`，进总表走后期 TTS 轨；在镜首切片中注明入点（如"入点镜01 2.5s，J-Cut 跨镜"）。

### 4.4 音频ID 命名细则

`E集数_S镜号_角色_台词前四字.wav`——集数两位（E01）、镜号与分镜总表一致（S12C 表为 S12-CUT 时取 S12C）；角色取注册表资产名去 @；台词前四字=去标点后前四个汉字（"好啦宝子们，明晚…"→`好啦宝子`）；同镜同人双台词天然靠前四字去重；分镜删节台词的音频ID 即时作废并在总表标注。

## 五、常见错误示范 vs 满分工业级示范

### 对比组 1：剧本与分镜混淆（本技能最高频事故）

❌ **Bad Case**：
> 【第3场 · 偏院 · 日 · 内】镜头缓缓推近，给她一个面部的特写，然后切到杏儿反应镜头，节奏上做个慢动作；这里可以用 ControlNet 锁姿态，I2V 出 5 秒；她心里很难过，想起外婆的温柔。

**扣分点**：一句话犯满三条铁律——"推近/特写/切/慢动作"是 R2 的视听语言（铁律1）；"ControlNet/I2V/5秒"是 R5/R6 的机器语言（铁律1）；"心里很难过"是心理直译（铁律3）。下游 R2 拿到后无法判断故事目的，R7 无从评分。

✅ **Good Case**：
> 【第3场 · @沈府偏院 · 入夜 · 内（沧澜·东澜国）】
> 暮色四合，屋里点起一盏豆大的油灯。@沈小满倚在床头，就着灯火翻那册蓝布面线装手札；她合上手札，摩挲左手中指的旧玉戒——指尖针眼被戒身硌开，一滴血珠滚落，正落在戒面饕餮纹的兽目上。血珠像被吸了进去，纹路深处泛起一线暗金微光，转瞬即敛。她指尖一颤，仿佛触到一点温热。
> **@沈小满**【画外OS·不张嘴】："第一笔，记上了。"（冷静·3.5字/秒）[音频ID: E01_S06_沈小满_第一笔记.wav]

### 对比组 2：台词无轨别 / OS 张嘴

❌ **Bad Case**：
> 旁白：上一秒我还在直播间熬高汤。（画面里"沈小满"嘴巴一张一合地念出这句话）

**扣分点**：OS 无轨别标签，编译时会混入口型层——"OS 张嘴"是观众瞬间出戏的一票否决崩坏（铁律4）。

✅ **Good Case**：OS 行标 `【画外OS·不张嘴】` 并注明入点（"入点镜01 2.5s，J-Cut 跨入镜02"）；画面内角色保持闭唇隐忍，OS 由后期 TTS 轨压入——痛感与幽默同帧，嘴不张。

## 六、边界情况处理（Edge Cases）

1. **原著改编版权红线**：改写时禁用原著专名/原句/具体情节链（对照剧集圣经〇节五条红线）；情绪节拍可参考，文字表达必须原创；改写完成后过一遍红线自查表。
2. **冷开场/闪回/插叙**：文学剧本按**故事时序**书写；冷开场、闪回、平行插叙等蒙太奇重排属 R2 分镜层手法——分镜总说明中注明源场次（如"镜01 为第3场针刺事件的前置闪切"），镜首切片回填对应镜号即可，剧本不重排。
3. **无名群演/一次性角色**（退婚使、轿夫、仪仗兵）：不注册资产，剧本以身份称谓+外貌描写承载；过 R4 查重，不与注册名冲突、不抢戏份。
4. **剧本台词与分镜压缩冲突**：2~4 分钟单集容不下剧本全部台词时，R2 可删节但**严禁改写或新增**；删节须回写总表（标"分镜删节"、音频ID 作废回收），保持三层文本严格同源。
5. **无对白集/默片段**：总表仍须产出——每镜占一行标 `【纯静默】`，环境音与 BGM 卡点位填入"重音秒位"列，音频ID 留"—"。
6. **双时空平行叙事**：两界戏场头必须带界别缀（"（现代·地球）/（沧澜·东澜国）"），同日平行事件在场头标注"另一端/与此同时"；时段各自独立锁定，防场记时空调错与光位常量误派生。
