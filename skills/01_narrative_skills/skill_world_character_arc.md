# 世界观与人物弧光技能（NARR-02）

## 执行步骤

1. **世界观三问**：规则（力量/社会体系）、稀缺（什么最珍贵）、禁忌（什么不可为）——各写 1~2 句，多余的设定砍掉（短剧不需要百科）。
2. **人物立体小传**：按 KB_01 原型库选型 → 性格外化表（静态/动态/微表情三列）→ 年龄段锁定（KB_01 第三节）→ 记忆点 1+1（可视化、可叙事、可复现、不冲突）。
3. **外貌锁定摘要**：用 KB_02 第七节模板生成，写入资产注册表（后续所有 Prompt 唯一引用源）。
4. **关系三角**：每对主要人物（表面关系/真实关系/变化方向）。
5. **潜台词三层法改写台词**：字面 → 潜台词 → 外化动作；台词只保留字面，外化动作单独列（交给导演做动作节拍）。
6. 更新剧集圣经；新角色同步登记资产注册表。

## 输出格式

```
【世界观】规则：…｜稀缺：…｜禁忌：…
【人物卡】@名｜原型：…｜年龄感：…｜性格外化：静态…/动态…/微表情…
【外貌锁定摘要】（KB_02 模板逐项填写）
【记忆点】主：…（前史：…）备：…
【关系三角】@A—@B：表面…/真实…/变化…
【潜台词示例】台词"…" → 潜台词… → 外化动作…
```

## 正反例

✅ 正确：`@林烬｜原型：隐忍复仇者｜记忆点：左手虎口旧疤（母亲护子所留）+单侧嘴角冷笑｜外化：拳收袖中、指节泛白`。
❌ 错误：`@林烬是个很复杂很深情的人，内心有很多故事`——无外化、无记忆点、AI 无法生成"复杂"。
