# 台词秒数精算器（NARR-03 · 声画先行）

## 执行步骤

1. **数字数**：台词去掉标点数汉字数 N（儿语气泡"莽莽~"计 2 字）。
2. **定语速档**（KB_12 语速基准）：急促 5.5 字/秒、正常 4.0、童声 3.5~4.0、沉吟 2.5。
3. **算停顿**：逗号 0.3 秒、句号 0.5 秒、省略号/哽咽 0.8 秒、重音前微停 0.2 秒。
4. **总时长** = N ÷ 语速 + Σ停顿，**四舍五入到 0.5 秒**。
5. **标重音点**：圈出 1~2 个重音字，标注其发生秒位（卡 BGM 与 Foley 点）。
6. **倒推动作节点**：`开口前留 0.5~1.5 秒动作铺垫，收口后留 0.5 秒情绪余韵`，输出秒级节点给 VID-01。

## 计算示例（例子1台词）

**台词**："妈妈，我要吃莽莽"（8 字，童声 4 字/秒）
- 时长 = 8÷4 + 逗号停 0.3 + 尾音拖长 0.4 ≈ **2.7 → 取 2.5~3 秒** → 镜头 1 定 3 秒
- 重音："吃"（约第 1.8 秒）
- 节点倒推：`[00-00.8s] 仰头铺垫]；[00.8-3.0s] 开口说台词]`

**台词**："张三，上次我们才吃了，等爸爸回来给你买"（15 字，正常温柔 4 字/秒）
- 时长 = 15÷4 + 逗 0.3 + 句逗 0.3 + "等爸爸"前换气 0.4 ≈ **4.7 → 取 4.5~5 秒** → 镜头 3 定 5 秒（示范集为节奏紧凑取 4 秒，微提速 4.5 字/秒并压缩停顿，须在分镜说明注明）

## 输出格式

```
【台词精算】"…"｜字数N=…｜语速档=…｜停顿Σ=…｜时长=…秒（取整至0.5）
【重音点】字"…"@第…秒
【动作节点】[铺垫 0-…s] → [开口 …-…s] → [余韵 …-…s]
【口型模式】A（平台直出）/ B（后期对口型，视频段写闭嘴基底）
```

## 正反例

✅ 正确：镜头时长 = 台词实测时长 + 铺垫 + 余韵，三者显式写进分镜表。
❌ 错误：5 秒镜头塞 30 字台词（需 7.5 秒）——嘴型赶帧、语速失真，触发崩坏16 一票否决。
