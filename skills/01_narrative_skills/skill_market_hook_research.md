# 市场钩子与情绪曲线技能（NARR-01）

## 执行步骤

1. **受众画像**：确认题材赛道（男频玄幻爽剧 / 女频情感 / 全龄温情 / 悬疑），列出核心受众痛点（被轻视、等待、亏欠、逆袭渴望）。
2. **黄金前 3 秒钩子设计**：从下列钩子库选取 1 主 1 备，并写出首镜画面（可直接交给导演拆镜）。
3. **情绪曲线排布**：以 15 秒为一格绘制整集情绪刻度（1-10），强制"压抑→反转→爆发"至少一轮，标注爆点秒位。
4. **爽点/泪点配额**：60~90 秒单集 ≥2 个小爆点 +1 个钩尾悬念。
5. 交棒：输出 Schema 交给导演（R2）拆分镜，S 级镜头直接对齐爆点秒位。

## 钩子库（前 3 秒）

| 钩型 | 模板 | 示例 |
|---|---|---|
| 压场型 | 反差身份+全场噤声 | 叛徒之子一剑立台，千名弟子无人敢前 |
| 危机型 | 倒计时灾难+弱者 | 孩子走失前最后 3 秒 |
| 悬念型 | 反常细节特写 | 停在 3 点 07 分的怀表 |
| 冲突型 | 当众羞辱+隐忍 | 被扔出的聘书散落泥水 |
| 温情型 | 稚语戳心 | "妈妈，爸爸什么时候回来呀" |

## 输出格式

```
【市场受众分析】赛道：…｜核心痛点：…｜对标：…
【黄金前3秒钩子】主：…（首镜画面：…）备：…
【情绪曲线】0s钩子(7)→15s压抑(3)→30s小反转(6)→45s再压(2)→60s大爆点(9)→尾钩悬念(8)
【爽点清单】秒位+内容+等级建议(S/A)
```

## 正反例

✅ 正确："0-3s 钩子：@林烬背断剑立于台心，雷云骤暗，全场弟子后退半步（压场型，S级）"——画面可直接执行。
❌ 错误："开头要很炸很吸引人"——空洞形容词，无画面无秒位，评分官按 G12 扣分。
