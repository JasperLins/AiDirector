# 豆包 Seedream 平台插件（PLAT-01）· 工业级完整版

## 一、核心职责与工业级法则（6 条硬核铁律）

1. **中文原生铁律**：豆包 Seedream 中文理解顶级（官方 4.0 中文原生）——**禁止翻译成英文**喂豆包；英文串只在 ComfyUI 用。中文打光/材质/骨相术语直响应，翻译反而丢语义。
2. **三层空间分句铁律**：豆包对"前景…中景…远景…"分句式空间层次理解极强——任何含空间的图必须按三层分句组织；三层顺序固定（前景→中景→远景），每层一句，句内给虚实（"虚化/实焦"）。
3. **象限量化铁律**：多主体排布必须用量化象限词——`画面左侧三分之一 / 右侧三分之二 / 左前景 / 右后景纵深处 / 中轴线上`；模糊的"旁边/一旁"在多主体时必串位（配合身高差+服装色差三重锚定）。
4. **光影直命名铁律**：光学层直接点名光型术语（豆包强项）——伦勃朗光/轮廓光/逆光/分割光/环形光/顶光/丁达尔体积光；同时保留"高光不过曝、保留面部细节"防护句（I2V 首帧必挂，崩坏10）。
5. **文字克制铁律**：豆包 4.0 中文文字能力虽有增强，但**长句清晰文字仍不稳**——画面文字策略：①无文字（首选）②"字迹模糊虚化"（景深元素化）③短词 2~4 字（招牌/匾额，可尝试且备后期）；清晰长文一律剪映后期贴字。
6. **分辨率声明铁律**：末尾缀 `2K` / `4K`（4.0 原生 4K）；横幅资产/场景 4K、竖屏立绘 4K、快速草稿 2K；组图需求显式写"组图"并说明每格内容。

## 二、标准执行 SOP（Step-by-Step）

**Step 1 · 读入初稿**：取 KB_08 编译初稿（八层全量）；确认出图目标与多主体数。

**Step 2 · 空间重排**：按铁律 2/3 把初稿的空间/环境/主体层重排为"前景句→中景句→远景句"，多主体套象限句式+身高差+服装色差。

**Step 3 · 光影替换**：按 4.2 光影词替换表把通用光学描述换成豆包直响应术语；首帧图加过曝防护句。

**Step 4 · 文字方案**：按铁律 5 处理画面文字需求（三选一）。

**Step 5 · 规格与挂锁**：末尾依序挂 @画风锁+线别缀+画幅+分辨率；资产锁定图按 KB_06 例外条款替换光影词为 Albedo 平光组。

**Step 6 · 抽卡建议**：给次数（资产 2~3 次/首帧 3~5 次）与选优标准（下颌线最锐/双脸同真/白雾层次最好等具体指标）。

## 四、专项工具箱

### 4.1 长句空间方位排布语法（结构模板 + 象限词表）

**结构模板**：
```text
[景别+视角]@[场景/主体]：前景为[元素+虚实+占比暗示]，中景为[主体/核心元素+状态]，远景为[延伸元素+虚化]；
（多主体时）画面[象限词]为@人物A（身高+服装主色），[象限词]为@人物B（身高差+服装主色差）；
[光学层+色温]，[镜头层构图]，@画风锁+[缀]，[画幅]，[分辨率]
```
**象限词表**：`画面左侧三分之一 / 画面右侧三分之二 / 左半区 / 右半区 / 中轴线上 / 左前景 / 右前景 / 左后景纵深处 / 右后景纵深处 / 上三分之一（天空区）/ 下三分之一（地面区）`。
**虚实词表**：前景虚化 / 微虚化 / 实焦 / 大光圈虚化 / 焦点落于… / 景深外柔化。

### 4.2 中式光影质感词库（豆包直响应术语 · 替换表）

| 通用写法（弱） | 豆包直响应术语（强） |
|---|---|
| 脸上有光有影 | `伦勃朗光（单侧三角光）` / `分割光（左右脸明暗对分）` |
| 背着光 | `侧逆光镶金边` / `逆光剪影（高光不过曝）` |
| 光从上面来 | `顶光压迫感` / `教堂式顶光垂落` |
| 有氛围光 | `丁达尔体积光柱自云隙垂落` / `晨雾中的体积光` |
| 脸打匀了 | `蝴蝶光（环形光）` / `大型柔光箱正面平光` |
| 金属亮 | `精钢寒光凛冽镜面打磨` / `鎏金温润斑驳做旧` |
| 水汽感 | `白雾蒸腾自锅沿翻涌` / `薄雾漫过石板路面` |

### 4.3 中文文字渲染技巧（三档策略）

| 档位 | 适用 | 写法 | 风险 |
|---|---|---|---|
| ① 无文字 | 默认 | 不提文字；负向意识上规避（招牌只写色块形状） | 零 |
| ② 虚化文字 | 氛围招牌/匾额 | `招牌字迹模糊虚化不可辨认，作为景深元素` | 低 |
| ③ 短词尝试 | 剧情必需招牌（2~4字） | `匾额上书"玄天宗"三字楷书` + 抽卡 3 次 | 中（错字率存在，必配后期贴字备份） |

### 4.4 推荐分辨率与规格

| 场景 | 规格 |
|---|---|
| 资产三视图/场景全景/首帧基准 | 16:9 / 9:16，4K |
| 独立立绘（竖） | 9:16，4K |
| 快速草稿迭代（构图试错） | 2K（定稿后 4K 重出） |
| 组图（表情/分镜宫格） | 显式写"组图/九宫格"+每格内容，4K |

## 五、常见错误示范 vs 满分工业级示范

### 对比组 1：空间排布

❌ **Bad Case**：
> 一个大大的比武台，很多人围着看，远处有山有云有宫殿，主角站在中间很威风，光线很有氛围感，画质高清。

**扣分点**：无三层分句（豆包的空间强项没用上）；"很多人/有山有云"堆名词无层次无虚实；"中间/远处"未量化；"氛围感/高清"空洞——人群必糊成一团，宫殿飘在云上无纵深。

✅ **Good Case**：
```prompt
远景俯瞰@玄天宗比武台：前景为青石台面与四角符文石柱局部（微虚化），中景为立于台心的黑衣长发@林烬（九头身，玄黑劲装银线暗纹，小比例不抢戏），远景为云海之上层叠浮空山岳与凌霄殿玄铁飞檐（虚化）；台下环形人群剪影散布广场两翼；雷云压城冷青蓝主调天光，丁达尔光柱自云隙垂落三道，符文银白高光点缀石柱；低角度仰拍与中心构图，@画风锁+冷青蓝主调剑气银白高光，16:9，4K
```

### 对比组 2：文字与光影

❌ **Bad Case**：
> 街道招牌上写着"光大美食街欢迎品尝正宗手工馄饨"，字体清晰漂亮，人物站在光线下，光影效果好。

**扣分点**：12 字长句清晰文字（铁律5 红线，必乱码崩坏11）；"光影效果好"无术语（豆包直响应能力被浪费）。

✅ **Good Case**：
> 文字档②：`街道两侧招牌字迹模糊虚化不可辨认，作为黄昏景深元素`（"光大小吃"四字若剧情必需，短词尝试 3 次并备剪映贴字）；光影直命名：`黄昏暖金橙主调，侧逆光为@李梅母子镶金边轮廓，高光不过曝保留面部细节`。

## 六、边界情况处理（Edge Cases）

1. **多主体 ≥3**：豆包象限词只保主互动 2 人量化分区；第三人写"背景虚化剪影"（清晰三人脸=串脸温床，崩坏06）。
2. **竖屏（9:16）图**：象限词改纵向——"上三分之一天空区/下三分之一地面区/中轴主体贯穿"；空间三层改"下前景/中主体/上远景"纵向叠压。
3. **多图融合编辑（改图需求）**：豆包 4.0 支持多图融合创作——底图（要保留的构图）+人物参考图（立绘）双上，Prompt 注明"保持底图构图与人物参考外观"；重绘等效幅度靠"轻改/仅改光影层"文字指令控制。
4. **组图九宫格表情矩阵**：写"3x3组图"+九格情绪词逐格列出（每格给具体面部动作词）；抽卡选优标准="九格同一张脸"，不同脸即废。
5. **资产锁定图（三视图）**：本插件同样适用——Albedo 平光词组是豆包可执行的正面物理描述；但三视角一致性要求高时，评估转 ComfyUI（Lineart 钉轮廓）。
6. **生成结果画幅不符**：豆包偶发画幅漂移——Prompt 末尾画幅词重复一次（"16:9横幅，16:9"），仍漂则后期裁切并在复盘占位归档（EVO-01 修订本插件）。
