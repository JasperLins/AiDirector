# 豆包 Seedream 平台插件（PLAT-01）

## 平台语法特征（核实版）

1. **中文原生**：无需英文，直接中文长句；对打光术语直响应（伦勃朗光/轮廓光/逆光/分割光/环形光/顶光，KB_04 四节）。
2. **空间方位语法**：按"前景…中景…远景…"分句排布；支持 `画面左侧三分之一` / `右侧三分之二` / `左前景虚化` / `右后景纵深处` 精准象限词——多主体分区构图首选平台。
3. **分辨率词缀**：末尾缀 `2K` / `4K`（4.0 原生 4K）；支持组图生成与多图融合编辑。
4. **画风挂载**：`@画风锁` 放末尾仍然有效，符合本框架编译顺序。

## 编译调整（相对公用版）

- 空间分区句式升级为"前景/中景/远景 + 三分法象限"双层描述。
- 光学层直接点名具体光型 + 色温（豆包强项，别浪费）。
- 资产图仍执行 KB_06 零光影铁律（"平光/漫反射固有色"同样是豆包可执行的正面物理描述）。

## 模板示例（@玄天宗比武台全景）

```prompt
远景俯瞰@玄天宗比武台：前景为青石台面与四角符文石柱局部（微虚化），中景为立于台心的黑衣长发@林烬（仅剪影级小比例，不抢戏），远景为云海浮空山岳与凌霄殿玄铁飞檐层叠铺开；雷云压城冷青蓝主调天光，体积光柱自云隙落下三道，剑气银白高光点缀石柱符文；低角度仰拍与中心构图，@画风锁+冷青蓝主调剑气银白高光，16:9，4K
```

## 正反例

✅ 正确：前景/中景/远景三层分句 + 左右三分象限 + 光型命名 + 4K 词缀。
❌ 错误：把 Seedream 当英文模型翻译成英文长串（浪费其中文优势）；或塞入视频运镜词（生图平台不执行运镜）。
