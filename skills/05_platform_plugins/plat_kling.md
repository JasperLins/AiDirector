# 可灵 Kling 平台插件（PLAT-05）

## 平台语法特征（核实版）

1. **官方公式**：`主体（主体描述）+ 运动 + 场景（场景描述）+（镜头语言 + 光影 + 氛围）`——主体+运动+场景是核心三要素。
2. **首尾帧（First & Last Frame）**：上传首帧+尾帧双图锚定起止画面，Prompt 只描述中间过渡运动；**运镜幅度必须匹配首尾帧画面差异**，否则运镜指令不执行。
3. **物理规律模拟**：3D 时空联合注意力机制，写符合物理的动作描述（重力、惯性、碰撞）效果更佳；大幅度运动合理性强。
4. **锚点间隔**：多镜头分段叙事时时间锚点间隔 ≥3 秒，否则切换生硬。
5. 主体崩坏急救：增加外貌细节 + 使用主体参考图。

## 编译调整（相对公用版）

- 按官方四段式重排：主体（锚点2词）→ 运动（过渡描述，非起止状态）→ 场景 → 镜头语言+光影+氛围。
- S 级镜头必配首尾帧双图（IMG-02 产出），Prompt 中注明"首帧=图1（台心持剑静立），尾帧=图2（剑指前方衣袂定格）"。
- 大幅运动写物理语言："剑势劈落带起气流掀动衣摆""落地下沉缓冲单膝微屈"。

## 模板示例（S 级压场爆发 · 首尾帧）

```prompt
首帧=图1（@林烬立于@玄天宗比武台中央持剑静立），尾帧=图2（@林烬剑指前方、衣袂上扬定格）。
主体：黑衣长发@林烬；运动：镜头低角度快速推近的同时，他右手提@焚天断剑自下而上划出弧线，剑身暗红纹路亮起，气流掀动衣摆与马尾，最终定格剑指前方，落地步伐沉稳下沉（符合重力与惯性）；场景：青石比武台、四角符文石柱微光、远处云海山岳与围观人群静立；镜头语言：低角度推近，冷青蓝主调天光，体积光柱随剑势亮起，剑气银白高光，压迫威严氛围，@画风锁+冷青蓝主调剑气银白高光，16:9，5秒
```

## 正反例

✅ 正确：首尾帧双图声明 + 运动只写"中间过渡" + 物理语言（重力惯性）+ 幅度与差异匹配。
❌ 错误：首尾帧几乎相同却写"快速环绕运镜"（差异小幅度大→运镜不执行）；Prompt 复述首帧静态外貌 50 字（浪费过渡运动描述，V2 扣分）。
