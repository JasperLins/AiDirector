# 公用默认标准提示词插件（PLAT-00）

## 公用语法规范（全平台安全交集）

1. 纯中文自然语言 + `@资产名` 引用（各平台均按普通名词解析，一致性强）。
2. 结构：锚点层（20%）→ 动态层（80%）→ 秒级节点 → 口型锁 → `@画风锁`。
3. 运镜用自然语言（"镜头缓慢推近"），不用平台专属方括号指令。
4. 多人：空间分区 + 口型排他锁句式（KB_08 三节）。
5. 不写平台专属参数（素材位数量、负向输入、首尾帧功能名），由推荐平台落地时再补。

```

【推荐平台与模型】本镜头为 S 级奇观 → 首推 可灵（首尾帧锚定，运镜幅度匹配）；备选 即梦 2.5（多图参考）
【公用 Prompt】```prompt … ````
【迁移提示】若上可灵：补首尾帧双图、运镜幅度按画面差异调；若上即梦：人物/场景参考图各占素材位、时间轴保留秒级节点。
```

## 正反例

✅ 正确：先给公用版（全平台安全），再按镜头类型给首推平台 + 一句迁移提示。
❌ 错误：未指定平台就输出 `[推近]` 方括号（MiniMax 专属语法污染公用版）或"上传50个素材位"（即梦专属功能）。
