# 即梦 Seedance 平台插件（PLAT-02）

## 平台语法特征（核实版）

1. **结构化公式**：`主体（外貌+服装）+ 动作序列 + 镜头语言（推/拉/摇/移/跟随/环绕）+ 视觉风格 + 约束条件`。
2. **多模态参考**：人物图、场景图、道具图上传素材位（2.5 版最多 50 个），Prompt 中用 `@资产名` 与对应素材绑定（本框架纯中文命名在素材位命名与提示词间天然对齐）。
3. **秒级时间轴**：官方支持 `[0-4秒]…[5-10秒]…` 分段，单条最长 30 秒；短节点照写 `[00-02s]` 也兼容。
4. **原生音画同出（模式A 首选）**：写明台词文本+语气+张嘴动作即直出带口型对白；多人必须口型排他锁。
5. 约束条件可写："保持人物外观与参考图一致""背景与场景参考图一致"。

## 编译调整（相对公用版）

- 素材位规划清单前置输出：`素材位1：@李梅全身立绘 ｜ 素材位2：@张三全身立绘 ｜ 素材位3：@光大街边空镜`。
- 时间轴用"秒"字格式 `[0-3秒]`；台词以引号内嵌并标注语气。
- 结尾加一致性约束句："人物与场景外观全程与参考素材保持一致"。

## 模板示例（例子1镜头1 · 模式A）

```prompt
素材位1：@李梅全身立绘；素材位2：@张三全身立绘；素材位3：@光大街边空镜。
黄昏@光大街边街道，画面左侧三分之一为成年女性@李梅（米白针织开衫，身高约一米六五），右侧三分之二为孩童@张三（天蓝小熊耳卫衣，身高约一米一），两人牵手间距一臂前行。[0-1秒]远景镜头缓慢推近，@张三仰头拽动母亲衣角，梧桐树影斑驳、美食摊白雾轻晃；[1-3秒]@张三抬头张嘴说话，嘴唇随台词自然开合："妈妈，我要吃莽莽"（奶声奶气、尾音拖长、渴望语气）；一旁的@李梅保持双唇闭合、嘴角含笑低头倾听，不发一言。人物与场景外观全程与参考素材保持一致，@画风锁+暖金橙主调黄昏柔焦光晕，16:9
```

## 正反例

✅ 正确：素材位清单 + 分区 + 时间轴（X秒）+ 台词语气 + 倾听者闭嘴锁 + 一致性约束句。
❌ 错误：不传参考图却要求"和上一镜长得一样"（即梦一致性来自素材位，不来自祈祷）；50 素材位全塞满（权重失衡串色，人物 2 + 场景 1 + 道具 1 为宜）。
