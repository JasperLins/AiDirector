# 大香蕉 / Nano Banana 平台插件（PLAT-07）· 工业级完整版

## 一、核心职责与工业级法则（6 条硬核铁律）

1. **镜像防御铁律（实测最痛弱项置顶）**：本平台存在**左右镜像风险**（实测泪痣疑似翻转到对侧）——方位一律用"画面左侧/右侧"**绝对方位**（KB_08 八节2）；关键单侧特征（痣/疤/梨涡/单耳坠）生成后**肉眼终审左右，镜像即整张重抽**（镜像图裁切救不回来）；单侧特征至少两个时，抽卡选优标准里左右终审置顶。
2. **纯自然语言正向排他铁律**：无独立负向框——内容否定一律转**正向排他**（"双手空无一物""其余肌肤光洁无瑕"），严禁正文"不要X"堆砌（粉色大象效应）；版式控制不得占用句首权重位、正文严禁"设定集/多视图/分格/画中画"字眼（同样触发粉色大象）——版式一律由第②层正向构图锚定（`单人全身居中立像`）承担，首句保留给 `PACK-XX` 维度①媒介声明（R9-20261005-17）。
3. **规格外道具排他铁律**：实测无指令自添折扇/配饰——人物资产图**必写**`双手空无一物`（或显式持物清单三要素复述：`右手执一柄湘妃竹骨折扇，扇面收拢`）；背景元素写`画面中无其他陈设道具`。
4. **数量量化铁律**：离散特征数量控制不稳（实测"三两点"雀斑出 8~10 颗）——凡离散特征必写**显式数量+硬上限**（"疏落三两点，至多三粒""泪痣仅一枚，别无其他"）。
5. **复杂纹样垫图补强铁律**：蟒纹/云锦类复杂纹样本平台最弱（实测蟒纹缺失变云纹）——纹样类任务**必带参考垫图**（ChatGPT/豆包版构图参考）＋文字三要素复述（"蟒纹暗绣盘绕全身清晰可辨"）；无垫图则改道 ChatGPT/豆包。
6. **气质与材质强物理句铁律（本平台最强项，值得写满）**：气质拿捏三平台最准（实测 15 岁侍女稚气/怯懦忠心眼神最佳）、玉质感与微光物理感最强——气质词直给（4.2 词表）、材质态用**强物理比喻句**（4.3 句库），抽象形容词（"有气质""质感好"）一律禁用。

## 二、标准执行 SOP（Step-by-Step）

**Step 1 · 读入初稿**：取 KB_08 编译初稿＋注册表记忆点摘要；**标注单侧特征清单**（镜像风险项）与纹样复杂度（垫图需求）。

**Step 2 · 挂镜像防御**：全部方位绝对方位化；单侧特征挂数量硬上限（铁律1/4）。

**Step 3 · 负向转正向**：负向包逐条转排他句——多指→"五指自然并拢分明"；自添道具→"双手空无一物"。

**Step 4 · 气质与材质升格**：按 4.2/4.3 把气质与材质层替换为直给气质词+强物理句（如"玉质感好"→"玉质温润半透，缝隙深处透出细如发丝的暗红辉光，如余烬"）。

**Step 5 · 纹样垫图判定**：蟒纹/云锦/错金类→必挂垫图声明+三要素复述；素面/浅纹样→直出。

**Step 6 · 规格挂锁与抽卡建议**：末尾挂 @画风锁（展开纯文本，题材身份词保留）＋画幅＋分辨率；盯片顺序=**单侧特征左右终审（置顶）→ 纹样存失 → 规格外道具 → 数量越界**。

## 四、专项工具箱

### 4.0 实测画像（E01 七资产 × 20 图对照 · R9-20261005）

- **强项**：**气质拿捏三平台最准**（15 岁侍女稚气/怯懦忠心眼神最佳，E01 杏儿基准图）；**玉质感与微光物理感最强**（缝隙内发丝状暗红辉光唯一稳定呈现）；雀斑等浅色细微特征形态正确。
- **弱项**：**左右镜像风险**（泪痣疑似翻转到对侧——方位一律绝对方位+肉眼终审）；**复杂纹样最弱**（蟒纹缺失变云纹）；**规格外道具冗余**（无指令自添折扇）；数量控制不稳（"三两点"雀斑出 8~10 颗）。
- **定位**：气质定调、材质与发光态参考、多轮编辑修图首选；复杂纹样场景避开或垫图补强。

### 4.1 镜像防御与绝对方位语法

**结构模板**：
```text
[媒介前置·PACK-XX维度①] + [表情前置短句+正向构图锚定（单人全身居中立像等）] + [方位全部绝对方位化] + [单侧特征三要素+硬上限] + [成对/对称特征显式声明] + [@画风锁展开] + [规格]
```
- 绝对方位词表：`画面左侧 / 画面右侧 / 画面左前景 / 画面右后景纵深处 / 中轴线上`——禁"她的左手边/身体左侧"（生成端左右手定义与人类直觉相反时必镜像）。
- 单侧特征模板：`画面[左/右]侧[锚点]+[形态]+仅一枚/一道，别无其他`。
- 对称特征显式声明：双眼/双耳坠类写"左右对称各一枚"——不写则可能单边化。
- **终审流程**：出图后第一眼先查单侧特征左右→对镜像零容忍，整张重抽（局部翻转修图会引入新的形变）。

### 4.2 气质定调词法（本平台最强项）

气质不写形容词堆砌，写**"气质词+神态锚点+视线/微表情"三件套**：

| 气质目标 | 直给气质词 | 神态锚点 |
|---|---|---|
| 稚气怯懦（幼齿侍女） | 十五岁稚气脸型、怯懦忠心 | 眼睛微微低垂、双手交叠于腹前、欲言又止抿唇 |
| 清冷疏离（仙门师姐） | 清冷出尘、眉目疏淡 | 平视远方、唇线平直、下颌微抬 |
| 市井烟火（老板娘） | 泼辣爽利、眉眼带笑 | 眼尾上挑、嘴角一侧含笑、叉腰 |
| 少年英气（小将） | 英气挺拔、锋芒内敛 | 剑眉入鬓、直视镜头、肩背挺直 |

**用法**：气质词 2~3 个为限（多则互相稀释），配 1~2 个神态锚点动作；实测本平台对"年龄感"执行最准（15 岁稚气不跑成 20 岁）——年龄写具体数字+头身比（"十五岁，约一米五二，头身比一比六"）。

### 4.3 材质与发光态强物理句库

| 材质目标 | 强物理句（直用） |
|---|---|
| 玉质微光道具 | `玉质温润半透，边缘薄处透光，缝隙深处透出细如发丝的暗红辉光，如余烬` |
| 鎏金做旧 | `鎏金表面温润斑驳，磨亮处映烛光成一点暖黄光斑` |
| 精钢寒光 | `剑身打磨如镜，寒光沿刃口一线流淌，映出模糊人影` |
| 烛焰氛围 | `烛焰豆大，焰心一点亮白，四周晕开暖黄光圈，在墙面投出摇曳浅影` |
| 粗棉麻织物 | `粗棉麻纹理清晰可辨，肘部磨得发亮，衣摆两处补丁针脚细密` |

**写法规则**：材质句必含**光源逻辑**（光从哪来、落在哪、什么形状的光斑）——本平台物理感执行强，"玉质感好"这类抽象词是对强项的浪费。

### 4.4 排他与数量上限句库

| 风险 | 排他/量化句 |
|---|---|
| 自添折扇/配饰 | `双手空无一物`；持物时 `右手执一柄湘妃竹骨折扇（扇面收拢），左手空无一物` |
| 雀斑/痣点失控 | `雀斑疏落三两点，至多三粒，集中于鼻梁两侧`；`泪痣仅一枚，别无其他` |
| 多余陈设 | `背景纯色无接缝，画面中无其他陈设道具` |
| 多指 | `五指自然并拢分明` |
| 正脸人群 | `街市行人疏落五六人，全部背身或侧身剪影，无正脸` |

### 4.5 多轮编辑修图工作流（对话式迭代）

1. **母版定稿**：首轮出图过四项盯片（左右/纹样/道具/数量）后定母版。
2. **单变量迭代**：`在上一张基础上，只将[材质/微光强度/持物]改为[新状态]，其余保持原样`——道具剧情态迭代（素戒→微光戒→认主纹路亮起）是本插件最佳场景。
3. **每轮终审**：单侧特征左右复核置顶；材质态变化不牵动五官（牵动即回退）。
4. **跨平台迁移**：本平台气质定调图作为他平台的**气质参考垫图**；本平台吃垫图时纹样类必带（铁律5）。
5. **定稿归档**：剧情态变体登记注册表为同一资产的剧情态，不新开资产。

## 五、常见错误示范 vs 满分工业级示范

### 对比组 1：单侧特征与数量

❌ **Bad Case**：
> 一个可爱的小侍女，脸上有雀斑和一颗泪痣，戴一枚玉戒指，很有气质，画质高清。

**扣分点**："脸上有"未绝对方位（镜像高危）；雀斑无上限（实测外溢到 8~10 颗）；"一枚"无"别无其他"封口；"有气质"抽象词浪费本平台气质强项；未声明双手（自添折扇风险）。

✅ **Good Case**：
```prompt
国风仙侠漫剧插画，二维国漫工笔厚涂画风；神情怯懦中带忠心，侍女低调拘谨，单人全身居中立像：平视胸像构图，少女杏儿居中占画面三分之二：十五岁及笄少女，五官已长开、四肢纤长已抽条的亭亭少女身形，约一米五二头身比一比六，圆润杏眼微微低垂含怯意，欲言又止轻抿唇；雀斑疏落三两点至多三粒，集中于鼻梁两侧；画面右侧外眼角一枚针尖大小浅褐色泪痣，仅此一枚，别无其他；双手交叠于腹前五指自然并拢分明，双手空无一物；素青粗棉麻襦裙纹理清晰可辨，肘部磨亮；仙侠唯美漫剧质感，新中式工笔厚涂，肤若凝脂衣袂仙气流转，8K高清，16:9，4K
```

### 对比组 2：材质微光

❌ **Bad Case**：
> 一枚古老的玉戒指，很有神秘感，微微发光，材质高级。

**扣分点**："微微发光"无光源逻辑与形态（物理感强项全浪费）；"神秘感/高级"抽象空洞；无辉光位置（缝隙？表面？）。

✅ **Good Case**：
> `一枚古朴饕餮纹玉戒特写：蜜黄玉质温润半透，边缘薄处透光；纹路凹槽深处透出细如发丝的暗红辉光，如余烬将熄；戒身内圈一道细金线包边，磨亮处映出一点暖黄光斑；深色绒布衬底，浅景深虚化`。

## 六、边界情况处理（Edge Cases）

1. **复杂纹样任务（蟒纹/云锦/错金）**：无垫图直出必缺失（实测蟒纹→云纹）——必挂 ChatGPT/豆包参考垫图+纹样三要素复述；垫图后仍失真则整单改道 ChatGPT（蟒纹可辨认档）。
2. **镜像已发生**：单侧特征翻边即整张重抽（禁局部修图——Inpainting 翻转区会造新形变）；连续 2 次镜像→该资产改道 ChatGPT 出基准，本平台转做气质参考。
3. **竖屏（9:16）立绘**：三层纵向叠压（前虚化—中主体—上留白）+`全身完整入画，头顶脚下各留白一成`；立绘防拼图＝首句媒介声明+第②层正向构图锚定（`单人全身居中立像`），禁句首负向版式锁（已废除，R9-20261005-17）。
4. **多人同框**：象限分区+身高差+服装色差三重锚定（同豆包象限句式）；倾听者显式`双唇闭合不发一言`（口型排他锁补丁1）。
5. **数量特征全灭（雀斑一颗都没有）**：升格形态描写（"鼻梁两侧浅褐色小雀斑隐约可见"）+再抽；仍无则接受素颜版，雀斑改后期或放弃该记忆点（浅层记忆点可协商降级）。
6. **气质定调跨平台复用**：本平台定调图作为全局"气质锚"垫图供他平台参考时，Prompt 中声明`人物气质与神态参考所附图片，五官与记忆点以文字复述为准`——防气质图反向污染五官锁定。
