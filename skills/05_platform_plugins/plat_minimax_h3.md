# MiniMax 海螺 H3 平台插件（PLAT-04）

## 平台语法特征（核实版）

1. **多模态统一（T2VA / I2VA / 首末帧）**：单模型同时预测视频帧与 32kHz 立体声音轨——对白、音效、音乐可同出（模式A）。
2. **方括号运镜指令**（置于句首或对应节点前）：`[推近]` `[拉远]` `[左移]` `[右移]` `[上摇]` `[下摇]` `[环绕]` `[固定]`。
3. **微表情递进语法**：按时间轴写面部变化链（KB_02 五节词典），H3 对细腻微表情的执行度是各平台之最。
4. **参考模式（Reference Mode）**：素材标记 + 保留标记词，六栏位结构（主体参考/动作/时间节拍/声音设计等）。
5. 参考素材绑定：`@资产名` 与上传参考图对应，保留标记词声明"保持@资产名面部与参考一致"。

## 编译调整（相对公用版）

- 运镜层替换为方括号指令 + 幅度副词（"[推近]缓慢"）。
- 动态层优先安排"微表情链"作为主动作（H3 特长）。
- 声音设计栏显式写：台词（语气）/环境音/音效（模式A）。
- 眨眼规范写入（崩坏15）："眨眼频率自然，约三秒一次轻微眨眼"。

## 模板示例（微表情情感镜头 · 模式A）

```prompt
[固定]近景，@李梅面部特写参考图，保持@李梅面部与参考一致，眨眼频率自然约三秒一次轻微眨眼。[00-02s]她先弯眼含笑望向画外下方的孩子，嘴角上扬；[02-04s]说到"等爸爸"三字时眼神先亮起随即轻轻垂下，睫毛颤动一次，嘴角笑意未消但微微收拢，轻声说："张三，上次我们才吃了，等爸爸回来给你买"（温柔轻叹、语速4字/秒、"等爸爸"前轻换气）；[04-05s]抬手入画抚向孩子头顶（手部仅入画至腕部，五指自然并拢）。环境音：黄昏街道市井嘈杂低鸣+远处炒菜声；@画风锁+暖金橙主调黄昏柔焦光晕，16:9
```

## 正反例

✅ 正确：`[固定]` 单运镜 + 微表情链按秒递进 + 眨眼规范 + 声音设计栏 + 手部防崩（腕部截断+五指并拢）。
❌ 错误：方括号叠三个运镜（`[推近][环绕][拉远]`连用，V9 扣分且 H3 执行混乱）；微表情写成"她很感动"（心理描写不可生成）。
