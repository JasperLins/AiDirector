# 分镜前置资源策划技能（IMG-02）· 工业级完整版

## 一、核心职责与工业级法则（8 条硬核铁律·R9-20261006 增第 8 条）

1. **等级决定资源铁律（2026-10-18 回滚重订·单镜默认制）**：S 级=**分镜图（首帧）+尾帧设计图**双锚；A 级=分镜图单锚；B 级=超高清静态图 1 张（不生成视频，后期关键帧缓推动态）。**实验路径⑤（段级直出）用户明示启用时**：S/A 级分镜图即段内区间锚图（S 级加强精出+抽卡预算上浮）。等级与资源错配（S 级缺尾帧 / B 级出双图）一律退回重规划。
2. **分镜图对表铁律（原"首帧即首秒"·R9-20261010-18 更名）**：分镜图的景别/机位/构图必须与分镜表逐字对齐（默认单镜 I2V 时该图即视频第一秒画面；实验路径⑤段级直出时该图为对应时间区间的画面锚），人物挂单人参考图（立绘/面部特写），三视图整图禁止入位（VIS-03 防呆）。
3. **同源双图铁律**：首尾帧两张图必须同光源、同色温、同画风——尾帧只改变"动作顶点状态+运镜推进量"，其余逐字复用首帧 Prompt；可灵的运镜幅度匹配前提就是两图差异可控。
4. **动态范围防护铁律**：分镜图（首帧）禁止强逆光/大面积高光/纯剪影（崩坏10 视频过爆放大器）；光学层必写"高光不过曝、保留面部细节"。
5. **成对出图铁律**：过肩正反打的两张首帧必须同批次成对生成（同 Prompt 仅换越肩方向），防对白正反打色温跳变；单张抽卡合格后再补拍另一张=废片率高发区。
6. **序列同源垫图铁律（R9-20261007-16 重订，原"垫图省抽卡铁律"废止）**：同场次 ≥3 个连续镜头且构图变化小 → 必须先做**双通道选道评估**并在生产单留痕（A-1 宫格通道：模型强/该平台宫格实测通过 → 4.3 宫格一次生成；A-2 逐镜序列通道：弱模型默认/宫格两轮废片 → 4.4 逐镜满分辨率生成）——**跳过选道评估的任何通道选择均=流程违规打回**。A-2 通道的合法性建立在**三重序列约束**之上（每镜同源垫图：图1 人物主图@资产+图2 场景机位库对应格/空镜基准；全序列同源：@画风锁+@光位常量逐镜挂载；相邻镜渐变关系声明），**裸逐镜（无垫图/无序列约束/无生产单）仍是违规**——防的是无总控抽卡，不是逐镜通道本身（立法背景：弱模型宫格质量差·黑名单 39）。
7. **生图策略行与场景锚点铁律**（R9-20261005 新增）：每条首帧/尾帧 Prompt 落盘时必须同步附"**生图策略**"行——底图@来源（I2I 权重）｜人物参考@来源（参考位权重）｜特殊处置（无锚理由/首帧级资产直出回填等）；已注册场景必须以"@场景名"锚点进入 Prompt 文本（不得降级为纯自然语言描写），并以该场景空镜基准/全景图作 I2I 底图——首帧级新场景除外，须显式注明"文生图直出后回填注册表"。缺生图策略行或 @场景锚点丢失 → 视为资源策划未完成，SOP Step 6 送检前自查退回，禁止交 R7。

8. **双机位基准与中帧关键帧铁律（R9-20261006 · R3 契约/KB_08 五节承诺落地）**：①核心场景（主角居所/主城街道等高频场景）策划时必须配套**双机位基准图**——俯瞰全景基准（宏观环境）+平视/低机位基准（人物对话与特写垫图），防补丁7 垫图透视冲突；已建**场景机位库**（R9-20261006-6）的场景，分镜机位与两基准图冲突时**先查机位库**——命中近似机位子图即垫图（裁切图须已补高清），无匹配才卸垫图盲抽；②一镜到底三段管线（R 段接力）的前置资源必须含**中帧关键帧**（首帧同源改三点法产出，改三点=动作中间态/机位中间位/光影中间档），中帧锚是三段接力的成立前提（VID-02 接力链调和铁律）。
9. **一镜到底资源执法三查铁律（R9-20261006-13 立 · 20261007-14 执法主体升级：R10 分镜图总控为三查 Owner，R5 执行自查，R7 复核——立法背景：E02 四个 S 级镜全部漏尾帧、10 秒镜建立在未实测的平台假设上被全链路放行——One-Take First 只进了分镜表没进资源清单，黑名单 38；2026-10-18 回滚恢复单镜默认口径）**：每集资源策划落盘前强制三查（**R10 生产单三查核验单主责**+R5 执行自查+R7 复核，任一不过打回）——**①S 级双锚查**：每个 S 级镜必须"分镜图+尾帧设计图"双锚齐备（4.2 同源改三点法），缺尾帧=资源未完成禁止送检；**②时长假设查**：超过平台常见上限（5s）的一镜到底镜，必须先实测该平台时长上限再定"单镜直出 vs R 段接力"——禁止以"平台应该支持"跳过实测（证据位阶铁律·AGENTS 〇节9），接力镜须预列中帧锚产出计划（实验路径⑤的段直出上限按 KB_14 五节附首跑留痕校准）；**③运镜渐变评估查**：S/A 级镜的视频运镜禁默认单运镜（"固定/固定微推"保守式为旧防崩哲学残余，黑名单 139 已废止）——每镜评估"缓推→上摇/焦点转移（前景道具→面部）/跟随移动"等连续渐变是否适配本镜叙事，不适配者显式标注"固定机位=叙事选择"留痕。**附：机位库双用途（R9-20261006-13）**——场景机位库子图除作垫图弹药外，可作一镜到底长镜的多图参考关键帧锚（R6 首尾帧/多图参考技法的轨迹锚点：镜头在长镜内从机位A视角渐变至机位B视角，用两机位图锁运动轨迹）。

## 二、标准执行 SOP（Step-by-Step）

**Step 1 · 读入定资源**：读分镜表行（等级/景别/机位/构图/时长/@资产/台词）；按铁律 1 定资源清单（S 双图 / A 单图 / B 静态）。

**Step 2 · 路由技法**：过 IMG-01 决策树得技法组合（底图选择+锁脸手段+ControlNet 需求），写"生图技巧策划说明"。

**Step 3 · 编译分镜图**：按 `KB_08` 生图全量公式八层编译（主体/服饰/动作/空间/环境/光学/镜头/画风+规格），景别机位构图逐字对齐分镜表；多人镜头挂 KB_07 空间分区句式。

**Step 4 · 编译尾帧**（仅 S 级）：复制分镜图 Prompt，只改——动作顶点描述（剑指前方定格/相拥瞬间）、运镜推进后的景别变化、可强化的氛围（光柱落台/雨落），光源色温逐字不动。

**Step 5 · 垫图评估**（多镜连拍时）：先查该场景机位库子图可垫性（补丁7 冲突镜按 R9-20261006-6 查询顺序）；再按铁律 6 做**双通道选道评估**并在生产单留痕——A-1 走 4.3 流程策划 2x2/3x3 连贯分镜宫格垫图（列"格位分配表"，编译宫格 Prompt）；A-2 走 4.4 逐镜分镜序列规范（三重序列约束+分镜图登记表）。

**Step 6 · 一致性保障与送检**：写同源保障措施（成对出图/尾帧复用句/宫格裁切规范）；全部 Prompt 送 R7 维度核查（KB_10 八层表），8/8 全过交用户跑图，并留"交 R6 备注"（分镜图即视频第0秒画面（实验路径⑤时=段内时间轴区间锚图）/尾帧用于可灵锚定）。

### 4.3 多宫格连贯分镜垫图策划流程与模板

**适用判定**：同场次 ≥3 连续镜 + 构图变化小（同机位族/同景别族）+ 时长均 ≤5s → 用宫格垫图；跨场次/景别跳级大（远→特写）不适用。

**策划流程**：
1. **格位分配表**：把镜号映射进宫格（2x2 四格 / 3x3 九格），标注每格的"构图差异增量"（人物位置/朝向/前景元素微调）。
2. **统一基准**：所有格共享——场景三层、光源色温、画风锁；仅变——格内主体姿态/朝向/局部前景。
3. **编译宫格 Prompt**（模板如下）。
4. **逐格裁切**：宫格图生成后按格裁切为独立分镜图（4K 宫格裁后单格 ≥1080p 达标）；裁切图回填 IMG-01（补高清重绘 0.3）。
5. **一致性红利**：同源宫格裁切的连续分镜图，视频生成后镜头间空间延续性显著高于独立抽卡。

**宫格模板（2x2 · V2 极简式·R9-20261006-12 连坐修订，复用 plat_01 六节 10 宫格极简版式铁律——复测④教训连坐：旧"左上格[镜N]…"式格位绑定+长模板与本技能同病）**：
```prompt
[媒介前置]；2x2组图，参考图中的@[场景名]同一机位族的四个连续瞬间——[瞬间A主体状态4~12字]、[瞬间B增量]、[瞬间C增量]、[瞬间D增量]（每条只写主体姿态/朝向/前景微调，禁量化构图锚）；四格同光源同画风，风格与参考图一致；16:9，4K
```
*执行要点（V2 修订）：①**机位/瞬间用开放式顿号列表、禁绑格位编号**（格位绑定实测无效——模型做不了标签→格位映射）；②**文字只管"版式+瞬间状态"**——场景/光源/画风交参考图（垫机位库子图或场景空镜基准）；③人物一致性另挂人物参考图（多图融合：图1=场景参考·机位库对应格或空镜基准，图2=人物主图）；④**成图后按实际内容回填格位分配表**（哪格是哪镜看图登记，剪辑顺序由镜号决定，不赖格位）；⑤全文 ≤150 字。*

**格位分配表格式（成图后登记，非 Prompt 绑定）**：
| 格位（成图后看图填） | 镜号 | 构图增量 |
|---|---|---|
| 看图登记 | 镜5 | 基准：母左子右中景行走 |
| 看图登记 | 镜6 | +推近半档，子转头仰视 |
| 看图登记 | 镜7 | +前景灯串入画一角 |
| 看图登记 | 镜8 | +母低头含笑，子停下 |

**与场景机位库宫格的边界（R9-20261006-6 · 两套宫格禁止混用模板）＋双层管线（R9-20261006-12 立）**：本节宫格的格位＝**时刻**（同机位族连续瞬间，时间轴，服务连续分镜首帧）；场景机位库宫格（VIS-03 三件套③ / KB_06 母版⑧）的格位＝**机位**（同场景不同视角，空间轴，服务跨分镜垫图弹药库）——前者格间变"动作增量"，后者格间变"视角"且全格同刻同光位、无人物。**两套为双层串联管线而非二选一**：先建机位库（空间轴·生产资料）→ 连续镜组分镜宫格**垫机位库对应子图**生首帧（时间轴·同源构图延续）→ 逐格裁切→I2V。垫图查询顺序（补丁7 冲突镜）：先查机位库子图 → 命中即垫（裁切图须已补高清 0.3）→ 未命中才卸场景垫图纯文本盲抽＋负向机位约束。**执法注记（R9-20261006-12 立·R9-20261007-16 修订）**：铁律 6 为强制评估项——同场次 ≥3 连续镜且构图变化小（如 E02 正门系过肩组/正反打组）未做双通道选道评估直接裸逐镜抽卡＝流程违规打回。

### 4.4 逐镜分镜序列生成规范（A-2 通道 · R9-20261007-16 立）

**适用判定**：同场次 ≥3 连续镜 + 构图变化小 + **弱生图模型 / 该平台宫格两轮废片 / 竖屏剧集 / 需要实验路径⑤分镜图满分辨率**——SBM-01 生产单路由 A-2 后由本节执行。

**与 A-1 的分工**：A-1 用"一次生成多格"换同源与省抽卡，代价是单格分辨率摊薄且弱模型格间质量失控（实测三连败·黑名单 37/39）；A-2 用"逐镜满分辨率"换单图质量，跨镜一致性改由**三重序列约束**保证——两通道平级，按模型能力分流（选道理由留痕生产单）。

**三重序列约束（缺任一=序列未完成，禁交 R7）**：
1. **每镜同源垫图**：每镜独立 Prompt 各挂——图1=人物主图@资产（单人立绘/面部特写，三视图整图禁入位）＋图2=场景参考·机位库对应格或空镜基准（垫图机位按补丁7 三分法决策：同档垫/宫格指定格垫/裁格垫/卸垫盲抽）——**人物与场景同图生成，占位天然匹配场景**（解决"人物占位与场景不符"）。

## 五、常见错误示范 vs 满分工业级示范

### 对比组 1：首帧策划

❌ **Bad Case**：
> 镜头4 前置资源：生成一张李梅在街上的图片，最好是黄昏，好看一点，人物清晰。平台随便，出来直接用。

**扣分点**：无空间分区（过肩构图谁前谁后？）；无"高光不过曝"防护（黄昏逆光高危）；无参考图挂载（人物必漂移）；无同源保障（与镜2色温跳变）；"好看一点/随便"不可验收。

✅ **Good Case**：
> **策划说明**：图生图（@光大街边空镜底图，重绘 0.4）+ IP-Adapter（@李梅立绘 0.7 锁脸）+ OpenPose 0.6（垂眸+右手抬至胸前骨架）；与镜 2 成对同批出图防色温跳变。
> **Prompt**：`过肩镜头分镜图：越过孩童@张三的右肩与后脑（画面右下角虚化剪影，天蓝卫衣帽可见）拍摄成年女性@李梅：@李梅位于画面左侧三分之二，[骨相+套装]…右手刚抬至胸前…黄昏金橙色温柔和平射光，高光不过曝保留面部细节…@画风锁+暖金橙主调黄昏柔焦光晕，16:9，4K`——9.3 分放行。

### 对比组 2：分镜序列生产（R9-20261007-16 重订）

❌ **Bad Case（裸逐镜——注意：违规的是"裸"，不是"逐镜"）**：
> 镜5~8 每个镜头单独生成一张首帧图，各自写一遍完整提示词，参考图随手挂，多抽几次卡总能对上。

**扣分点**：四张独立抽卡=四套独立空间解读，镜头间墙面/摊位/灯串位置各画各的，剪辑时空间跳跃；抽卡成本 4 倍；**违反铁律 6**（未做双通道选道评估、无三重序列约束的裸逐镜）。

✅ **Good Case A（A-1 宫格通道，模型强时）**：
> 判定镜 5~8 同场次同机位族（中景行走+微推）且平台宫格实测通过 → 2x2 宫格垫图：左上基准（母左子右行走）→ 右上（+推近半档子转头）→ 左下（+前景灯串一角）→ 右下（+母低头子停步）；统一黄昏金橙与三层环境；生成后逐格裁切+补高清 0.3 → 四张同源首帧，空间延续性一次锁定。

✅ **Good Case B（A-2 逐镜序列通道，弱模型时·R9-20261007-16）**：
> 同为镜 5~8，目标生图模型弱（宫格两轮废片）→ 生产单留痕选道 A-2 → 逐镜满分辨率分镜图 Prompt×4，每镜垫"图1=@李梅主图+图2=机位库对应格"、光学层与画风层四镜逐字相同、序列登记表声明相邻镜渐变增量（行走→推近→灯串入画→停步）→ 四张分镜图交 R10 视频段分组/实验路径⑤——单图质量最优，跨镜一致性由三重序列约束锁定。

## 六、边界情况处理（Edge Cases）

1. **首帧含 ≥3 人**：禁止单图直出（串脸高危）——拆"主双人首帧（分区句式）+ 第三人后期贴入（剪映画中画）"或改分镜为反应 Cutaway 递补第三人存在感。
2. **首尾帧差异过大（S 级大幅动作）**：两图差异超出"改三点"范围（如全景→特写）→ 放弃首尾帧锚定，改"首帧 I2V + 尾帧弃用 + 剪辑切镜"方案，并通知 VID-02 改技法预选。
3. **竖屏（9:16）首帧**：宫格垫图改用"1x4 竖排条"（各格 9:16）或 2x2 正方形内留竖向安全区；首帧单独出图时画幅字段写 9:16 且构图过 VIS-01 的 4.3 转换表。
4. **B 级静态图的高清要求**：静态图承担"放大 108% 缓推"余量，分辨率必须 4K（裁切后局部仍 ≥1080p）；不足时 IMG-01 补高清（重绘 0.3）。
5. **场景无空镜基准图**（新场景漏产）：先回 VIS-03 补两件套再策划前置资源——禁止"拿别人镜的首帧当底图"（误差累积漂移）。
6. **接力镜（Tail-to-Head）的首帧**：不新出图——直接取上一镜生成视频尾帧 + 高清修复/Inpainting 微调（改衣摆角度/光斑位置），本技能只出"尾帧修复指令单"交 IMG-01 执行。
