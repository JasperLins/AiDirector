# 分镜前置资源策划技能（IMG-02）

## 执行步骤

1. **按镜头等级定资源**：
   - S 级：首帧基准图 + **尾帧设计图**（首尾帧双锚定）
   - A 级：首帧基准图（单锚）
   - B 级：超高清静态图单张（后期关键帧缓推，无需视频）
2. **首帧基准图编译**：KB_08 生图全量公式，但光学层允许轻光影（与成片一致的光位与色温）；构图/景别/机位与分镜表逐字对齐；人物挂面部特写/立绘参考（三视图先裁切，KB_06 四节防呆）。
3. **尾帧设计图**（S 级）：描述动作顶点帧（剑指前方定格/母子相拥瞬间），与首帧同光源同色温，供可灵首尾帧锚定。
4. **多宫格垫图**：同场次连续 4 镜构图变化小 → 2x2 垫图一次生成 → 逐格裁切为首帧，省抽卡且构图延续。
5. **过肩/正反打成对出图**：越 A 肩拍 B 与越 B 肩拍 A 两张同光源成对生成，防止对白正反打色温跳变。
6. **动态范围控制**：I2V 首帧避免强逆光/大面积高光（崩坏10），写"柔和侧逆光、高光不过曝、保留面部细节"。
7. 产出前置生图 Prompt（代码块）→ 送 R7 评分 → ≥9.0 交用户跑图。

## 输出格式

```
【生图技巧策划说明】镜头等级…｜资源类型：首帧[+尾帧]｜技法：…（IMG-01路由）｜参考图：@资产裁切图｜平台推荐：…
【前置生图 Prompt】```prompt … ````
【评分】R7 执行
```

## 正反例

✅ 正确：镜头3（过肩）先出"越@张三右肩拍@李梅"首帧图，图生图重绘 0.35 挂 @李梅立绘参考，光学层"黄昏金橙侧逆光不过曝"。
❌ 错误：直接把三视图整张喂视频模型当首帧——三视图被识别为三人同框，复制人+乱张嘴（KB_06 防呆红线）。
