# 生图技法路由器（IMG-01）· 工业级完整版

## 一、核心职责与工业级法则（6 条硬核铁律）

1. **先路由后写词铁律**：任何生图任务在写 Prompt 前必须先过本路由决策树确定技法组合——技法决定参考图挂载与参数，参数决定 Prompt 里哪些层要写哪些层省略（图生图低重绘时静态层可简写）。
2. **重绘幅度安全铁律**：图生图重绘幅度（denoising strength）锁定 0.3~0.45 区间——低于 0.3 改不动，高于 0.45 换脸漂移；要大改就换技法（ControlNet），不要硬拉重绘。
3. **保人优先铁律**：涉及已注册人物的任务，锁脸手段（LoRA 0.6~0.85 / PuLID 0.6~0.8 / IP-Adapter 0.5~0.7）优先级高于一切风格参数；LoRA 严禁 >0.9（画风僵硬+"塑胶脸"）。
4. **单一控制源铁律**：ControlNet 同类控制只用一个源（姿态就用 OpenPose，别再叠 Canny 钉轮廓除非显式说明权重减半）；多控制叠加时权重各 ×0.7 且总和等效 ≤1.2，互相打架=两头不执行。
5. **最小干预铁律**：只改局部必须用 Inpainting（蒙版圈选，羽化 20~30px，重绘限蒙版内）；用整图重绘修一只手=全图重新抽卡，已过审部分全部作废。
6. **两轮升级铁律**：同一技法改词两轮仍翻车 → 立即升级技法级（见决策树第 5 层失败预案），禁止第三轮同法重试——时间成本高于换法成本。

## 二、标准执行 SOP（Step-by-Step）

**Step 1 · 查表读入**：读 `KB_06` 六节锁脸规范（参考图链与权重）、`KB_09` 四节修正工作流（翻车对号入座）；读入任务输入四要素（目标/保留/改变/参考图清单）。

**Step 2 · 过决策树**：按 4.1 决策树五问逐层路由，得出技法组合结论（可多技法叠加，按铁律 4 控制权重）。

**Step 3 · 填参数区间表**：按 4.2 参数区间表逐项给出数值与理由（如"IP-Adapter 0.7——过肩近景保脸优先级最高"）。

**Step 4 · 列参考图挂载清单**：明确每张参考图（@资产图集内的面部特写/全身立绘/空镜底图）挂到哪个节点、什么权重——**只允许单人参考图入位，三视图/矩阵整图禁止**（VIS-03 防呆铁律）。

**Step 5 · 配负向词包**：从 `KB_09` 三节标准负向包按任务裁剪（生图/视频分用），随 Prompt 交付。

**Step 6 · 交平台与预案**：给出平台落地建议（豆包 Seedream 4.0 / ComfyUI Flux 分工）与失败预案（两轮翻车后的升级路线）。

## 四、专项工具箱

### 4.1 技法路由决策树（五问五层）

```text
Q1 要不要动"形"？（姿态/构图/空间结构）
 ├─ 动形 → Q1a 什么形？
 │   ├─ 姿态/动作 → ControlNet-OpenPose（0.6~0.8）【骨架图先行】
 │   ├─ 空间纵深/机位 → ControlNet-Depth（0.5~0.7）【深度图先行】
 │   └─ 轮廓/边缘（改材质不改形）→ ControlNet-Canny/Lineart（0.5~0.7）
 └─ 不动形，只改"色/光/质" → Q2
Q2 要不要保"人"？（已注册人物入画）
 ├─ 保人 → 锁脸三选一：角色LoRA（0.6~0.85）＞PuLID（0.6~0.8，Flux/SD系）＞IP-Adapter（0.5~0.7，挂单人立绘/面部特写）
 └─ 不保人（纯场景/道具）→ 直接进 Q3
Q3 只改一小块？（换手/去光影/换天/改局部道具）
 ├─ 是 → Inpainting（蒙版圈选，羽化20~30px，重绘仅限蒙版内0.4~0.5）
 └─ 否 → Q4
Q4 要不要先控"明暗布局"再上色？
 ├─ 是 → 灰度图二段式（灰度草图定明暗→上色段重绘0.35~0.45）
 └─ 否 → 图生图（0.3~0.45）或文生图直出
Q5 翻车了吗？（同法改词两轮仍废）
 └─ 是 → 升级路线：改词 → 换控制源(OpenPose↔Depth) → 加锁脸权重+0.05 → 拆单主体分图 → 降级B级静态图+剪映动效
```

### 4.2 参数区间总表（核实版基线）

| 技法/参数 | 安全区间 | 越界后果 | 适用场景 |
|---|---|---|---|
| 图生图重绘幅度 | 0.3~0.45 | <0.3 改不动 / >0.45 换脸漂移 | 微调光影/场景，人物已在底图 |
| ControlNet-OpenPose | 0.6~0.8 | <0.6 姿态不执行 / >0.8 肢体僵直 | 控姿态/双人站位骨架 |
| ControlNet-Depth | 0.5~0.7 | >0.7 画面糊成深度图 | 钉空间纵深/多主体前后层次 |
| ControlNet-Canny/Lineart | 0.5~0.7 | >0.7 边缘生硬描边感 | 改材质不改形（换装/换色） |
| 灰度图二段式 | 灰度→上色重绘 0.35~0.45 | 上色段过高破坏明暗布局 | 强设计感光影构图 |
| 角色 LoRA 权重 | 0.6~0.85 | >0.9 画风僵硬塑胶脸 | 角色专属长相复现 |
| PuLID（Flux/SD） | 0.6~0.8 | >0.8 表情锁死 | 人脸 ID 严格锁定 |
| IP-Adapter | 0.5~0.7 | >0.7 风格污染串脸 | 单人立绘/面部特写参考注入 |
| Inpainting 羽化 | 20~30px | <20 蒙版硬边 / >30 改出圈 | 局部修补（手/疤/光影残留） |
| 多控制叠加 | 各×0.7，总和等效≤1.2 | 打架=两头不执行 | Pose+Depth 复合 |

## 五、常见错误示范 vs 满分工业级示范

### 对比组 1：改光影任务路由

❌ **Bad Case**：
> 任务：把已过审的 @光大街边 母子首帧从白天改成黄昏。做法：重新文生图一张黄昏母子街景，提示词完整重写一遍。

**扣分点**：文生图重出=人物/构图全部重新抽卡，已过审资产作废（违反最小干预）；无锁脸手段，母子必漂移（崩坏09）。

✅ **Good Case**：
> 路由：Q1 不动形 → Q2 保人 → Q3 非局部 → Q4 否 → **图生图（原首帧为底，重绘 0.35）+ IP-Adapter 双参考（@李梅立绘 0.6 / @张三立绘 0.6）**；Prompt 仅改光学层（"黄昏金橙平射光，高光不过曝"）+空间层逐字复用。产出与原图人物一致、仅色温切换。

### 对比组 2：控姿态任务路由

❌ **Bad Case**：
> 任务：让 @林烬 从"负剑静立"改成"抬剑指前方"。做法：图生图重绘拉到 0.7 强度硬改。

**扣分点**：0.7 重绘越安全区间（铁律2）——脸和衣服全部重新生成，等于换人；大幅姿态变化必须走骨架控制。

✅ **Good Case**：
> 路由：Q1 动形（姿态）→ **ControlNet-OpenPose 0.75（手摆"抬剑指前"骨架图）+ PuLID 0.7（@林烬面部特写）+ Canny 0.5×0.7（保服装轮廓）**；原图为底图重绘 0.4。产出姿态精准、脸服同源。

## 六、边界情况处理（Edge Cases）

1. **双人 ControlNet 骨架重叠打架**：OpenPose 双人骨架先分层（骨架A/B 分离渲染再合并）；仍打架则 Depth 0.6 整体钉纵深 + 单人 OpenPose 只控主体、配角靠 Prompt 分区句式约束。
2. **参考图互相污染（人物参考与画风参考打架）**：砍掉画风参考（画风交给 @画风锁 文字层）；IP-Adapter 只留人物——参考图越多，每张权重越被稀释串色。
3. **无底图无参考的全新资产**：决策树从 Q1 走完直接文生图，但必须挂 KB_06/KB_08 编译模板与负向包；产出后立刻走"裁切→单人参考图"流程反哺图集。
4. **平台不支持 ControlNet（豆包等在线端）**：降级方案——"参考图多图融合 + Prompt 空间分区句式 + 抽卡 3~5 次人工选优"；需要骨架精控的镜头转 ComfyUI 执行。
5. **LoRA 与 IP-Adapter 同时可用时**：有角色 LoRA 用 LoRA（0.7），IP-Adapter 留给服装/道具参考——同源功能不双挂，权重打架。
6. **修图连环套（改了 A 处又想改 B 处）**：禁止多次 Inpainting 叠加（画质衰减累积）；回到上一层重路由一次成型，或接受 A 处结果只修 B。
