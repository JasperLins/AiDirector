# 生图技法路由器（IMG-01）

## 技法速查表

| 技法 | 适用场景 | 关键参数基线 | 输入依赖 |
|---|---|---|---|
| 文生图 | 全新资产首产 | 温度中位、抽卡2~3 | 锁定摘要+画风锁 |
| 图生图（I2I） | 在既有图上微调（改光/改景不动人） | 重绘幅度 0.3~0.45（过高换脸） | 基准图 |
| ControlNet-OpenPose | 控姿态/动作 | 强度 0.6~0.8 | 姿态骨架图 |
| ControlNet-Depth | 控空间纵深/构图 | 强度 0.5~0.7 | 深度图 |
| ControlNet-Canny/线稿 | 控边缘轮廓（改材质不改形） | 强度 0.5~0.7 | 线稿图 |
| 灰度图控制 | 控明暗布局（先灰后彩） | 二段式：灰度→上色 | 灰度草图 |
| LoRA | 角色专属风格/长相 | 权重 0.6~0.85（>0.9 僵硬） | 角色LoRA |
| Inpainting 局部重绘 | 只改局部（换手/去光影/换天） | 蒙版羽化 20~30px | 原图+蒙版 |
| 多宫格垫图 | 一张图锁定多分镜构图 | 2x2 四格，格间留白 | 分镜构图清单 |
| PuLID/IP-Adapter（Flux/SD） | 锁脸 | 0.5~0.8 | 面部特写参考 |

## 路由决策树

1. 要不要动"形"？→ 动形（姿态/构图）→ ControlNet（姿态用 OpenPose，纵深用 Depth，轮廓用 Canny）；不动形只改"色/质"→ 图生图低重绘 或 灰度图二段式。
2. 要不要保"人"？→ 要保人 → LoRA(0.6~0.85) 或 PuLID/IP-Adapter + 参考图。
3. 只改一小块？→ Inpainting（蒙版圈选，羽化 20~30px，重绘仅限蒙版内）。
4. 要一次出多镜首帧？→ 多宫格垫图 → 逐格裁切。
5. 翻车了？→ KB_09 修正词库对号入座，改词两轮无效升级技法级。

## 输出格式

```
【生图策略】技法：…｜输入依赖：@资产/基准图/骨架图｜参数：…（如 ControlNet-Depth 0.6 + 图生图重绘0.35）
【理由】…
【平台建议】…（结合目标平台推荐）
```

## 正反例

✅ 正确："首帧需保持人物但改黄昏光 → 图生图重绘 0.35 + @李梅面部特写参考（IP-Adapter 0.6），仅改光学层其余逐字复用"。
❌ 错误："直接重写一遍完整提示词重新生成"——无参考输入，人物必漂移（崩坏09）。
