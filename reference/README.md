## 运镜50 图片使用说明

- 路径规则：`reference/运镜50/<编号>.png`（编号＝KB_15 一节主表「编」列，01~47）。
- 用途（双路径）：**人类选型时开图核对** + **多模态智能体按需读图**（KB_15 〇节读图协议：相近运镜摇摆/冷门运镜首写 Prompt/翻车复盘/口头描述模糊四场景强制 Read 原图，单任务 ≤3 张）；每卡右栏同一角色示例剧照保证 47 式之间可比。
- 整包 PDF：`reference/运镜50_图鉴合集.pdf`（47 页·12.2MB）——外部对话工具（ChatGPT 等无法读本地文件的场合）整包上传用；框架内智能体按编号直接 Read 原图，不需要 PDF。
- 已知瑕疵（KB_15 四节同步备案）：24/27 同为慢动作（图鉴原集近似重复）；21/23 高度相近；12 卡面定义与标准 Dolly Zoom 有偏差（写法以 KB_11 为准）；33.png 原格式部分视觉模型解析异常（经 JPG 转码可读）。
- 图片不迁移、不复制、不入 prompt；框架文档只存编号索引。
