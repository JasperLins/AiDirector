# P0-1 维度核查表落地（KB_10重写+QC-01+AGENTS连坐+linter输出）

## Goal

把用户 2026-10-25 裁决的质检新范式落进框架：**废 10 分自评与复盘占位**（自评无外部效度），改为**维度证据核查制**——视频 8 维（镜头规格/构图/人物站位/透视与空间/一致性/连续性/动作与时间/台词音色口型）、生图对八层（KB_08 一节 ①~⑧），**缺一即不通过、不打总分、每维必须引用证据（提示词行/镜头卡字段/注册表行），无证据=判缺失**。

## Requirements

1. **KB_10 整册重写**为维度制（V3）：〇节总则（双擎保留、执法方式改为维度核查）、一节生图八层核查表、二节视频 8 维核查表、三节崩坏→维度映射、四节放行/打回双模板（维度版）、五节流程、六节实测自查、七节宫格附加+升级规则。**保留**全部执法细则文本（多轨兼容/风格包六维/宫格附加），只换判定载体（分值扣分→维度缺失）。表结构见 design.md。
2. **QC-01 技能重写**（`skill_qc_prompt_scorer_10pt.md` 文件名保留防断链）：frontmatter description 改维度制；铁律/SOP/契约/打回单模板改维度版；实战演示保留李梅母子案例改判维度版（该案例=金标准②）；B 级镜豁免规则保留（静态图仍走八层全检+时长声明）。
3. **AGENTS 连坐**：〇8 评分加载策略→维度核查加载；三节 R7 标题与角色卡（10 分制→维度制，Schema 改维度核查表输出）；状态机细则 1/3（评分四件套→核查三件套，复盘占位移除）；流水线 ASCII（≥9.0/<9.0→维度全过/缺维打回）；第七节资产行/ENN 结构行/逐分镜与段级死锁模块（评分→维度核查行；复盘占位模块移除）；双擎联审段（L2智检得分→L2维度核查 8/8）。
4. **SKILL_INDEX** QC-01 行（十分制评分官→维度核查官；触发词补维度核查）。
5. **qc_linter.py**：docstring 与末尾 L2 交棒块改为"缺维清单交棒单"（Q1~Q5 语义并入 8 维问法）；"评分锁定 0 分"措辞改"强制打回"。
6. **历史 349 条评分行**：按默认裁决"保留+文档头代际注记"——本任务先在 KB_10 四节定义注记行模板；对 12 个历史文档的批量加注为尾批步骤（若本轮未完成，转 P2-I 收尾）。

- 不动 R9 角色卡与 AGENTS 第八节复盘触发机制（retro-simplify 任务管）；KB_10 六节涉复盘字段的行只做中性化改写避免矛盾。
- 不改 B 级镜免检语义、实验路径⑤ V13 五件套（并入维度表段级口径）、宫格附加核查。
- 不改 QC-01 文件名与路径；不删历史文档评分行。
