# 世界视觉档案立法：AI主导提案制立项采集+桥归桥Gate1重跑

## Goal

修复框架级缺陷"立项视觉信息真空"（2026-10-25 桥归桥 Gate 1 三图全废实测暴露）：0.0 立项闸只采集商业参数（两层 11 项），故事世界的视觉信息（地域/时代/场景形制/人物履历）无采集闸门、无承载容器、无确认位——AI 脑补静默入圣经，美工拿残缺设定编译，废片后才从用户抱怨中回收信息。立法原则（用户 2026-10-25 两轮裁决）：**框架主导提案、用户裁决迭代**——AI 从素材记录+专业体系主动起草完整视觉方案（带默认值+来源标注），用户整体过目/修改/重确认；问询仅限真实信息真空且必须带选项；禁止把细节决策推给用户填空，也禁止 AI 脑补静默入宪。

## Requirements

**Part A 框架立法（5 件）**：
1. NARR-00（skill_series_intake.md）：增设第三层「世界视觉档案采集轮」——AI 主导起草（素材提取+专业推演+🤖AI补全标记）→ 一页式视觉设定卡陈述 → 用户放行/修改 → 修改后重新确认（迭代环）；问询仅限信息真空字段且带选项；铁律6 提问权集中条款同步扩域。
2. NARR-02（skill_world_character_arc.md）：人物立体小传模板增"履历与体态来源"必填字段；圣经产出结构新增「世界视觉档案」节（承载容器：地域地貌/时代质感/核心场景形制/人物履历/生活特色五区）；AI 补全标记铁律（🤖待确认→批量确认后去标）。
3. KB 修订四项（编译层配套）：KB_08 七节1 特征词三要素分轨（写实端禁痣/疤类微特征记忆点）；VIS-03/KB_06 母版① 人物资产图零道具政策（含长杆，修正示例②负剑适用域）；KB_05 PACK-02 ⑤ 年龄锚正向词法（衰老词最小化）；KB_06 A 轨 PACK-02 适配版（剥离 Flat Lit Albedo/正交投影等贴图学术语——"不像真人"①级实测证据）。
4. 黑名单新条目（46）：立项视觉信息真空（症状/根因四断层/立法修复/证据位阶①）。
5. AGENTS.md 法则所有权表补一行（世界视觉档案采集轮→NARR-00）；audit_consistency.py 单源检查覆盖新立法文件引用。

**Part B 本剧落地（用新流程重启，非照抄用户反馈）**：
1. 重读全部 6 份素材，提取环境/人物背景线索成清单（来源标注）。
2. 起草《桥归桥路归路·世界视觉档案（AI 草案）》：五区全字段默认值（用户两轮反馈信息+素材证据+川南乡村专业推演），未知处标 🤖 待确认或列真空问询（带选项，≤5 问）。
3. 压成一页式视觉设定卡交用户裁决（放行/修改→重确认）。
4. 用户确认后：圣经/注册表修订（人物外貌锁定摘要×2+场景空间锁定摘要+同框锚去痣联动+光位常量复核）→ Gate 1 三图 Prompt 重编译 → L1/L2 双门禁 → 用户复测。
