# AiDirector

> AIGC 影视与短剧多智能体工业化创作框架 —— 跨平台通用（ZCode / Trae / WorkBuddy 开箱即用）

一套用于 AI 短剧 / 漫剧工业化生产的提示词工程框架：**9 大角色智能体协同** × **KB 专业词典查表编译** × **独立插件式 Skills 按需加载** × **10 分制硬性质量门禁** × **复盘自进化闭环**。所有产出为可直接投入生产的中文提示词。

## 核心特性

- **三层双擎架构**：两级记忆（全局 × 剧集）驱动生产；KB 词典负责"查表编译、拒绝空洞形容词自由造句"，Skill 插件负责按需加载、防平台语法互相污染。
- **10 大角色智能体**：高级编剧大师 / 高级导演 / 美术指导 / 场记 / 分镜图总控大师 / 生图专家 / 视频提示词专家 / 10 分制评分官 / 剪映剪辑调音大师 / 复盘自进化引擎，按结构化交接 Schema（Hand-off）协作。
- **6 大工业思维**：差分编译（20% 锚点 + 80% 动态）、S/A/B 镜头算力分级、皮克斯声画先行、Cutaway 救场缓冲镜、尾帧接力长镜头、跨集状态快照。
- **5 大防崩补丁**：多主体空间分区与口型排他锁、9:16/16:9 构图自适应、`@画风锁` 三级常量、音频可替换原则（原生直出+后期静音换TTS手动对齐）、` ```prompt ` 标准代码块封装。
- **10 分制硬性门禁**：每条提示词独立评分，低于 9.0 强制打回重写（38 种 AI 视频物理崩坏模式为一票否决题库）。
- **平台专属插件**：豆包 Seedream、即梦 Seedance、ComfyUI（Flux/Wan）、MiniMax H3、可灵 Kling、ChatGPT、大香蕉 Nano Banana、公用默认——互斥加载，未指定平台时自动给出推荐。

## 快速上手（5 步）

1. **读总控建记忆**：通读 `AGENTS.md` 与 `skills/SKILL_INDEX.md`；新剧在 `memory/projects/[剧名]/` 建三件套。
2. **剧本→分镜**：编剧产出钩子、情绪曲线与完整分场文学剧本（NARR-04：外化动作+画面口型/画外OS 双轨台词+音频ID 预埋）；导演拆分镜并标注 S/A/B 算力分级；台词先做声画先行秒数精算。
3. **资产先行**：按 `KB_06` 零光影铁律产出三视图 / 表情矩阵 / 面部特写 / 全身立绘；登记 `@纯中文` 资产名与音色卡。
4. **编译过门禁**：生图走八层全量公式，视频走差分公式 + 口型排他锁（音频可替换原则：原生直出，后期可静音原轨换 TTS 手动对齐）；每条 Prompt 过 10 分制评分，<9.0 打回。
5. **实测复盘进化**：跑图跑片后填写 `Prompt 实际产出复盘`，复盘引擎自动归因并修订词典与插件。

## 首页与教学文档

- 浏览器直接打开 `index.html`：沉浸式影院级首页——约 3 秒视频预载序章（0~100% 计数 + Logo 飞入导航位），随后 Canvas 伪 3D 圆角"传送门"开启三幕体验（CREATE 创作 → GENERATE 生成 → REFINE 精修），门户随指针倾斜、点击即跳转下一幕；终幕传送门直达教学文档。左侧栏为八大教学栏目导航，全程自定义光标。
- 浏览器打开 `doc/doc.html`：完整教学文档——10 分钟实战教学营（5 步口令）、偷懒口令卡、核心数据看板（20/80 配比 / S-A-B 分级 / Token 负载 / 四轨 dB）、全景架构拓扑、9 大角色面板、12 KB × 24 Skill 速查器、6 思维 × 5 补丁、多平台 Prompt 实验室（平台语法切换 / 一键复制 / `@中文资产` 高亮）、10 分制评分官扣分模拟器。
