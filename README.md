# AiDirector

> AIGC 影视与短剧多智能体工业化创作框架 —— 跨平台通用（ZCode / Trae / WorkBuddy 开箱即用）

一套用于 AI 短剧 / 漫剧工业化生产的提示词工程框架：**9 大角色智能体协同** × **KB 专业词典查表编译** × **独立插件式 Skills 按需加载** × **10 分制硬性质量门禁** × **复盘自进化闭环**。所有产出为可直接投入生产的中文提示词。

## 核心特性

- **三层双擎架构**：两级记忆（全局 × 剧集）驱动生产；KB 词典负责"查表编译、拒绝空洞形容词自由造句"，Skill 插件负责按需加载、防平台语法互相污染。
- **9 大角色智能体**：编剧 / 导演 / 美术指导 / 场记 / 生图专家 / 视频提示词专家 / 10 分制评分官 / 剪映剪辑调音大师 / 复盘自进化引擎，按结构化交接 Schema（Hand-off）协作。
- **6 大工业思维**：差分编译（20% 锚点 + 80% 动态）、S/A/B 镜头算力分级、皮克斯声画先行、Cutaway 救场缓冲镜、尾帧接力长镜头、跨集状态快照。
- **5 大防崩补丁**：多主体空间分区与口型排他锁、9:16/16:9 构图自适应、`@画风锁` 全局常量、音画双管线分流（模式A/B）、` ```prompt ` 标准代码块封装。
- **10 分制硬性门禁**：每条提示词独立评分，低于 9.0 强制打回重写（17 种 AI 视频物理崩坏模式为一票否决题库）。
- **平台专属插件**：豆包 Seedream、即梦 Seedance、ComfyUI（Flux/Wan）、MiniMax H3、可灵 Kling、公用默认——互斥加载，未指定平台时自动给出推荐。

## 快速上手（5 步）

1. **读总控建记忆**：通读 `AGENTS.md` 与 `skills/SKILL_INDEX.md`；新剧在 `memory/projects/[剧名]/` 建三件套。
2. **剧本→分镜**：编剧出钩子与情绪曲线；导演拆分镜并标注 S/A/B 算力分级；台词先做声画先行秒数精算。
3. **资产先行**：按 `KB_06` 零光影铁律产出三视图 / 表情矩阵 / 面部特写 / 全身立绘；登记 `@纯中文` 资产名与音色卡。
4. **编译过门禁**：生图走八层全量公式，视频走差分公式 + 口型排他锁 + 模式 A/B 声明；每条 Prompt 过 10 分制评分，<9.0 打回。
5. **实测复盘进化**：跑图跑片后填写 `Prompt 实际产出复盘`，复盘引擎自动归因并修订词典与插件。
