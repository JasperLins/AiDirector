# AiDirector

> AIGC 影视与短剧多智能体工业化创作框架 —— 跨平台通用（ZCode / Trae / WorkBuddy 开箱即用）

一套用于 AI 短剧 / 漫剧工业化生产的**中文提示词工程框架**：**10 大角色智能体协同** × **15 册 KB 词典查表编译** × **27 个插件式 Skill 按需加载** × **维度制硬性质量门禁（视频 8 维 / 生图八层 · 证据核查）** × **问题直通与知识沉淀闭环**。所有产出为可直接复制进平台的中文提示词（MIT 开源）。

## 核心特性

- **三层双擎架构**：两级记忆（全局 × 剧集）驱动生产；KB 词典负责"查表编译、拒绝空洞形容词自由造句"，Skill 插件按需加载、平台语法互斥防污染。
- **10 大角色智能体**：高级编剧 / 高级导演 / 美术指导 / 场记 / 分镜图总控（R10）/ 生图专家 / 视频提示词专家 / 维度核查官（R7）/ 剪映剪辑调音大师 / 知识库维护引擎（R9），按结构化交接 Schema（Hand-off）协作。
- **8 大工业思维**：差分编译（20% 锚点 + 80% 动态）、S/A/B 镜头算力分级、皮克斯声画先行、Cutaway 救场缓冲镜、尾帧接力长镜头、跨集状态快照、**覆盖冗余生产（S 级 3机位×3条投保）**、**导演前期工作制（90% 前置定稿才开跑）**。
- **8 大防崩补丁**：多主体空间分区与口型排他锁、9:16/16:9 构图自适应、`@画风锁` 三级常量、音频可替换原则、` ```prompt ` 纯净代码块直发、垫图机位三分法、**台词与音色必备件（五要素＋静默声明＋音色五维）**。
- **维度制硬性门禁**：视频 8 维（镜头规格/构图/人物站位/透视与空间/一致性/连续性/动作与时间/台词音色口型）**缺一即不通过、不打总分、每维必引证据**；生图对 KB_08 八层逐层核；L1 机检（`qc_linter.py`）+ L2 维度核查双签定稿；53 种崩坏速查静态知识库兜底。
- **空间镜头卡先行**：站位 / 机位高度 / 焦段（20~200mm 数值表）/ 距离 / 构图 / 运动起终 / 轴线侧 / 视线方向——先定几何再出文字，首帧先过构图门禁。
- **平台插件互斥**：豆包 Seedream、即梦 Seedance、ComfyUI（Flux/Wan）、MiniMax H3、可灵 Kling、ChatGPT、大香蕉 Nano Banana、公用默认——未指定平台时自动产出公用标准提示词并给推荐。

## 快速上手（5 步 · 立项闸先行）

1. **读总控、过立项闸**：通读 `AGENTS.md` 与 `skills/SKILL_INDEX.md`；新剧必须先经 NARR-00 立项问询器收口参数 → **一页式立项书用户拍板**（0.0 闸：未经拍板不得建三件套、不得写圣经全文）。
2. **剧本 → 分镜**：编剧产出钩子、情绪曲线与双轨台词剧本（NARR-04）；**剧本大纲先过用户裁决位**再进正文与 N 三查；导演拆镜**每镜先填空间镜头卡**（几何先行），S/A/B 分级＋冗余覆盖档＋场次覆盖调度表；R10 产出分镜图生产单（0.6 闸：无生产单不生图）＋生产排期表（拍摄顺序≠叙事顺序）。
3. **资产先行**：按零光影铁律产出三视图 / 表情矩阵 / 立绘；登记 `@纯中文` 资产名＋基准图＋音色五维与平台 voice-id。
4. **编译过门禁**：生图走八层黄金语序、视频走差分公式＋台词五要素＋口型排他锁；**每条 Prompt 过 L1 机检＋R7 维度核查（8/8 或八层齐才放行）**。
5. **实拍与问题直通**：人工复制到豆包 / 即梦 / ComfyUI 等平台跑图跑片；发现问题**直接指示即时修复**（EVO-01 归因定位＋同族连坐刷新＋沉淀知识库）——无逐条复盘负担。
