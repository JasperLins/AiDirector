## 一、高星权威开源仓库架构提炼（学系统骨架）

### 1.1 anthropics/skills（官方 Agent Skills 规范，179k+ Stars）
- **核心规范**：一个 Skill = 一个文件夹 + 一个 `SKILL.md`；文件顶部必须有 YAML Frontmatter，其中 `name` 与 `description` 为必填字段，`description` 是决定智能体是否自动调用该 Skill 的**首要触发机制**。
- **description 黄金结构**：必须同时包含 **WHAT（这个技能做什么）+ WHEN（什么条件下触发使用）**，例如："为即梦 Seedance 撰写多主体参考视频提示词。当用户指定即梦平台或需要多图参考融合时触发。"
- **按需加载（Progressive Disclosure）三段式**：① 元数据层（name/description，常驻索引）→ ② 正文层（SKILL.md 主体，调用时才读取）→ ③ 附属资源层（词典、脚本，执行到对应步骤才读取）。本框架的 `skills/SKILL_INDEX.md` 路由即仿照此机制设计，用于在 ZCode / Trae / WorkBuddy 中节省上下文 Token。
- **常见故障**：Skill 无法被识别的首要原因是 Frontmatter 缺失或 YAML 格式错误——本框架所有 Skill 文件创建时必须自检 Frontmatter 完整性。

### 1.2 chatfire-AI/huobao-drama（火宝短剧，15k+ Stars，AI 短剧一站式平台）
- **全流程管线**（本框架三阶流水线直接吸收）：
  `小说原文导入 → AI 改写为可拍摄剧本（按集拆分、标注场景与角色） → 角色/场景/道具一致性资产提取与生成 → 分镜拆解 → 基于资产参考的视频提示词生成 → 视频合成`。
- **关键设计**：剧本阶段即"按集拆分并标注场景与角色"，角色形象提取后以**资产引用（本框架升级为 `@中文资产名称` 体系）**方式注入后续所有生图与生视频提示词，保证跨镜头一致性。
- **多模型路由**：文本模型（改写）、图像模型（资产/分镜图）、视频模型、TTS 模型分离配置——对应本框架"平台插件式 Skills"分层。

### 1.3 HKUDS/ViMax（港大多智能体视频框架，12k+ Stars）
- **多智能体协同管线**：Screenwriter（编剧）→ Shot Planner（分镜规划）→ Character Styling（角色造型）→ Image Generation → Video Generation → **VLM-based Quality Control（视觉语言模型质检回路）** → Final Assembly。导演（Director）+ 编剧 + 制片人（Producer）三核心角色统筹。
- **首帧一致性（First Frame Consistency）**：视频片段的画面一致性依赖"先生成关键帧图像，再以该图像作为视频首帧"的锚定策略——这正是本框架"分镜前置资源（首帧基准图）"的理论来源。
- **质检回路**：生成结果先经视觉语言模型审片打分，不合格自动打回重生成——本框架"10 分制评分官 + 低于 9 分强制重写"机制由此强化。

### 1.4 FoundationAgents/MetaGPT 与 crewAIInc/crewAI（多智能体协作范式）
- **结构化交接契约（Hand-off Schema）**：角色之间不传闲聊，只传"结构化文档"——编剧交出标准剧本 JSON/表格，导演交出分镜表，美术交出资产设定卡。下游角色只依赖上游的结构化产物工作。本框架规定每个角色的"输出 Schema"即由此而来。
- **质量门禁与打回（Guardrail）**：crewAI 的 Task 可挂 Guardrail 回调，输出不达标即拦截并要求重做——本框架评分官的"一票否决扣分题库 + 强制重写回路"同源。
- **角色=职责+工具+预期输出**：定义智能体时必须写清三者，防止角色越界互相抢活。

### 1.5 垂直提示词实战库（awesome-seedance 系列等）
- **按秒切分时间轴写法**：`[0-2s] 镜头缓推，主角抬头；[2-5s] 衣袂翻飞，握紧剑柄`——Seedance 2.5 官方即支持秒级时间戳分段叙事，单条最长可达 30 秒。
- **一镜一主动作原则**：单个 5 秒镜头只安排一个主动作 + 一个镜头运动，多动作串联必拆多镜，否则模型在时间轴中段动作漂移。
- **多宫格分镜垫图法（Storyboard Grid）**：用一张网格图（如 2x2 四格）垫底生成连贯分镜，再逐格裁切为视频首帧，可低成本锁定同一场景内的构图延续性。
- **对白时长测算**：中文正常语速约 4 字/秒，急促 5.5 字/秒，沉吟 2.5 字/秒——台词字数除以语速再加情绪停顿 0.3~0.8 秒，得镜头最短时长。

## 二、四大靶向专业数据（核实版词库与语法）

### 2.1 靶向一：扩散模型零光影正交三视图 & Albedo 固有色词库

**原理**：扩散模型对否定词（"无高光""无阴影"）不敏感——否定词在 cross-attention 中反而注入了"高光/阴影"的概念激活。正确做法是**用正面物理状态描述替代否定**，即描述"光被均匀化了"这一事实，而非"光不存在"。

**核心正面词库（中文编译版，已核实）**：
- 布光状态：`360度环形无影棚拍柔光`、`大型柔光箱正面平光`、`均匀漫射平光（Flat Even Lighting）`、`影棚基准平光`
- 贴图质感：`漫反射固有色贴图质感（Flat Lit Albedo / Diffuse Pass）`、`PBR 漫反射贴图`、`哑光固有色`
- 投影方式：`正交投影相机（Orthographic Projection）`、`零透视畸变`、`平行投影无近大远小`
- 背景规范：`中性18%灰背景`、`纯白背景`、`无接缝纯色背景（Seamless Backdrop）`
- 姿态规范：`A-Pose 双臂自然微张`（防衣袖与躯干粘连，优于 T-Pose）、`T-Pose 双臂水平展开`（适合需要完整展袖的服装）、`双脚与肩同宽站立基准`
- 版式规范：`角色设定三视图（Turnaround Sheet）`、`正面/左侧面/背面三视图等距水平排列`、`model sheet 排版`、`同一角色三个视角比例严格一致`

**国际通用英文关键词对照**（供 ComfyUI/Flux 类英文语义更强的模型使用）：
`character turnaround sheet, three view (front / side / back), orthographic projection, T-pose / A-pose, full body, consistent proportions, flat lighting, albedo map style, neutral white background, model sheet layout`

**三视图 vs 单镜头参考的关键区分（防"三个人同框"崩坏）**：
- 三视图**只用于锁定资产设定**（人设存档、LoRA 训练集、重绘参考）。
- 喂给视频模型做首帧/参考图时，**必须先裁切出单一视角的"独立全身立绘"或"独立面部特写"**，否则视频模型会把三视图识别为三个人同框，导致多人乱张嘴、串脸、复制人。
- 因此资产库中每个角色除三视图外，必须额外产出：`独立正面全身立绘图` + `独立面部特写图`（均为零光影平光规范）。

### 2.2 靶向二：各平台最新真实语法特征

**① 豆包（Seedream 4.0，生图）**——中式美学与空间排布之王
- 中文原生理解优秀，**无需翻译成英文**；直接写中文打光术语即可精准响应：`伦勃朗光`、`轮廓光`、`逆光`、`分割光`、`环形光`、`顶光`。
- **长文本空间方位语法**：按"前景…中景…远景…"分句描述，4.0 对空间层次理解极强，可精准执行 `画面左侧三分之一` / `右侧三分之二` / `左前景虚化` 等排布指令。
- 分辨率控制：提示词末尾缀 `2K` / `4K`；4.0 原生支持 4K 与组图生成、多图融合创作。
- 适合：东方玄幻场景、人物主图、多主体空间分区构图、海报级质感图。

**② 即梦（Jimeng / Seedance，生视频）**——多主体参考融合与分秒叙事
- **多模态参考**：Seedance 2.x 支持上传多张参考素材（人物图、场景图、道具图，2.5 版最多可达 50 个素材位），在提示词中以引用关系绑定。
- **秒级时间轴**：官方支持 `[0-4秒]…[5-10秒]…` 时间戳分段叙事，单条最长 30 秒。
- **结构化公式**：`主体（外貌+服装）+ 动作序列 + 镜头语言（推/拉/摇/移/跟随/环绕）+ 视觉风格 + 约束条件`。
- **原生音画同出**：Seedance 支持直出对白与音效，写明台词文本与语气即可生成带口型的说话画面（原生音画直出首选平台之一；音频不满意后期静音原轨换 TTS）。

**③ MiniMax 海螺（H3，生视频）**——多模态统一与运镜指令
- H3 为通用多模态视频模型：文/图/首末帧输入（T2VA / I2VA / Frames）、原生预测视频帧 + 32kHz 立体声音轨（对白、音效、音乐可同出）。
- **参考模式（Reference Mode）**：支持素材标记与保留标记词，六栏位结构化提示词（主体参考/动作/时间节拍/声音设计等）。
- **方括号运镜指令**：社区实战语法以方括号置于句首/句中控制运镜：`[推近]`、`[拉远]`、`[左移]`、`[右移]`、`[上摇]`、`[下摇]`、`[环绕]`、`[固定]`；配合细腻面部微表情递进描述（`嘴角缓缓上扬`、`眼神从错愕转为狠戾`）效果拔群。官方另提供 9 个可直接套用的 Skill 模板。
- 适合：情感戏、微表情特写、带原生对白音频的镜头（原生音频仅占位参考，后期可整轨替换 TTS）。

**④ ComfyUI（Flux + Wan2.1/2.2，工作流自建）**——可控性天花板
- **Flux 主体一致性**：PuLID（人脸 ID 锁定）、IP-Adapter（风格/角色参考注入）、Redux（参考图重铺）；LoRA 权重常规 0.6~0.85，过高（>0.9）易画风僵硬。
- **ControlNet 组合**：Depth（景深结构）、OpenPose（姿态骨架）、Canny/线稿（边缘轮廓）；视频侧 Wan2.1 Fun Control 官方工作流支持姿态/深度/边缘三分支引导视频生成。
- **Wan 视频模型**：支持动态幅度控制（Motion Strength / 视频差分引导），图生视频以首帧锚定；Wan2.2-S2V 支持无限时长数字人口播。
- **标准 Negative Prompt 传统**：ComfyUI 生态保留独立负向词输入端，可用"多余手指、肢体畸变、面部扭曲、闪烁、伪影"等负向词兜底。
- 适合：B 级降本镜头（静态图+关键帧）、大批量资产图、极端可控的 S 级精修。

**⑤ 可灵（Kling，生视频）**——首尾帧锚定与物理规律
- **提示词公式（官方）**：`主体（主体描述）+ 运动 + 场景（场景描述）+（镜头语言 + 光影 + 氛围）`，核心是主体+运动+场景。
- **首尾帧（First & Last Frame）**：上传首帧+尾帧两张图锚定起止画面，提示词只描述中间过渡运动；**运镜幅度必须匹配首尾帧画面差异**，否则运镜指令不执行。
- **物理规律**：3D 时空联合注意力机制可模拟真实物理（重力、惯性、碰撞），提示词写符合物理的动作描述效果更佳。
- **锚点间隔**：多镜头分段叙事时，时间锚点间隔至少 3 秒，否则分镜切换生硬；主体崩坏时增加外貌细节描述 + 使用主体参考。
- 适合：S 级长镜头、大幅度打斗、首尾帧精准控制的奇观镜头。

### 2.3 靶向三：剪映专业版真实菜单名 & TTS 真实语音标签（严禁编造）

**剪映专业版·曲线变速（入口：选中素材 → 右侧调节面板 →「变速」→「曲线变速」）**——系统内置 6 种预设，名称核实无误：
| 预设名 | 节奏效果 | 典型用途 |
|---|---|---|
| `蒙太奇` | 先慢后快再慢 | 片头快速闪过、结尾聚焦 |
| `英雄时刻` | 突然变慢再恢复 | 高光/燃点瞬间 |
| `子弹时间` | 极致慢放 | 动作定格、戏剧化瞬间 |
| `跳接` | 节奏跳跃 | 卡点、快剪 |
| `闪进` | 开场加速 | 无缝入场转场 |
| `闪出` | 结尾加速 | 无缝出场转场 |
另支持自定义曲线（横轴时间、纵轴速度倍数拖锚点调节）。

**剪映专业版·转场特效（入口：「转场」面板，白色竖线衔接处应用）**：
- 基础类：`叠化`（含淡入淡出，建议时长 0.2~0.3 秒）、`闪黑`、`闪白`
- 运镜类：`推进`、`拉远`、`左移`、`右移`、`旋转`、`模糊`
- 光效与 MG 类：`漏光`（特效→氛围/光效分类）、`故障`（转场-特效中搜索"故障"，故障模糊）、`燃烧`
- 快捷键：`Alt+T` 打开转场面板

**剪映专业版·音频处理（入口：音频轨道 → 音频调节面板）**：
- `人声美化`、`智能降噪`、`声音克隆`（内置音色复刻）、`变声`、`音频卡点`（节拍标记自动对齐）

**TTS 平台真实参数与副语言控制符（核实版）**：
- **Fish Audio**：参考音频最少 10 秒可克隆，15~30 秒更准确复刻说话模式与情感，官方建议最佳 1~3 分钟；ComfyUI Instant Voice Clone 节点接受 1~20 段录音、每段 10~30 秒、总时长硬性校验 <270 秒；S2 版本支持行内开放域标签与词级控制（如重音、停顿、语种切换）。
- **MiniMax 语音（speech 系列）**：预设库标签可直接内嵌文本——情绪标签 `<#>`、停顿 `( )`、语气词标记；支持混合音色与情感风格调节。
- **CosyVoice**：instruct 指令模式可用自然语言控制副语言；文本开头使用全大写情感标记 `<|HAPPY|>`、`<|SAD|>`、`<|ANGRY|>` 等，长文本可插入多个标记实现情感转换；克隆模式 3 秒即可，但 2.0 克隆模式下自然语言语气描述可能失效（已知问题，需 instruct 模式）。
- **通用副语言写法（英文括号/方括号标签，多数平台兼容）**：`(sigh)` 叹气、`(laughter)`/`[laughter]` 笑声、`(breath)` 换气、`(pause)` 停顿、`(whisper)` 气声；语速以倍率或字/秒指定；情绪以"开心/悲伤/愤怒/惊讶/平静"等标签前置。

| CosyVoice | TTS | instruct 副语言指令、3秒克隆、可本地部署 | 2.0 克隆模式语气描述失效 | 本地化批量配音 |

**选型路由启发式**：
1. 用户指定平台 → 直接加载对应 `plat_*` 插件。
2. 未指定平台生图 → 默认公用标准提示词 + 推荐豆包 Seedream 4.0（中文/人设）或 ComfyUI Flux（需锁脸/批量）。
3. 未指定平台生视频 → 默认公用标准提示词 + 按镜头类型推荐：S 级奇观→可灵；对白戏→即梦或 MiniMax H3（口型细腻优先）；微表情情感戏→MiniMax H3；B 级降本→ComfyUI Wan2.1（音频后期 TTS 轨替换，音频可替换原则）。
