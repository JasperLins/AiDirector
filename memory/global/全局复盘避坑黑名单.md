## 第一部分：17 种高频物理崩坏模式总库

### 崩坏 01｜手部六指 / 手指融化
- **触发条件**：手部特写、快速手势、手指交叉、多人握手贴手。
- **根因**：手部几何自由度高，扩散模型跨帧保持几何稳定性差（Elser AI / Higgsfield 实验证实为最高频翻车点）。
- **预防写法**：手部动作写"简化手势"（`五指自然并拢`、`单手握拳`）；特写镜头降速；ComfyUI 走 OpenPose 手部骨架控制；负向词兜底 `多余手指、六指、手指粘连`。
- **评分规则**：提示词中出现"十指交叉""比复杂手势"且无保护写法 → 一票否决，直接扣至 8 分以下打回。

### 崩坏 02｜双手十指交叉导致手部彻底融化
- **触发条件**：`十指交叉`、`双手紧握对插` 类描述。
- **根因**：交叉手指的自遮挡关系超出模型拓扑理解，直接融合成"莫比乌斯环"。
- **预防写法**：改写为 `双手交叠放于身前（一手覆于另一手之上）` 或 `单手抱臂`；情侣牵手改为 `十指相扣→五指并拢轻握` 且镜头避开手部特写。
- **评分规则**：出现"十指交叉"字样 → 一票否决。

### 崩坏 03｜360 度大转身导致五官移位
- **触发条件**：单镜内 `转身360度`、`原地旋转`、`急速回身甩头`。
- **根因**：大角度旋转中面部朝向跳变，模型在中途帧丢失五官锚点。
- **预防写法**：拆为两镜（`转身前半段` + `转身后定格`），中间用甩发/衣摆特写 Cutaway 遮转场；必须旋转时用可灵首尾帧锚定起止脸。
- **评分规则**：单镜含 360 度旋转且无首尾帧锚定 → 一票否决。

### 崩坏 04｜单镜多机位硬切导致空间撕裂
- **触发条件**：一条 5 秒提示词里写"先全景、再切特写、再切侧面"（提示词内隐含剪辑）。
- **根因**：视频模型单次生成是**连续单机位**时空，提示词内写镜头切换会导致画面空间错位撕裂。
- **预防写法**：铁律"一镜一机位一主动作"；需要切换必须拆分独立镜头各自生成，剪辑台上再切。
- **评分规则**：单条视频 Prompt 含 2 个及以上机位描述 → 一票否决。

### 崩坏 05｜多人同框全员乱张嘴
- **触发条件**：多人画面 + 提示词只写台词不写口型归属。
- **根因**：模型将对白音频/文本泛化到画面所有人物面部。
- **预防写法**：**口型排他锁**——显式写 `说话者@张三抬头张嘴说话，嘴唇自然开合；一旁的@李梅保持双唇闭合、面带微笑低头倾听`。
- **评分规则**：多人 + 有台词 + 未写倾听者闭嘴状态 → 一票否决（对应防崩补丁1）。

### 崩坏 06｜多主体串色 / 串脸（角色A的脸长到角色B身上）
- **触发条件**：多人同框但未划分空间象限与体型差。
- **根因**：多主体特征在注意力中互相渗透。
- **预防写法**：**多主体空间分区**——`画面左侧三分之一处为成年女性@李梅（身高约一米六五、米白风衣），画面右侧三分之二处为孩童@张三（身高约一米一、蓝色卫衣）`，以体型差+服装差+方位差三重区分。
- **评分规则**：≥2 个人物资产同框且无空间分区描述 → 一票否决。

### 崩坏 07｜快速奔跑双腿交替穿模
- **触发条件**：`狂奔`、`疾跑`、`连续跳跃`。
- **根因**：腿部交替频率超出帧间运动估计能力，左右腿互相穿透。
- **预防写法**：降速词（`小跑`、`疾走`）；或改半身景别（腰部以上跟拍）；或可灵首尾帧锚定起止步态 + `符合人体运动规律的连贯奔跑`。
- **评分规则**：全景+狂奔+无锚定 → 扣 1.5 分并要求修改。

### 崩坏 08｜衣物与身体粘连 / 衣袖消失
- **触发条件**：宽袍大袖 + 大动作；三视图阶段 T-Pose 展臂不足。
- **根因**：布料与躯干自遮挡判断失败。
- **预防写法**：资产三视图用 A-Pose 双臂微张 30~45 度；视频词加 `衣袂随动作自然摆动，袖口与手腕分离清晰`。
- **评分规则**：古风宽袍 + 挥剑大动作且无衣袖分离描述 → 扣 1 分。

### 崩坏 09｜面部身份漂移（越动越不像）
- **触发条件**：长镜头持续运动、多镜头接力后未重新锚定角色脸。
- **根因**：模型"无记忆"，逐帧独立猜测（Higgsfield 分析），误差累积。
- **预防写法**：每 5 秒一个镜头重锚 `@资产名`（首帧参考图）；接力镜头首帧用上一镜尾帧；B 级镜头改静态图 + 后期动态。
- **评分规则**：连续第 3 镜及以后未刷新首帧锚定 → 扣 1 分。

### 崩坏 10｜首帧带强逆光导致视频过曝崩坏
- **触发条件**：首帧图逆光/大面积高光（窗前剪影、日落背光）。
- **根因**：视频模型在 I2V 时放大首帧曝光特征，高光区溢出色彩断层。
- **预防写法**：首帧基准图控制动态范围（`柔和侧逆光、高光不过曝、保留面部细节`）；重曝戏份用`轮廓光适度`。
- **评分规则**：前置生图 Prompt 中出现"强逆光/纯剪影"用于 I2V 首帧 → 扣 1.5 分。

### 崩坏 11｜文字与招牌乱码
- **触发条件**：画面含招牌、字幕、书籍、手机屏幕文字。
- **根因**：扩散模型文字渲染能力不稳定，视频逐帧更甚。
- **预防写法**：中文招牌用 `字迹模糊虚化` 处理为景深元素；必须清晰的文字用剪映后期贴字；避免提示词要求生成可读文本。
- **评分规则**：要求 AI 生成清晰可读文字 → 扣 1 分并建议后期贴字。

### 崩坏 12｜道具中途变形 / 消失
- **触发条件**：手持道具（剑、伞、包）在长镜头中换手或离开画面。
- **根因**：道具跨帧一致性弱，被注意力丢弃后重生成时变形。
- **预防写法**：`@焚天断剑始终握于右手、剑身完整不入画出画`；道具离镜写明 `将剑收入背后剑鞘` 的显式过渡动作。
- **评分规则**：核心道具镜头未写持握手与不离镜约束 → 扣 1 分。

### 崩坏 13｜人物瞬移 / 穿墙穿模
- **触发条件**：提示词写 `走到画面另一端` `穿过人群` 等长距离位移。
- **根因**：大位移空间推理失败，跳切式瞬移。
- **预防写法**：单镜位移限制在一个身位内；跨场景移动拆镜头 + 转场；可灵模式下用首尾帧锚定起点终点。
- **评分规则**：单镜位移超过 3 米且无锚定 → 扣 1.5 分。

### 崩坏 14｜液体与布料物理违和（水不流、布如铁）
- **触发条件**：泼水、雨中淋湿、丝绸垂坠、瀑布。
- **根因**：流体与软体动力学模拟不真实，凝固或抖动。
- **预防写法**：降复杂度（`细雨飘落` 优于 `瓢泼大雨`）；茶水特写用 B 级静态图 + 剪映蒸汽特效替代。
- **评分规则**：核心叙事依赖复杂流体且无降级方案 → 扣 1 分。

### 崩坏 15｜眨眼缺失或高频抽搐
- **触发条件**：长特写凝视镜头。
- **根因**：眼部微动作帧间不稳定，要么死鱼眼不眨、要么高频抽动。
- **预防写法**：MiniMax H3 写 `眨眼频率自然，约三秒一次轻微眨眼`；或 B 级镜头静态图 + 剪映`眼动`关键帧。
- **评分规则**：特写超过 4 秒且无眨眼描述（H3 类平台）→ 扣 0.5 分。

### 崩坏 16｜口型与台词不同步 / 对不上音节
- **触发条件**：模式A直出对白时长与台词字数不匹配；模式B后期对口型基底嘴型过大。
- **根因**：时长测算缺失；或原视频嘴部大幅开合与 LatentSync/剪映对口型二次合成打架重影。
- **预防写法**：声画先行测算（字数÷语速+停顿=时长）；模式B强制 `嘴唇保持自然闭合或极轻微闭合微动（预留后期Lip-Sync口型合成干净基底）`。
- **评分规则**：有台词镜头无时长测算，或模式B未写闭嘴基底 → 一票否决。

### 崩坏 17｜背景周期性闪烁 / 纹理游走
- **触发条件**：高频重复纹理背景（栅栏、砖墙、树林、波光）。
- **根因**：重复纹理帧间相位差引发摩尔纹式闪烁。
- **预防写法**：景深虚化背景（`背景树林大光圈虚化`）；运动镜头降低背景权重；后期剪映`智能补帧`缓解。
- **评分规则**：高清重复纹理背景 + 运动镜头且无虚化 → 扣 0.5 分。
