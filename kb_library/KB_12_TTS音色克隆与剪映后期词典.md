## 一、TTS 音色克隆真实参数（Fish Audio / Noiz / MiniMax / CosyVoice）

### 1.1 Fish Audio（音色克隆主力）
| 参数项 | 真实要求 |
|---|---|
| 最短克隆时长 | 10 秒即可克隆 |
| 推荐时长 | 15~30 秒准确复刻；官方最佳建议 1~3 分钟 |
| ComfyUI Instant Voice Clone 节点 | 1~20 段录音，每段 10~30 秒，**总时长硬性 <270 秒** |
| 参考音频质量 | 发音清晰、情绪平稳、背景干净（干声） |
| S2 特性 | 词级控制、行内开放域标签、80 语种 |

### 1.2 MiniMax 语音（情绪台词主力）
- 文本内嵌标签：情绪标签 `<#>`、停顿 `( )`、语气词标记。
- 支持混合音色与情感风格调节；儿童声优先用平台预设微调。

### 1.3 CosyVoice（本地批量）
- instruct 指令模式：自然语言控制副语言（"用颤抖的声音说"）。
- 文本头部情感标记（全大写）：`<|HAPPY|>`、`<|SAD|>`、`<|ANGRY|>`、`<|SURPRISED|>`、`<|CALM|>`；长文本可多点插入实现情感转换。
- 已知限制：2.0 克隆模式下自然语言语气描述可能失效 → 语气控制走 instruct 模式。
- 克隆仅需 3 秒样本，SSML 可控停顿/发音。

### 1.4 通用副语言标签（多平台兼容写法）
`(sigh)` 叹气、`(laughter)` / `[laughter]` 笑声、`(breath)` 换气、`(pause)` 停顿、`(whisper)` 气声、`(softly)` 轻柔、`(excited)` 兴奋。
语速：倍率（0.8x~1.3x）或字/秒；音调：`升调/降调/平调`；情绪：`开心/悲伤/愤怒/惊讶/平静/温柔/委屈/狠戾`。

### 1.5 语速基准（声画先行 NARR-03 联动）
| 语速档 | 字/秒 | 适用 |
|---|---|---|
| 急促 | 5.5 | 争吵、报信 |
| 正常 | 4.0 | 日常对白 |
| 放慢童声 | 3.5~4.0 | 孩童台词（奶音拖尾） |
| 沉吟 | 2.5 | 压场、深情、威吓 |

## 二、剪映专业版真实菜单词典（严禁编造）

### 2.1 曲线变速（选中素材 → 调节面板 →「变速」→「曲线变速」，6 种系统预设）
| 预设名（真实） | 节奏效果 | 短剧用途 |
|---|---|---|
| `蒙太奇` | 先慢后快再慢 | 片头闪过、结尾聚焦 |
| `英雄时刻` | 突然变慢再恢复 | 高光燃点 |
| `子弹时间` | 极致慢放 | 动作定格 |
| `跳接` | 节奏跳跃 | 卡点快剪 |
| `闪进` | 开场加速 | 无缝入场 |
| `闪出` | 结尾加速 | 无缝出场 |
自定义曲线：横轴时间、纵轴速度倍数，拖锚点调节。

### 2.2 转场特效（「转场」面板；快捷键 Alt+T）
- 基础类：`叠化`（建议 0.2~0.3 秒）、`闪黑`、`闪白`
- 运镜类：`推进`、`拉远`、`左移`、`右移`、`旋转`、`模糊`
- 光效/MG 类：`漏光`（特效→氛围/光效）、`故障`（转场-特效搜"故障"，故障模糊）、`燃烧`

### 2.3 音频处理（音频轨道 → 音频调节）
`人声美化`、`智能降噪`、`声音克隆`、`变声`、`音频卡点`（节拍标记自动对齐）。

### 2.4 其他常用真实功能名
`入场动画/出场动画`（如渐显、向右上飞入）、`智能补帧`、`文本朗读`、`歌词识别`、`色度抠图`、`蒙版（线性/圆形/爱心）`、`画中画`、`关键帧`、`美颜美体`、`对口型`（数字人/口型驱动类功能入口）。

## 三、剪辑手法规范（R8 输出词源）

### 3.1 声画错位（Cutaway 遮瑕核心）
- `J-Cut`：下一镜声音先入、画面后切（听觉提前引导）。
- `L-Cut`：上一镜声音延入下一镜画面（对话余韵）。
- 用法：缓冲镜（美食摊白雾特写 1.5 秒）覆盖在主轨上方做 L-Cut，掩盖主镜局部瑕疵。

### 3.2 卡点与节奏
- 动作卡点：重音落在动作顶点帧（剑出鞘瞬间打 BGM 重拍）。
- 情绪留白：爆点前插 0.5 秒黑场/定格呼吸。
- 整集节奏曲线：钩子（0-3s）→ 升压 → 小爆点 → 压抑 → 大爆点 → 悬念钩尾。

### 3.3 多轨混音规范
- 轨道分层：人声轨（-6dB 主导）＞Foley 动作音效轨（-12dB）＞BGM 轨（-18~-20dB）＞环境音底噪轨（-24dB）。
- 对白段 BGM 侧链压低（ducking）或手动拉低 30%。
- 环境音：街道底噪持续铺底保"真实感"；转场处音效先行 0.3 秒。

### 3.4 Foley 音效搜索词库（剪映音效库直搜）
脚步（碎石地/柏油路）、衣袂摩擦、剑鸣出鞘、风声呼啸、孩童笑声、炒菜锅铲、白雾蒸腾嘶嘶声、雷声低鸣、市井嘈杂、硬币落地。

## 四、后期 Lip-Sync 对口型流程（模式B 收尾）

1. Fish Audio/MiniMax 克隆台词音频（含情感标签）。
2. ComfyUI LatentSync / 剪映「对口型」类功能：视频片段 + 音频对齐。
3. 基底必须干净（视频生成阶段已声明"嘴唇自然闭合"）。
4. 导出前核对音节重音与头部动作节拍一致（崩坏16 复查）。

## 五、音色克隆工作卡模板（写入资产文档）

### @李梅 音色克隆卡
- 目标平台：Fish Audio / MiniMax
- 音色特征：温软治愈女声，尾音轻微上扬带暖意，安慰语段气声增多
