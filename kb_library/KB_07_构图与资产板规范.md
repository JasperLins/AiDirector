# KB_07 构图与资产板规范（资产板排版 · 景别构图法则 · 16:9 vs 9:16 自适应）

> 用途：导演分镜与美术资产板的构图权威词库。所有"构图"字段的词必须出自本典，尤其执行防崩补丁2（竖屏构图自适应）。

---

## 一、通用构图法则词典

| 构图法 | 描述词 | 心理效果 |
|---|---|---|
| 中心构图 | 主体居中、对称稳定 | 威严、压场（@林烬比武台） |
| 三分法 | 主体落于左/右三分线 | 自然、电影感 |
| 黄金螺旋 | 视线沿螺旋落点汇聚 | 引导聚焦 |
| 对角线构图 | 主体沿对角线排布 | 动势、冲突 |
| 引导线构图 | 街道/灯串纵深线条引向主体 | 纵深（@光大街边） |
| 框式构图 | 门窗/门洞框住主体 | 窥视感、宿命感 |
| 对称构图 | 中轴对称 | 仪式、庄严 |
| 留白构图 | 大面积负空间 | 孤独、意境 |
| 前景遮挡 | 前景虚化人群/花枝遮挡一角 | 偷窥/临场感 |

## 二、多人空间分区词典（防崩补丁1 · 防串色必用）

| 描述模板 | 说明 |
|---|---|
| `画面左侧三分之一处为[人物A描述]，画面右侧三分之二处为[人物B描述]` | 横向分区标准句式 |
| `前景为[人物A半身背影虚化]，中景焦点为[人物B清晰]` | 纵深分区（过肩镜头） |
| `上下分区：上方高位为[俯视者]，下方为[仰视者]` | 竖屏高低机位用 |
| 体型差三重锚定 | 空间象限 + 身高差具体值 + 服装主色差（如成年女性米白 vs 孩童天蓝） |

## 三、16:9 横屏构图法则（漫剧/横版）

- 允许横向大空间铺开：`宗门广场横向铺开、人群两侧环形围绕、建筑群水平展开`。
- 常用：中心构图+横向展开（压场）、三分法+引导线（街景）、对称纵深（殿宇）。
- 对话正反打：标准过肩（越 A 肩拍 B ↔ 越 B 肩拍 A，轴线两机位）。

## 四、9:16 竖屏构图法则（短剧主力 · 防崩补丁2）

**总则**：禁用横向大铺开，强制切换以下三类：
1. **前中后大纵深叠压构图**：`前景虚化美食摊白雾，中景母子牵手主体清晰，远景居民楼暖灯虚化`——用纵深换横向信息量。
2. **上下高低机位对角线构图**：`高机位俯拍孩童仰望 / 低机位仰拍母亲俯身`，或人物沿画面对角线从头到脚贯穿。
3. **竖屏紧凑过肩正反打**：`越过孩童肩膀的紧凑过肩，母亲面部占画面上半三分之二`。

**竖屏台词镜头额外规则**：面部占画面高度 ≥1/3；字幕安全区预留底部 15%；双人同框用上下半分区代替左右分区。

## 五、资产板排版规范（美术产出）

| 板类型 | 版式规范 | 必含元素 |
|---|---|---|
| 角色资产设定板 | 2x2 或 1x3 网格：主图+三视图+表情格+道具小图 | @资产名水印、比例尺、画风锁标注 |
| 三视图板 | 正/侧/背三视角等距水平排列，顶部留标题栏 | A-Pose、18%灰背景 |

## 六、景别词典（分镜表"景别"字段唯一来源）

大远景（环境主导）、远景（全身+环境）、全景（全身）、中景（膝上）、中近景（腰上）、近景（胸上）、特写（面部）、大特写（眼/手/物局部）。
**竖屏建议**：多用中近景/近景/特写；远景慎用（人物过小）。

## 七、轴线与机位半圆（场记执行标准）

- 180 度轴线规则：一场戏确立轴线（人物 A→B 连线或运动方向线）后，所有机位必须在轴线同一侧半圆内活动；越轴=观众方向感崩塌。
- 允许越轴的合法手段：中性镜头（正对/背对轴线）过渡、骑轴镜头（正俯/正仰）、动作剪辑点越轴（大幅动作遮越轴）。
- 分镜表必须写明：`轴线声明：@李梅（画面左，行进向右）—@张三（画面右），机位锁定轴线南侧半圆`。

## 八、构图连续性自检（场记用）

- [ ] 同场次同景别序列符合"景别递进"（远→全→中→近→特）或刻意跳级有戏剧理由？
- [ ] 9:16 集是否全部规避横向铺开？
- [ ] 多人镜头是否都有空间分区句式？
- [ ] 机位是否全部位于轴线同侧？
- [ ] 前景遮挡元素（白雾/人群）跨镜一致？
