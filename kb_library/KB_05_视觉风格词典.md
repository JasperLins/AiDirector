## 二、渲染引擎与画质词缀

- 引擎感：`虚幻引擎5渲染、OC渲染、Blender Cycles 光线追踪`（3D 类）
- 画质：`8K超高清、超精细细节、大师级构图、获奖短片质感`
- 镜头感：`35mm胶片颗粒、浅景深大光圈、变形宽银幕镜头光晕`
- 负向兜底：`低分辨率、模糊、崩坏、错误 anatomy`（进 KB_09 负向包）

## 三、@画风锁 规范（项目级常量机制）

### 3.1 结构公式
```
@画风锁 = [流派与质感] + [细节颗粒度] + [光影氛围] + [影调色温] + [画质词缀]
```

### 3.2 定稿示例（《苍穹与烟火》）
```
电影级东方新国风写实厚涂质感，细腻皮肤纹理与织物纤维细节，volumetric 体积光氛围，高对比冷暖双色温影调，8K超高清画质，电影感构图
```
- 苍穹线追加缀：`冷青蓝主调+剑气银白高光`
- 烟火线追加缀：`暖金橙主调+黄昏柔焦光晕`

### 3.3 铁律
1. 定义后**不可篡改**；变更须美术指导+编剧双签，全局替换并通知所有未完成分集重编译。
2. 所有生图/生视频 Prompt **末尾逐字挂载**（顺序：内容 → 构图 → 画风锁）。
3. 三视图资产图允许将"体积光氛围"替换为"平光漫反射"（KB_06 零光影铁律优先于画风锁的光影部分，其余逐字保留）。
4. 画风锁字符串在《资产注册表.md》常量区登记，与分集文档顶部声明一致。

## 四、画风一致性自检清单

- [ ] 当前 Prompt 末尾是否逐字含 `@画风锁`？
- [ ] 画风锁内光影词是否与资产图零光影要求冲突？（冲突时按 KB_06 覆盖）
- [ ] 分线追加缀是否正确（苍穹冷/烟火暖）？
- [ ] 生成结果与既有镜头对比：笔触、色温、细节密度是否同源？
- [ ] 是否误混流派（厚涂+赛璐璐平涂同框=废片）？
