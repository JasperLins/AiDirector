# KB_08 Prompt 编译器（生图全量编译公式 + 视频差分编译公式 + 多主体口型排他锁）

> 用途：框架的"编译器内核"。所有中文提示词必须按本典公式"查表拼装"，严禁大模型用空洞形容词自由造句。
> 两个公式：**生图全量编译**（资产/首帧图）与**视频差分编译**（20% 锚点 + 80% 动态）。

---

## 一、生图全量编译公式（资产图 / 首帧基准图）

```
[主体层] @资产名 + 骨相锁定摘要（KB_02 选取，5~8 个特征词）
+ [服饰层] 版型编号+面料+配色+工艺细节（KB_03/KB_04）
+ [动作姿态] 单一明确姿态（站/坐/持物手别）
+ [空间层] 空间分区句式（多人时必填，KB_07）
+ [环境层] @场景资产 + 时间天气 + 关键陈设
+ [光学层] 光线类型+色温+氛围（资产图替换为 KB_06 零光影铁律）
+ [镜头层] 景别+机位+构图（KB_07/KB_11）
+ [画风层] @画风锁（末尾逐字挂载；资产图按 KB_06 覆盖光影词）
+ [规格层] 画幅比例 + 2K/4K
```

**编译示例（@林烬主图）**：
```prompt
青年剑修@林烬，鹅蛋脸下颌线锋利，剑眉入鬓丹凤眼漆黑瞳，鼻梁高挺薄唇微抿，黑色长发束高马尾额前两缕碎发，九头身挺拔；玄黑窄袖劲装银线云纹暗纹刺绣，腰束墨玉扣腰封，右手负剑@焚天断剑于背后；单足立于青石台面中心，衣摆静止垂坠；背景为@玄天宗比武台四角符文石柱与远处云海山岳虚化，雷云冷青天光；低角度仰拍全景，中心构图横向空间展开，@画风锁（电影级东方新国风写实厚涂质感，细腻皮肤纹理与织物纤维细节，volumetric 体积光氛围，高对比冷暖双色温影调，8K超高清画质，电影感构图）+冷青蓝主调剑气银白高光，16:9，4K
```

## 二、视频差分编译公式（I2V 核心：Delta Prompting）

**原理**：I2V 首帧已锁定 90% 静态外观，视频 Prompt 重复堆砌五官穿搭 = 浪费动态算力 + 诱发身份漂移。

```
[锚点层·20%] @资产名 + 最多2个骨相关键词（如"黑衣长发@林烬"）
+ [动态层·80%] 镜头运动（1个）+ 肢体动作轨迹（1主动作+1次级微动作）
              + 材质动态（风吹衣角/发丝/热气/尘埃）
              + 光影变化（光斑移动/明暗渐变，可选）
+ [时长层] 秒级节点 [00-02s]... [02-05s]...（一镜一主动作）
+ [口型层] 模式A：台词+张嘴者+倾听者闭嘴锁；模式B：嘴唇自然闭合基底声明
+ [画风层] @画风锁（末尾挂载）
```

**编译示例（差分版）**：
```prompt
黑衣长发@林烬立于@玄天宗比武台中央，[00-02s]镜头缓慢低角度推近，衣摆与额前碎发被罡风掀起轻扬，[02-05s]他缓缓抬眼扫视四周，指节在剑柄上收紧一下，雷云天光在剑刃上流动一道银白反光，其余人物保持静立，@画风锁
```

## 三、多主体空间分区与口型排他锁（防崩补丁1）

### 3.1 空间分区模板（生图+视频通用，≥2 人必填）
```
画面左侧三分之一处为成年女性@李梅（身高约一米六五，米白针织开衫），
画面右侧三分之二处为孩童@张三（身高约一米一，天蓝小熊耳卫衣），
两人之间保持一臂牵手距离，体型与服装色彩差异清晰
```

### 3.2 口型排他锁模板（多人+台词镜头必填）
- **模式A（原生音画同出）**：
```
说话者@张三抬头张嘴说话，嘴唇随台词自然开合，语速清晰；
一旁的@李梅保持双唇闭合、嘴角含笑低头倾听，面部静止不说话
```
- **模式B（后期对口型）**：
```
@张三抬头面向母亲，面部微表情生动（眼睛瞪圆渴望、小嘴嘟起），但嘴唇保持自然闭合或极轻微闭合微动（预留后期Lip-Sync口型合成干净基底）；@李梅双唇闭合微笑倾听
```
**严禁**：只写台词不写口型归属（崩坏05 一票否决）。

## 四、秒级时间轴编译规范

- 格式：`[00-02s] 动作/运镜；[02-05s] 动作/运镜`；节点间隔 ≥1 秒，单镜 ≤3 个节点。
- 一镜一主动作：主动作（抬眼）+ 次级微动作（指节收紧）+ 环境动态（衣摆、热气），不再叠加第三主动作。
- 台词节点：写明 `[1.5-4.0秒] 开口说台词（台词文本，语气标注）`，时长来自声画先行测算（NARR-03：字数÷语速+停顿）。
- 30 秒长条（即梦 2.5 类）：节点可加密至 5~7 个，但每节点仍单主动作。

## 五、首尾帧/尾帧接力编译规范

- **首尾帧控制**：Prompt 只描述中间过渡运动，不重复首尾帧静态内容；`运镜幅度与首尾帧画面差异匹配`（可灵铁律）。
- **尾帧接力（Tail-to-Head）**：`以上一镜尾帧为首帧` + Prompt 只写增量变化（转身角度、手臂位移、光线推移）。
- 接力时锚点层可进一步压缩至 1 个词（`@林烬`），动态层占比升至 90%。

## 六、编译前置检查清单（评分官 R7 依据）

1. [ ] 所有 `@资产` 均在注册表内且名称纯中文？
2. [ ] 生图：八层齐全（主体/服饰/动作/空间/环境/光学/镜头/画风）？
3. [ ] 视频：锚点 ≤20%？动态 ≥80%？单主动作？秒级节点 ≤3？
4. [ ] 多人：空间分区句式 + 口型排他锁齐备？
5. [ ] 台词：时长测算完成且与镜头时长匹配？模式 A/B 已声明？
6. [ ] 末尾：`@画风锁` 逐字挂载？画幅与分辨率已标注？
7. [ ] 崩坏词规避：无十指交叉/360度转身/镜内切机位/狂奔穿模等黑名单触发词？
