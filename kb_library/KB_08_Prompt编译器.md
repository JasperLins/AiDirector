# KB_08 Prompt 编译器（高密度工业速查版）

> 用途：框架"编译器内核"。所有中文提示词按本典公式查表拼装，严禁大模型用空洞形容词自由造句。
> 本册包含：生图八层全量公式+**可复制母版** ｜ 视频 20/80 差分公式+**可复制母版（三档时长）** ｜ 口型排他锁句式库 ｜ 秒级节点规范 ｜ 首尾帧/接力编译 ｜ 编译前后正反对照 ｜ 前置检查 7 项。

## 一、生图全量编译公式（八层 · 资产图/首帧基准图）

```text
[主体层] @资产名+骨相锁定摘要5~8词(KB_02)
+ [服饰层] 版型编号+面料+配色+工艺(KB_03/KB_04四件套)
+ [动作层] 单一明确姿态+手部状态(五指并拢等)
+ [空间层] 多人分区句式(KB_07二节,≥2人必填)
+ [环境层] @场景资产+时间天气+关键陈设三层
+ [光学层] 光型+色温+过曝防护(KB_04四节;资产图替换为KB_06零光影铁律)
+ [镜头层] 景别+机位+构图(KB_07/KB_11)
+ [画风层] @画风锁(末尾逐字;资产图按KB_06例外条款)
+ [规格层] 画幅+分辨率(2K/4K)
```

**可复制母版（生图）**：
```prompt
[主体：@资产+5~8骨相词+肤色]，[服饰：编号+版型+面料+配色+工艺]，[动作：单一姿态+手部状态]；[空间：多人分区句式/单人省略]；[环境：@场景，前景…中景…远景…，时间天气]；[光学：光型+色温，高光不过曝保留面部细节]；[镜头：景别+机位+构图]；@画风锁+[线别追加缀]，[画幅]，[分辨率]
```

**编译成品示例（@林烬主图）**：
```prompt
青年剑修@林烬，鹅蛋脸下颌线锋利，剑眉入鬓丹凤眼漆黑瞳，鼻梁高挺薄唇微抿，黑色长发束高马尾额前两缕碎发，九头身挺拔，冷白皮细腻；玄黑窄袖劲装(玄铁锦缎，玄黑+银线，云纹暗绣皮甲缚带)，腰束墨玉扣腰封，右手负剑@焚天断剑于背后；站姿笔直，双手负于身后五指自然并拢，左手虎口旧疤清晰可见；背景纯白无接缝；360度环形无影棚拍柔光，均匀漫射平光，漫反射固有色贴图质感（Flat Lit Albedo），正交投影相机零透视畸变，全身完整入画；@画风锁（体积光氛围替换为均匀漫射平光）+冷青蓝主调剑气银白高光，16:9，4K
```

## 二、视频差分编译公式（I2V 核心 · 20% 锚点 + 80% 动态）

**八层分解表**：

| 层 | 占比 | 内容 | 词源 | 违规判定 |
|---|---|---|---|---|
| 锚点层 | ~20% | @资产名+骨相词 ≤2/人 | KB_02 掐尖 | 超 2 词=V2 否决 |
| 运镜动态 | 80%内 | 1 种运镜+幅度词 | KB_11 三/五节 | ≥2 种=V9 扣分 |
| 主动作 | 80%内 | 1 个（可跨节点） | 分镜秒级节点 | 第 2 主动作=V3 否决 |
| 次级微动作 | 80%内 | 1 个（指节收紧/睫毛颤） | KB_02 八节 | 点缀不抢戏 |
| 材质动态 | 80%内 | 衣摆/发丝/白雾/尘埃 | KB_04 三节 | 环境死板=画面假 |
| 光影变化 | 可选 | 光斑移动/天光渐暗 | KB_04 四节 | 强逆光=崩坏10 |
| 口型层 | 独立 | 模式A台词+锁 / 模式B闭嘴基底 | 本典三节 | 缺失=V5/V6 否决 |
| 画风层 | 末尾 | @画风锁+缀+画幅+秒数 | KB_05 | 缺失=V11/V12 扣分 |

**可复制母版（三档时长）**：

```prompt
【5秒标准式】[锚点层]@资产（≤2词）[场景定位]，[00-02s]镜头[运镜+幅度]，[材质动态]+[环境动态]；[02-05s][主动作]+[次级微动作]，[光影变化可选]，[口型/静默声明]，@画风锁+[缀]，16:9，5秒
```
```prompt
【3秒对白式】[锚点层]，[00-00.8s][铺垫微动作]；[00.8-03.0s][台词(引号+语气)+口型排他锁]，@画风锁+[缀]，16:9，3秒
```
```prompt
【10秒长条式】[锚点层]，[0-2秒]…；[2-5秒]…；[5-8秒]…；[8-10秒]…（每段一个次级动作递进，主动作只在其中一段）；[第15秒类中段重锚@资产名]；@画风锁+[缀]，16:9，10秒
```

**编译成品示例（差分视频）**：
```prompt
黑衣长发@林烬立于@玄天宗比武台中央，[00-02s]镜头低角度缓慢推近，衣摆与额前碎发被罡风掀起轻扬，雷云天光渐暗翻涌；[02-05s]他缓缓抬眼扫视四周，右手取@焚天断剑自下而上划出弧线斜指前方，剑身暗红纹路亮起，气流掀动衣摆与马尾定格，台下人群剪影后倾半步，雷云中一道银白光柱落台，双唇闭合无张嘴动作，@画风锁+冷青蓝主调剑气银白高光，16:9，5秒
```

## 三、口型排他锁句式库（模式 A/B · 6 句式）

| 场景 | 句式（逐字可复制） |
|---|---|
| Mode A·多人双锁 | `说话者@X抬头张嘴说话，嘴唇随台词自然开合："[台词]"（[语气+TTS控制符]）；一旁的@Y保持双唇闭合、[神态]倾听，不发一言` |
| Mode A·单人 | `@X张嘴说话，嘴唇随台词自然开合："[台词]"（[语气]）` |
| Mode A·静默镜 | `双唇闭合无张嘴动作`（防全员乱张嘴，崩坏05 对静默镜同样生效） |
| Mode B·基底声明 | `面部微表情生动（[链式描述]），但嘴唇保持自然闭合或极轻微闭合微动（预留后期Lip-Sync口型合成干净基底）` |
| Mode B·倾听者 | `@Y双唇闭合微笑倾听` |
| 双管线选择 | `模式A=即梦/MiniMax H3/可灵原生音频直出；模式B=ComfyUI Wan无声+Fish Audio克隆+LatentSync/剪映对口型` |

## 四、秒级节点编译规范（6 条）

1. 格式 `[00-02s]` / `[0-2秒]`（即梦用"秒"字式）；节点数 ≤3；间隔 ≥1 秒。
2. 全部对齐 0.5 秒网格（继承 NARR-03 精算）；禁"持续地/渐渐地"无锚词。
3. 一镜一主动作；主动作+1 微动作+环境动态为上限。
4. 台词节点写 `[1.5-4.0秒] 开口说台词（"…"，语气）`，时长=字数÷语速+停顿。
5. 30 秒长条节点可加密至 5~7 段，每段仍单动作，第 15 秒重锚。
6. 换运镜指令（MiniMax 类）必须落在节点边界。

## 五、首尾帧与尾帧接力编译规范

- **首尾帧**：Prompt 只写中间过渡运动；`运镜幅度匹配首尾画面差异`（可灵铁律）；禁复述起止静态。
- **尾帧接力（Tail-to-Head）**：`以上一镜尾帧为首帧`；锚点压至 1 词；Prompt 只写增量（新增动作/光移/表情递进）；链 ≤2 段，第 3 段重锚全量首帧。

## 六、编译前后正反对照（❌ 自由造句 → ✅ 查表编译）

❌ **编译前（自由造句）**：
> 一个很帅的黑衣剑客站在气势恢宏的比武台上，周围人山人海，天空电闪雷鸣，他潇洒地拔出剑指向前方，气场全开，画面震撼，电影感拉满。

✅ **编译后（查表）**：
> `黑衣长发@林烬立于@玄天宗比武台中央，[00-02s]镜头低角度缓慢推近，衣摆与额前碎发被罡风掀起轻扬，雷云天光渐暗翻涌，台下人群剪影静立；[02-05s]他缓缓抬眼扫视四周，右手取@焚天断剑自下而上划出弧线斜指前方，剑身暗红纹路亮起，气流掀动衣摆与马尾定格，台下人群剪影后倾半步，雷云中一道银白光柱落台，双唇闭合无张嘴动作，@画风锁+冷青蓝主调剑气银白高光，16:9，5秒`
> **差异**：人山人海→人群剪影（串脸防线）｜潇洒震撼→秒级动作链（可执行）｜气场全开→物理动态+光影（可生成）｜补口型锁与规格。
