# KB_02 人体与面部设计词典（高密度工业速查版）

> 用途：人物外貌描写的唯一权威词库。同一角色的"外貌锁定摘要"一经登记，所有 Prompt 必须逐字复用本典词条（换词=换脸）。
> 词条统计：体型 8 ｜ 脸型 12 ｜ 下颌颧骨 10 ｜ 眉 10 ｜ 眼型瞳色眼神 30 ｜ 鼻唇耳 20 ｜ 发型发色发饰 44 ｜ 皮肤手部 20 ｜ 微表情链 8 组 —— **合计 150+ 词条**。

## 一、头身比与体型词典（8 型）

| 体型代码 | 描述词组 | 适用 |
|---|---|---|
| 婴幼儿比例 | 头身比1:3.5~4、圆润短四肢 | 0~3 岁 |
| 幼儿比例 | 头身比1:4~4.5、圆润短四肢、小翘鼻 | 3~6 岁孩童（如@张三） |
| 少年比例 | 头身比1:6.5、肩窄、四肢修长感初显 | 10~15 岁 |
| 标准成人女 | 头身比1:7、肩宽约1.5头宽、腰臀曲线柔和 | 都市女性 |
| 标准成人男 | 头身比1:7.5、肩宽约2头宽、倒三角微显 | 都市男性 |
| 修长英气男 | 头身比1:8~9（九头身）、肩宽腰窄、长腿 | 玄幻剑修/模特感（如@林烬） |
| 健硕壮汉 | 头身比1:7、虎背熊腰、脖颈粗 | 武将/保镖 |
| 佝偻老者 | 头身比1:6、脊柱微弓、关节突出 | 老年角色 |

**体型差速记（多人同框防串色）**：身高差写具体数值（"母亲一米六五，孩童一米一，差约半米"）优于"一大一小"。

**年龄双向锚铁律（R9-20261005-17 · 候补 25 转正 · 与 KB_01 三节联动）**：头身比词条挂载时必须配语义化解码词（"头身比一比六点五"纯数字不解码）——①女主型（16~18 岁）防上浮：`头身比词条 + 年龄数字 + 身高 + 脸颊微带少女圆润感`；②丫鬟/双髻型（14~16 岁）防塌缩：`头身比词条 + 十五岁及笄硬锚 + 五官已长开、四肢纤长已抽条的亭亭少女身形 + 与十六岁小姐身量相近仅矮小半个头`（反锚三件套缺一不可）；③幼态特征词（稚气未脱/圆脸/大眼/毛茸茸）堆叠 ≥3 个且无反锚＝幼童塌缩直通证（实测 15 岁→5 岁视感）。

## 八、微表情神态词典（8 大情绪 × 四相递进链 · 视频秒级节点专用）

| 情绪 | 基准相→触发相→过渡相→定格相（按秒展开） |
|---|---|
| 喜 | 平静含笑 → 嘴角先单侧上扬 → 眼睛弯成月牙+露齿 → 笑出声肩部轻颤 |
| 怒 | 平静 → 眉骨紧锁+鼻翼扇动 → 咬紧牙关下颌绷出棱角 → 瞳孔收缩定住 |
| 哀 | 平静 → 睫毛颤动垂下 → 嘴角向下微抿+眼眶泛泪光 → 一滴泪滑落 |
| 惧 | 平静 → 瞳孔骤缩+倒吸凉气微张嘴 → 后缩半步 → 手指攥紧衣角 |
| 冷笑 | 平静 → 只扯单侧嘴角 → 眼神下压再缓缓抬起 → 鼻息轻嗤收势 |
| 惊 | 平静 → 眼睛瞪圆+微张嘴倒吸 → 定格两秒 → 缓缓恢复眨眼一次 |
| 温柔安慰 | 平静 → 先弯眼笑 → 伸手轻抚+语气放软尾音上扬 → 眼神先亮后垂(克制的爱) |
| 渴望(孩童) | 平静 → 眼睛瞪圆紧盯+舔嘴唇 → 咽口水喉头微动 → 拽衣角仰头 |

**眨眼规范**：特写 ≥3 秒必标"眨眼频率自然，约三秒一次轻微眨眼"（防崩坏15：死鱼眼/高频抽搐）。

## 九、角色外貌锁定摘要模板（写入资产注册表的唯一格式）

```text
@资产名｜年龄段（含双向锚词）｜头身比（含语义解码词）｜脸型+下颌线｜眉+眼型瞳色｜鼻+唇｜发型发色发饰｜肤色质感｜穿搭索引(KB_03编号)｜记忆点2个｜同框关系锚｜禁用词(易混淆特征)
```
**示例(@林烬)**：`青年22岁｜九头身｜鹅蛋脸下颌线锋利｜剑眉+丹凤眼漆黑瞳｜鼻梁高挺+薄唇微抿｜黑长发高马尾额前两缕碎发｜冷白皮细腻｜GX-01玄黑劲装｜左手虎口旧疤+单侧嘴角冷笑｜同框：与@苏晚晴高差一头、玄黑×月白冷暖呼应｜禁用"笑容灿烂/圆润脸"`
**示例(@杏儿·丫鬟型)**：`十五岁及笄少女（防塌缩三件套：五官已长开+四肢纤长已抽条+与十六岁小姐身量相近仅矮小半个头）｜头身比一比六点五=亭亭少女身形｜…｜同框：矮沈小满小半个头、青绿靛蓝与素青邻色系｜…`
**换词红线**：锁定后"杏眼"不得改"桃花眼"、"栗色"不得改"棕色"——一律回查本典原词条逐字复用。
**同框关系锚必填槽位（R9-20261005-17 · 候补 25 转正）**：多人剧组的主要人物摘要必须填「同框关系锚」槽（高差量化+服色关系+气质关系，详规见 KB_01 三节）——单人剧或纯旁白角色可填"无"；多人同框首帧 Prompt 编译时必须把关系锚展开进主体分区句（"画面左侧…与…仅矮小半个头"），缺失＝R4 场记打回。
**方位换算铁律（R9-20261005）**：摘要可按"人物自身左右"叙事记录；**编译进 Prompt 时必须换算为画面绝对方位**（正面/四分之三侧视图：自身右侧=画面左侧；背身视图单独标注"背身，左右对调"），严禁"自身右·画面左"双表述同现——实测双表述会激活双侧语义，增加镜像与双侧长痣概率。记忆点特征按 KB_08 八节三要素展开（位置锚点+形态比喻+数量尺寸量词）。
