# KB_02 人体与面部设计词典（头身比 · 骨相 · 眼型 · 发型 · 微表情）

> 用途：人物外貌描写的唯一权威词库。生图/三视图/表情矩阵 Prompt 中的所有人体与面部词汇必须从本表选取组合，保证同一角色跨镜跨集描述一致（同一锁定摘要严禁换词）。

---

## 一、头身比与体型词典

| 体型代码 | 描述词组 | 适用 |
|---|---|---|
| 幼儿比例 | 头身比1:4.5、圆润短四肢、小翘鼻 | 3~6岁孩童（如@张三） |
| 少年比例 | 头身比1:6.5、肩窄、四肢修长感初显 | 10~15岁 |
| 标准成人女 | 头身比1:7、肩宽约1.5头宽、腰臀曲线柔和 | 都市女性 |
| 标准成人男 | 头身比1:7.5、肩宽约2头宽、倒三角微显 | 都市男性 |
| 修长英气男 | 头身比1:8~9（九头身）、肩宽腰窄、长腿 | 玄幻剑修/模特感（如@林烬） |
| 健硕壮汉 | 头身比1:7、虎背熊腰、脖颈粗 | 武将/保镖 |
| 佝偻老者 | 头身比1:6、脊柱微弓、关节突出 | 老年角色 |

**体型差速记（多人同框防串色用）**：身高差写具体（"母亲一米六五，孩童一米一，差约半米"），比"一大一小"更抗崩坏。

## 三、眼型与眼神词典

| 维度 | 词库 |
|---|---|
| 眼型 | 丹凤眼（眼尾微挑）、杏眼、桃花眼、下垂眼（无辜）、瑞凤眼、眯缝眼、圆杏眼（孩童） |
| 瞳色 | 漆黑深邃、深棕、琥珀棕、墨绿、灰蓝（玄幻可用金瞳/赤瞳） |
| 睫毛 | 浓密纤长、根根分明、长而微翘（孩童强调） |
| 眼神（静态） | 静水深流、清冷疏离、温润含笑、锐利如鹰、懵懂清澈、疲惫涣散 |
| 眼神（转变，视频用） | 从错愕转为狠戾、由暗淡重新点亮、笑意从眼底漫出、警觉地眯起 |

## 五、微表情神态词典（视频提示词专用，配合秒级节点）

| 情绪 | 递进式微表情链（按时间轴展开） |
|---|---|
| 喜 | 嘴角先单侧上扬 → 眼睛弯成月牙 → 露齿笑 → 笑出声肩部颤动 |
| 怒 | 眉骨紧锁 → 鼻翼扇动 → 咬紧牙关下颌绷出棱角 → 瞳孔收缩 |
| 哀 | 睫毛颤动垂下 → 嘴角向下微抿 → 眼眶泛泪光盈盈 → 一滴泪滑落 |
| 惧 | 瞳孔骤缩 → 倒吸凉气嘴唇微张 → 后缩半步 → 手指攥紧衣角 |
| 冷笑 | 只扯单侧嘴角 → 眼神下压再缓缓抬起 → 鼻息轻嗤 |
| 惊 | 眼睛瞪圆 → 微张嘴倒吸 → 定格两秒 → 恢复 |
| 温柔安慰 | 先弯眼笑 → 伸手轻抚 → 语气放软尾音上扬 → 眼神先亮后垂（克制的爱） |
| 渴望（孩童） | 眼睛瞪圆紧盯 → 舔嘴唇 → 咽口水喉头微动 → 拽衣角仰头 |

**眨眼规范**：特写镜头标注"眨眼频率自然，约三秒一次轻微眨眼"（防崩坏15：死鱼眼/高频抽搐）。

## 六、皮肤与手部细节词典

- 皮肤：细腻光泽、皮肤纹理细腻真实、哑光健康、婴儿肥脸颊透红、风吹微红、苍白如纸、麦色粗糙。
- 手部（高危区，从严描写）：五指自然并拢、单手握拳、指节泛白（用力）、虎口旧疤、掌心老茧；**严禁**"十指交叉""复杂手势比心"（崩坏02）。
- 汗水/泪痕：额角薄汗、泪痕未干、鼻尖冒汗（情绪外化加分项）。

## 七、角色外貌锁定摘要模板（写入资产注册表）

```
@资产名｜年龄段｜头身比｜脸型+下颌线｜眉+眼型瞳色｜鼻+唇｜发型发色发饰｜肤色质感｜穿搭索引(KB_03)｜记忆点2个｜禁用词（易混淆特征）
```
示例（@林烬）：`青年22岁｜九头身｜鹅蛋脸下颌线锋利｜剑眉入鬓+丹凤眼漆黑瞳｜鼻梁高挺+薄唇微抿｜黑长发高马尾额前碎发｜冷白皮细腻｜玄黑劲装(KB_03-GX-01)｜左手虎口旧疤+单侧嘴角冷笑｜禁用"笑容灿烂、圆润脸" `
