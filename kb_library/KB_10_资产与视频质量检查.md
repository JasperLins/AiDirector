## 四、评分输出格式（R7 → 产出文档 · 双模板）

**放行模板**：
```markdown
- **质量关卡得分**：9.X / 10 分（通过！）
- **评分明细与使用建议**：
  - 逐项核验：V1 ✓（资产在册）｜V2 ✓（锚点2词）｜V3 ✓（单主动作）｜V5 ✓（双锁齐）…
  - 扣分说明：V9 幅度词轻微冗余 → 扣0.2（本轮已自动修正复审通过）
  - 使用建议：参考图权重0.7｜ControlNet 0.6｜抽卡2~3次取优｜盯片点…
```

**打回模板**：
```markdown
- **质量关卡得分**：8.X / 10 分（打回！第N轮）
- **打回原因**：V5 ◆ 否决——多人台词未写倾听者闭嘴状态（对应崩坏05）；证据："（引用原文）"
- **修改指令**：在 [0.8-3秒] 节点后原样追加"一旁的@李梅保持双唇闭合、面带微笑低头倾听"；补模式A声明；重写后提交复审。
```

## 五、评分流程（6 步）

1. R5/R6 产出 Prompt → ` ```prompt ` 代码块封装（防崩补丁5）。
2. R7 按对应表逐项核验，每项 ✓/✗ 附原文证据。
3. 计分（10−Σ扣分，一位小数；◆触发强制 ≤8.9）。
4. ≥9.0 → 放行写入产出文档；<9.0 → 打回单下发 R5/R6。
5. 打回 ≤3 轮；第 3 轮仍 <9.0 → "人工裁决"上报用户并抄送 EVO-01。
6. 评分明细随 Prompt 写入产出文档（透明可审计）。

## 六、实测维度质检参考（生成之后 · 用户自查）

- 资产图：三视角比例一致/无光影残留/手部可数/与锁定摘要逐项比对/矩阵同脸。
- 视频片段：动作连贯无撕裂/口型对齐/身份稳定/背景无闪烁/道具在手。
- 发现问题 → 填写 `Prompt 实际产出复盘：` → 触发 EVO-01（KB_09 四节修正工作流）。
