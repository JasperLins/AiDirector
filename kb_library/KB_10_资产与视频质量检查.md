# KB_10 资产与视频质量检查（维度制核查手册 · V3）

> 用途：【AI 提示词质量核查专家 R7】的唯一核查标准（完整权威版）。对每一条资产图/前置资源图/分镜图/视频 Prompt 独立核查。
> 铁律：视频 **8 维** ｜ 生图 **8 层**，**缺一即不通过**；**不打总分、不写分**；每维/每层必须引用证据（Prompt 原文行 / 镜头卡字段 / 资产注册表行），**无证据=判缺失**；修改指令随核查一并下发；打回 ≤3 轮，超限人工裁决。
> 范式版本：V1 扣分制（2026-10-05）→ V2 双擎评分制（R9-20261005-18）→ **V3 维度制（2026-10-25 用户裁决立法：废 10 分自评与逐条复盘占位——自评分数无外部效度；历史文档评分行=代际档案不回写，加挂四节注记行）**。

## 〇、双擎联审门禁总则（L1 Machine Linter + L2 Dimension Checker · V3）

**第一关 · L1 确定性机器硬检（`scripts/qc_linter.py`）**：负责机械语法层——查禁词残留、变量外壳（`@画风锁`/`[光位锁]`）、句首媒介前置词、尾锁画幅格式、`<details>` 零空行语法、视频时间轴节点数（单镜 ≤3·默认；实验路径⑤段级序列式=区间数与图N锚对账）与间隔（≥1.0s）、、跨文件《资产注册表》合法性对账，以及 **prompt 代码块内元话语污染扫描**（勘误/注册表/黑名单/词源/脑补/R9 戳/日期等编译器备注——补丁6 违例即 ERROR·2026-10-26 立）。**凡 `qc_linter.py` 报错未清零，该文档强制打回，严禁人工/AI 越权放行**——L1 未过即产出不可进入核查流程。

**第二关 · L2 维度核查（R7 维度核查官）**：在 L1 机检 `PASS` 的基础上，R7 免去机械查字负担，按 一节（生图八层）/ 二节（视频 8 维）逐层逐维取证核查——每个 ✓/✗ **必须引用证据位**（Prompt 原文片段、镜头卡字段值、注册表行），**无证据的 ✓ 无效，直接判该层/维缺失**。语义深度核验焦点（对应维度）：人设三要素与关系色（⑤/③层）、单镜动作机位纯度与蒙太奇B计划挂载（⑦维）、空间象限与口型排他锁（③⑧维）、20/80 差分纯度（⑤维）、光位轴线跨镜连续性（⑥维）；**场景新物件词源位**（2026-10-26 立·⑤/③层证据扩展）：块内出现引用资产清单之外的可见物件（椅/缸/筐/磨级），核查行必须给词源（注册表行/档案字段/[用户·日期]）或显式标"一次性道具"——两无＝该物件从块内删除。

**核查行双签格式（强制）**：产出文档核查行统一标注 `L1机检: PASS ｜ L2维度核查: 8/8 通过（视频）／ 8层齐（生图）`——单签视为门禁未执行，文档不得定稿。

**双擎与维度表的关系**：L1 的职责已内化为可机器判定子项（禁词/外壳/媒介/画幅/时间轴/注册表对账 → 归入 ⑤一致性 / ①镜头规格 / ⑦动作与时间 的机器子项）；L2 负责证据引用与语义判定——双擎不改维度结构，只改执法方式（机器先扫、逐维后审）。

## 五、核查流程（6 步）

1. R5/R6 产出 Prompt → ` ```prompt ` 代码块封装（防崩补丁5）。

## 七、宫格资产附加核查与高频升级规则
