# KB_10 资产与视频质量检查（10 分制硬性扣分检验表）

> 用途：【AI 提示词质量评分专家 R7】的唯一评分标准。对**每一条**资产图/前置资源图/视频 Prompt 独立评分。
> **铁律：满分 10 分，得分 <9.0 一票否决，强制打回 R5/R6 重写；修改指令必须随评分一并下发。**

---

## 三、评分输出格式（R7 → 产出文档）

```
- **质量关卡得分**：9.X / 10 分（通过！）
- **评分明细与使用建议**：
  - 逐项核验：V1 ✓（资产在册）、V2 ✓（锚点2词，动态占比约80%）...
  - 扣分说明：V4 节点间隔有一处仅0.8秒 → 扣0.2（本轮已自动修正后复审通过）
  - 使用建议：参考图权重建议0.7；ControlNet强度0.6；建议抽卡2~3次取优
```

**打回格式（<9.0 时）**：
```
- **质量关卡得分**：8.3 / 10 分（打回！）
- **打回原因**：V5 触发否决——多人台词镜头未写倾听者闭嘴状态（对应崩坏05）
- **修改指令**：在 [02-05s] 节点后追加"一旁的@李梅保持双唇闭合、面带微笑低头倾听"；重写后提交复审。
```

## 四、评分流程

1. R5/R6 产出 Prompt → 代码块封装（防崩补丁5）。
2. R7 按对应扣分表逐项核验，计算得分（10 − Σ扣分，保留一位小数）。
3. ≥9.0 → 放行写入产出文档；<9.0 → 生成打回原因+修改指令，回传重写。
4. 打回 ≤3 轮；第 3 轮仍 <9.0 → 标注"人工裁决"上报用户。
5. 评分明细随 Prompt 一同写入产出文档（透明可审计）。

## 五、实测维度质检（生成之后，供用户参考的非 Prompt 维度）

- 资产图：三视角比例一致 / 无光影残留 / 手部可数 / 与锁定摘要逐项比对。
- 视频片段：动作连贯无撕裂 / 口型对齐 / 身份稳定 / 背景无闪烁。
- 发现问题 → 填写 `Prompt 实际产出复盘：` → 触发 R9（KB_09 四节修正工作流）。
