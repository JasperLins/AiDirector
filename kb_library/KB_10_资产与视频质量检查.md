# KB_10 资产与视频质量检查（10 分制硬性质检 · 高密度速查版）

> 用途：【AI 提示词质量评分专家 R7】的唯一评分标准（完整权威版）。对每一条资产图/前置资源图/视频 Prompt 独立评分。
> 铁律：满分 10 分，**得分 <9.0 一票否决，强制打回 R5/R6 重写**；修改指令随评分一并下发；打回 ≤3 轮，超限人工裁决。

## 〇、双擎联审门禁总则（L1 Machine Linter + L2 Semantic Scorer · R9-20261005-18 立）

**第一关 · L1 确定性机器硬检（`scripts/qc_linter.py`）**：负责机械语法层——查禁词残留、变量外壳（`@画风锁`/`[光位锁]`）、句首媒介前置词、尾锁画幅格式、`<details>` 零空行语法、视频时间轴节点数（≤3）与间隔（≥1.0s）、以及跨文件《资产注册表》合法性对账。**凡 `qc_linter.py` 报错未清零，R7 评分强制锁定为 0 分打回，严禁人工/AI 越权给分**——L1 未过即产出不可进入评分流程。

**第二关 · L2 导演级语义智检（R7 十分制评分官）**：在 L1 机检 `PASS` 的基础上，R7 免去机械查字负担，100% 聚焦于 Python 无法判断的 **5 大深度语义与视听逻辑核验**：
1. **人设三要素与关系色语义（G2/G3）**：记忆点是否真正包含「画面绝对方位+形态比喻+数量尺寸上限」？服饰是否落实四件套及主仆/情侣关系色呼应？
2. **单镜动作与机位纯度（G11/V3）**：语义上是否严格"一镜一主动作一机位"？是否存在隐性多机位切换？是否命中双人近身抓握/夺物高危物理区需强制挂载「蒙太奇 B 计划」（VIS-01 铁律 7）？
3. **空间象限与口型排他锁语义（G7/V5/V6/V8）**：多人同框是否具备清晰的左中右/前中后物理分区与身高差？说话者张嘴+倾听者闭嘴的排他语义是否严密无歧义？
4. **20/80 差分编译纯度（V2/V9）**：视频 Prompt 是否严守 ≤2 骨相词，把 80% 篇幅留给物理运动轨迹、微表情四相递进与材质动态？
5. **光位与轴线跨镜连续性（G9/V11）**：光位方向、人物左右站位是否与场次 180° 轴线声明及《跨集状态快照》完全自洽？

**评分行双签格式（强制）**：产出文档评分行统一标注 `L1机检: PASS ｜ L2智检得分: 9.X / 10（通过）`——单签视为门禁未执行，文档不得定稿。

**双擎与扣分表的关系**：L1 的职责已内化为 G4/G5/G9/G10/G12 的机器可判定子项（禁词/外壳/媒介/画幅）；L2 继续使用下方 G1~G12 / V1~V12 全表语义判定——双擎不改分值结构，只改执法方式（机器先扫、智检后审）。

## 五、评分流程（6 步）

1. R5/R6 产出 Prompt → ` ```prompt ` 代码块封装（防崩补丁5）。
2. R7 按对应表逐项核验，每项 ✓/✗ 附原文证据。
3. 计分（10−Σ扣分，一位小数；◆触发强制 ≤8.9）。
4. ≥9.0 → 放行写入产出文档；<9.0 → 打回单下发 R5/R6。
5. 打回 ≤3 轮；第 3 轮仍 <9.0 → "人工裁决"上报用户并抄送 EVO-01。
6. 评分明细随 Prompt 写入产出文档（透明可审计）。
