# KB_09 错误修正与 Negative Prompt 词典（生图修正 + 生视频 17 崩坏修正）

> 用途：当生成结果翻车时的"急救手册"。与《全局复盘避坑黑名单》联动：黑名单定触发条件与根因，本典给可执行的修正词与改写方案。

---

## 一、生图错误修正词库

### 1.1 高光阴影污染（资产图出现强光影）
- **修正方向**：强化正面物理描述，弱化否定。
- **修正词组**：`大型柔光箱正面平光加强，360度环形无影棚拍柔光，固有色均匀无明暗过渡，Albedo漫反射贴图质感，均匀顶光加双侧反光板补光`
- **负向补充**：`硬阴影，投影，高光过曝，侧光，伦勃朗光，体积光`（仅在 ComfyUI 类支持负向输入时使用）

### 1.2 透视畸变（三视图近大远小）
- **修正词组**：`严格正交投影，平行视线无消失点，等距视角，平面化贴图视角`

### 1.3 多指/手指粘连
- **修正词组**：`五指自然并拢清晰可数，手部放松垂于身侧`（姿态规避优先）
- **负向**：`多余手指，六指，手指粘连，畸形手`

### 1.4 三视图复制人/三个相同人物
- **修正词组**：`同一角色的三个连续视角，非三个人物，角色设定图（model sheet），非合影`
- **负向**：`三个不同人，合影，多人`

### 1.5 双人融合/串色
- **修正词组**：空间分区句式强化（KB_07）+ `两人轮廓边缘清晰分离，无身体接触面融合`
- **负向**：`双人融合，肢体融合，连体`

### 1.6 文字乱码（招牌/字幕）
- **修正词组**：`招牌字迹虚化不可辨认，景深模糊背景元素`
- **负向**：`清晰文字，可读文本`（需要清晰文字一律走剪映后期贴字）

### 1.7 儿童画成缩小版成人
- **修正词组**：`幼儿头身比1:4.5，婴儿肥脸颊，大圆眼占比大，短四肢圆润`
- **负向**：`成人比例，九头身`

### 1.8 画风漂移（与既往镜头不同源）
- **修正词组**：@画风锁逐字重挂 + 附参考图 + `与参考图同一画风同一笔触同一色温`

## 二、生视频 17 崩坏修正速查（编号对应黑名单 01~17）

## 四、修正工作流（翻车后 4 步）

1. **定位**：对照黑名单 17 类 + 本典速查表编号定位崩坏类型。
2. **改词**：套用对应 Prompt 级修正写法重编译（只改崩坏相关层，其余层保持逐字不动，防二次漂移）。
3. **换法**：改词两轮仍翻车 → 升级技法级修正（ControlNet/首尾帧/降级 B 级静态图）。
4. **归档**：把触发 Prompt 片段与现象填入复盘占位，由 R9 归档进黑名单实战区。
