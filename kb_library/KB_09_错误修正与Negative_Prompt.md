## 三、标准负向词包（双母版 · 可直接复制挂载）

**生图母版（ComfyUI/Flux/SD 系）**：
```prompt
多余手指, 六指, 手指粘连, 十指交叉, 面部扭曲, 五官移位, 高光过曝, 硬阴影, 透视畸变, 双人融合, 三个相同人物, 复制人, 文字, 乱码, 水印, 签名, 低分辨率, 模糊, 噪点, 肢体比例错误, 器官错误, 畸形, 过饱和, 塑料感, 画风混杂, 成人比例孩童
```

**生视频母版（支持负向输入端）**：
```prompt
镜头切换, 机位跳切, 人物瞬移, 全员张嘴, 多人张嘴, 口型大开, 身份漂移, 面部变化, 肢体穿模, 腿部穿模, 手指畸形, 背景闪烁, 卡顿, 拖影, 鬼影, 色彩断层, 画面撕裂, 文字出现, 水印, 360度旋转
```

**使用规则**：①只挂支持负向输入的端（ComfyUI 系）；豆包/即梦/可灵等以正向物理式规避为主，本包供平台支持时兜底。②按任务裁剪（对白镜必留口型三词；多人镜必留融合两词）。③新增崩坏编号（18+）同步补词入包（EVO-01 职责）。④**平台分流铁律（R9-20261005）**：纯自然语言平台（ChatGPT/大香蕉 Nano Banana/豆包）**严禁在正文堆砌"不要X/无X"式内容否定**（粉色大象效应，越说越画）——一律转为正向排他句（"其余面部肌肤光洁无瑕""双手空无一物"），见 KB_08 八节第 4 条；指令级版式/机位约束（"严禁多视图分格"）不受此限。

## 四、修正工作流（翻车后 4 步闭环）

1. **定位**：对照第一节大表按症状命中编号（口语症状先过 EVO-01 的 4.1 字典规范化）。
2. **改词**：套用 Prompt 级修正写法重编译——**只改崩坏相关层，其余层逐字不动**（防二次漂移）。
3. **换法**：改词两轮仍翻车 → 升级技法级修正（ControlNet/首尾帧/降级 B 级静态图）。
4. **归档**：触发 Prompt 片段与现象填入复盘占位 → EVO-01 归档黑名单实战区并按高频规则升级 KB_10 否决项。
