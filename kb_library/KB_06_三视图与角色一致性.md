# KB_06 三视图与角色一致性规范（高密度工业速查版）

> 用途：重要资产图（三视图/表情矩阵/立绘/特写）生成铁律库。
> 核心原则：**用正面物理状态描述替代否定词**——扩散模型对"无高光无阴影"不敏感，对"平光/Albedo/正交投影"等物理事实高度敏感。
> 本册包含：正反词组对照公式 ×22 组 ｜ 姿态规范 6 式 ｜ 五件套清单 ｜ **五套可直接复制的编译母版** ｜ 防多头怪四步指南 ｜ 锁脸权重表 ｜ 质检对照清单。

---

## 一、零光影正交核心词组 · 正反对照公式（22 组 ❌否定式 → ✅正面物理式）

| 维度 | ❌ 错误否定式（失效） | ✅ 正面物理式（逐字编译） |
|---|---|---|
| 布光(4) | ~~无高光~~ | `360度环形无影棚拍柔光` |
| | ~~不要阴影~~ | `均匀漫射平光（Flat Even Lighting）` |
| | ~~光要均匀~~ | `大型柔光箱正面平光` |
| | ~~没有明显光比~~ | `影棚基准平光，受光面与背光面明度差极小` |
| 贴图(3) | ~~不要反光~~ | `漫反射固有色贴图质感（Flat Lit Albedo）` |
| | ~~哑光一点~~ | `PBR 漫反射贴图（Diffuse Pass）质感` |
| | ~~像手办的表面~~ | `哑光固有色，无镜面反射` |
| 投影(3) | ~~不要透视~~ | `正交投影相机（Orthographic Projection）` |
| | ~~别近大远小~~ | `平行视线无消失点，零透视畸变` |
| | ~~平面化一点~~ | `等距视角（Isometric-flat）贴图式呈现` |
| 背景(3) | ~~背景干净~~ | `中性18%灰背景` |
| | ~~纯色背景~~ | `纯白无接缝背景（Seamless Backdrop）` |
| | ~~别出现场景~~ | `背景无任何环境元素，仅纯色基底` |
| 姿态(3) | ~~手臂自然下垂~~（衣袖粘连） | `A-Pose双臂自然微张约30~45度` |
| | ~~标准站姿~~ | `T-Pose双臂水平展开`（展袖需求专用） |
| | ~~站好别动~~ | `双脚与肩同宽站立基准，头部正视前方` |
| 版式(3) | ~~三个角度~~ | `正面、左侧面、背面三视角等距水平排列` |
| | ~~多视图~~ | `角色设定三视图（Turnaround Sheet / Model Sheet）` |
| | ~~别画成多个人~~ | `同一角色三个视角比例严格一致（非三个人物，非合影）` |
| 通用(3) | ~~简洁一点~~ | `信息密度仅保留角色本体与必要道具` |
| | ~~高质量~~ | `超精细细节，8K超高清` |
| | ~~专业设定图~~ | `animation model sheet，industry character sheet standard` |

**英文对照串**（ComfyUI/Flux 等英文语义强模型直接使用）：
`character turnaround sheet, three view (front / side / back), orthographic projection, A-pose, full body, consistent proportions, flat lighting, albedo map style, neutral white background, model sheet layout`

## 二、姿态规范词典（6 式）

| 姿态式 | 描述词 | 适用 |
|---|---|---|
| A-Pose(首选) | 双臂微张30~45度、掌心朝内、五指自然分开贴腿侧 | 绝大多数角色（防衣袖粘连） |
| T-Pose | 双臂水平展开90度、掌心朝前 | 宽袖/披风完整展示 |
| 自然立正 | 双脚与肩同宽、垂手、正视 | 主图/立绘 |
| 微侧立 | 身体转向15度、头回正 | 主图增加体积感 |
| 坐姿基准 | 正坐椅上、双手置膝、双足落地 | 坐姿角色资产 |
| 道具持握式 | 单手持道具45度朝镜头、另一手自然垂 | 道具三视图（防手遮结构） |

## 四、五套可直接复制的编译母版（[ ]=注册表锁定摘要填空）

**母版① 人物主图**：

## 五、三视图切分单人参考防多头怪指南（四步）

**问题**：视频/单镜生图模型把三视图识别为"三个人同框"→ 复制人、全员乱张嘴、串脸（崩坏05/06 前置）。
1. **选格**：从三视图裁"正面"单格（侧面格备侧拍镜）。
2. **补图**：分辨率不足时以该格为图生图参考（重绘 0.3）重出高清单人——用母版⑤。
3. **特写**：另出母版④ 面部特写——多图参考锁脸首选。
4. **入位**：即梦素材位"立绘 1 位+特写可选 1 位"；ComfyUI PuLID/IP-Adapter 挂特写；可灵首帧用立绘合成图。
**红线**：素材位/首帧/ControlNet 参考位出现完整三视图或矩阵图=防呆违规。

## 六、锁脸手段权重表（跨镜一致性）
