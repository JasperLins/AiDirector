# KB_06 三视图与角色一致性规范（正交三视图 · Albedo 零光影铁律 · 锁脸规范）

> 用途：重要资产图（人物三视图/表情矩阵/立绘/特写）的生成铁律库。核心原则：**用正面物理状态描述替代否定词**——扩散模型对"无高光无阴影"不敏感，但对"平光、Albedo、正交投影"等物理事实描述高度敏感。

---

## 一、零光影正交三视图铁律（核心词组，逐字编译）

```
360度环形无影棚拍柔光，均匀漫射平光，漫反射固有色贴图质感（Flat Lit Albedo / Diffuse Pass），
正交投影相机（Orthographic Projection）零透视畸变，中性18%灰背景（或纯白背景），
A-Pose双臂自然微张约30~45度（或T-Pose双臂水平展开），角色设定三视图（Turnaround Sheet）：
正面、左侧面、背面三视角等距水平排列，同一角色三个视角比例严格一致，全身体现完整造型
```

**英文对照串**（ComfyUI/Flux 等英文语义强模型使用）：
`character turnaround sheet, three view (front / side / back), orthographic projection, A-pose, full body, consistent proportions, flat lighting, albedo map style, neutral white background, model sheet layout`

## 二、为什么必须这样写（原理速记）

| 错误写法 | 为什么失效 | 正确写法 |
|---|---|---|
| 无高光、无阴影 | 否定词反而注入"高光/阴影"概念激活 | 360度环形无影棚拍柔光 / 均匀漫射平光 |
| 不要透视 | 模型不懂"不要" | 正交投影相机零透视畸变 |
| 干净背景 | 太弱，易生成场景 | 中性18%灰背景 / 纯白无接缝背景 |
| 双臂自然下垂 | 衣袖与躯干粘连（崩坏08） | A-Pose 双臂自然微张 |

## 三、姿态规范

- **A-Pose（首选）**：双臂微张 30~45 度，防衣袖粘连，适合绝大多数角色。
- **T-Pose**：双臂水平展开，适合需要完整展示宽袖/披风的服装。
- 双脚与肩同宽站立基准；头部正视前方（正面图）/侧脸 90 度（侧面图）/背对（背面图）。
- 幼儿角色（如@张三）同样适用，头身比按 KB_01/02 年龄段锁定。

## 四、单镜头参考防呆（三视图 vs 视频/单图输入的关键区分）

1. 三视图**只用于**：人设存档、跨集对照、LoRA 训练参考、Inpainting 锁脸参考。
2. 喂给**图生视频/单镜生图**时，必须先裁切：
   - `独立正面全身立绘图`（单一视角、平光可保留但可允许轻光影）
   - `独立面部特写图`（发际线到锁骨、正面平光）
3. 否则视频模型将三视图识别为**三个人同框**→ 复制人/乱张嘴/串脸（崩坏05/06 前置诱因）。
4. 因此资产库每位人物必须产出五件套：**主图 + 三视图 + 表情矩阵 + 面部特写 + 全身立绘**。

## 五、表情矩阵规范（喜怒哀惧冷笑等）

- 版式：`3x3 九宫格表情矩阵图，同一@资产名角色，统一正面半身构图与平光，仅面部表情不同`。
- 必含格：平静（基准）、喜（露齿笑）、哀（含泪）、怒（眉锁咬牙）、惧（瞳缩后缩）、冷笑（单侧嘴角）。
- 选配格：惊讶、沉思、委屈、狠戾、温柔笑、困倦。
- 用途：视频"微表情递进"的表情锚点参考；Inpainting 面部替换的表情源。

## 六、锁脸规范（跨镜跨集一致性）

1. **参考图链**：所有含该角色的镜头，首帧生图必须挂载该角色参考图（面部特写优先）。
2. **ComfyUI 锁脸**：PuLID（ID 锁定，权重 0.6~0.8）/ IP-Adapter Face（0.5~0.7）；LoRA 角色专属模型权重 0.6~0.85，>0.9 画风僵硬。
3. **即梦/豆包**：多图参考中人物参考图置首位，Prompt 中 `@资产名` 引用并复述 2~3 个骨相关键词（丹凤眼+剑眉+高马尾）。
4. **接力镜头**：第 3 镜起刷新首帧锚定（崩坏09），或直接以上一镜尾帧为新首帧。
5. **微调而非重述**：视频阶段差分编译（KB_08），20% 锚点即可，不重复全量外貌。

## 七、场景与道具的一致性变体

- 场景：全景图（俯视/轴测）+ 空镜基准图（主机位视角、无人物）+ 可选时段派生（@光大街边夜）。
- 道具：三视图同人物规范；额外产 `特写基准图`（浅景深、无手部持握，规避手部崩坏）。

## 八、质检对照（送 KB_10 评分前的自查）

- [ ] 三视图三视角是否同比例、同间距、无透视？
- [ ] 是否残留高光/投影/环境色反光？（Albedo 检查：衣物阴影面与受光面明度差应极小）
- [ ] A-Pose 手臂与躯干之间是否留有清晰空隙？
- [ ] 表情矩阵是否同一张脸（骨相一致）？
- [ ] 是否已产出面部特写与全身立绘两个单视角衍生图？
