# KB_11 导演镜头与动态运镜词典（景别 · 机位角度 · 物理运镜）

> 用途：导演分镜表"景别/机位/构图/画面/运镜"字段的唯一词源。视频差分编译的"动态层 80%"主要从本典取词。

---

## 一、景别词典（与 KB_07 六节联动）

大远景、远景、全景、中景、中近景、近景、特写、大特写。
**功能速记**：大远景定世界、全景定关系、中近景给情绪、特写给爆点。

## 四、高级电影运镜词典

|---|---|---|
| 希区柯克变焦（Dolly Zoom） | 推镜头同时变焦，背景空间压缩/膨胀 | 惊觉、世界观崩塌 |

## 五、运镜幅度控制规范（可灵铁律：幅度匹配画面差异）

| 幅度 | 描述词缀 | 适用 |
|---|---|---|
| 微幅 | 轻微、缓缓、缓慢 | 情绪戏、B级 |
| 中幅 | 平稳、匀速 | 常规 A 级 |
| 大幅 | 快速、急速 | S 级爆点（须首尾帧锚定） |

**匹配规则**：首尾帧画面差异大 → 运镜幅度写大；差异小 → 写"缓慢"，否则运镜指令不执行（可灵实测）。

## 六、运镜与崩坏规避对照

- 摇镜 + 高频重复纹理背景 → 必加"背景虚化"（崩坏17）。
- 环绕 + 多人 → 空间分区句式必须保留（崩坏06）。
- 大幅推近 + 手部特写 → 降为微幅（崩坏01）。
- 单镜内严禁组合"推+摇+环绕"≥2 种主动运镜（V9 扣分）。
- 一镜一运镜 + 一次动态变化，是 5 秒镜头的安全上限。

## 七、场面调度词典（Mise-en-scène）

- 入画出画：`人物自画面左侧入画`（方向与轴线一致）。
- 前后景置换：`前景人物虚化后景人物走入焦点`。
- 静动对比：`人群静止唯主角衣摆翻飞`。
- 视线引导：`人物视线投向画外右下方，下一镜揭示其所见`。

## 八、分镜表填写规范（R2 输出）

```
镜号｜场次｜景别｜机位｜构图｜运镜(1种+幅度)｜时长秒｜等级S/A/B｜@资产清单｜台词引用(口型模式)｜秒级节点摘要
```
