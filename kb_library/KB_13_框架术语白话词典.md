# KB_13 框架术语白话词典（中英对照 · 面向人类导演的唯一术语总入口）

> 用途：全框架术语的**唯一权威白话源**——每个术语＝中文主导名（英文括注）＋一句白话。所有面向人类阅读的产出文档头部「📖 术语速查」精简行均出自本典（可按文档实际用词裁剪）；镜区块标题英文术语一律**中文主导＋英文括注**格式。
> 分工去重：框架自造术语以本典为唯一权威；影视后期术语（转场/变速/混音 dB）详解在 KB_12；镜头语言与运镜详解在 KB_11——本典只给一句白话并指回。
> 使用铁律：新术语入框架（R9 立法/新技法命名）必须同步在本典登记，未登记术语不得进入面向人类的产出文档。

## 一、框架自造术语（38 条 · 本典唯一权威）

| 术语 | 白话释义 |
|---|---|
| **画风锁**（Style Lock） | 项目级画风常量字符串（≤35 字），挂在每条 Prompt 末尾逐字复用，防止画风漂移；按人物/场景/道具分三级 |
| **光位常量**（Lighting Lock） | 每个场景定义的固定光方向描述（≤25 字），同场景所有镜头一致挂载，防止光影跳变 |
| **风格预设包**（PACK-01~04） | 一套打包好的画风方案：媒介词＋尾锁矩阵＋光影轨道＋禁词表＋年龄基线＋传染协议六件套，新剧整包取用 |
| **八层黄金语序**（8-Layer Golden Order） | 生图 Prompt 的固定层序：①句首媒介词→②表情+构图→③身份年龄记忆点→④服饰→⑤姿态手部→⑥空间三层→⑦光影轨道→⑧尾锁规格——层序错乱＝画风崩 |
| **差分编译**（Delta Prompting · 20/80） | 视频 Prompt 只写 20% 人物锚点＋80% 运动变化——长相衣服全在底图里，重复描写反而崩 |
| **无损膨胀**（Lossless Expansion） | 一句剧本含多个连续动作时拆成多个独立单镜（拆 1 为 3），细节零删减 |
| **信息守恒**（Info Conservation） | 剧本里的情感铺垫/情节推动细节必须 100% 变成分镜，禁止为省镜头数删戏 |
| **单镜时空唯一性**（One Shot One Spacetime） | 一条视频 Prompt 只描述一个 3~5 秒连续时空——AI 不会剪辑，塞两个机位＝像素融化 |
| **蒙太奇拆镜防崩**（Montage Split） | "关键动作"与"细腻表情"禁止同框——拆成 A 纯动作特写＋B 纯面部特写两个镜 |
| **蒙太奇B计划**（Montage Plan B） | 高危交互镜（抓腕/夺物等）必配的 3 切快剪救场方案：起势特写→接触点定格微距→结果反应，主方案废片即切换 |
| **接力段（R 镜号）**（Relay Segments · 02R-A/B/C） | 伪一镜到底的分段渲染标记——剧本连贯段落拆 A/B/C 段生成，剪辑后视觉无缝 |
| **一镜到底拆解重组**（Long-Take Recomposition） | 长镜高阶管线：多图参考锁轨迹＋尾帧接力分段＋剪辑拼接，突破 5 秒限制 |
| **中帧锚**（Mid-Keyframe Anchor） | 三段接力的中段关键帧图（首帧同源改三点产出）——有它才能安全接力 3 段，没有则最多 2 段 |
| **同框关系锚**（Pairing Anchor） | 双人同框时的身份关系描述（高差量化＋服色关系＋气质关系），让观众一眼读出人物关系 |
| **年龄双向锚**（Age Bidirectional Anchor） | 年龄防漂移双保险：女主型防"上浮变熟"配稚气词；丫鬟型防"塌缩变幼"配"及笄/已长开/矮半个头"三件套 |
| **三图试金石**（3-Shot Litmus Test） | 新剧绑定风格包后必先跑的 3 张校准图（主角立绘/跨时代配角/主场景空镜），全过才准批量 |
| **四道闸门**（4-Gate Pipeline） | 生产流水线四关卡：①试金石定锚→②资产扩展→③样板首帧→④全集放行——严禁跳闸批量 |
| **双擎联审**（L1+L2 Dual Gate） | 质量门禁双签字：L1＝Python 机检查语法（禁词/格式），L2＝R7 智检查视听语义——L1 不过强制 0 分 |
| **崩坏编号**（Defect No.01~33） | 黑名单里登记的 33 类 AI 生成翻车类型编号（手部融化/串脸/穿模等），评分与复盘按编号对号入座 |
| **画风基准传染**（Style Contagion） | 全剧首张人物基准图作为画风标尺，后续资产生图全部垫它作画风参考 |
| **垫图透视排他**（Reference Perspective Exclusion） | 分镜机位与垫图机位冲突时禁止垫图（俯瞰图垫平视镜＝缝合怪），宁盲抽不垫错图 |
| **群组绑定**（Group Binding） | 写多人 NPC 群组（使者/守卫）必须先绑相对距离（"并肩紧凑而立"）再给全局坐标，否则被随机打散 |
| **S·A·B 分级**（Shot Tiering） | 镜头算力分档：S 级奇观核心镜用顶级资源，A 级常规，B 级零视频（静态图＋剪映关键帧） |
| **切出缓冲镜配额**（Cutaway Quota） | 每 2~3 个主镜头配 1 个 1~2 秒插入镜的节奏缓冲定额（≥15%） |
| **状态快照**（State Diff） | 每集结束时的人物/道具/时间/情绪登记表，下集开拍前核对防穿帮 |
| **场景机位库**（Scene Camera Grid） | 一张 3x3（室内可 2x2）宫格图同时产出同一场景多个机位视角（俯瞰/平视/仰拍/纵深等），逐格裁切补高清后作各分镜垫图弹药库，减少垫图透视排他冲突下的盲抽（R9-20261006-6） |
| **头身分区设定板**（Head-Body Split Sheet） | 3+3 六格人物设定板：上排三角度头像满分辨率特写+下排无头人台正侧背服饰——头部细节不因全身等比缩小而丢失；只锁设定禁入参考位（R9-20261006-7） |
| **非人形分区轮转板**（Creature Turnaround Grid） | 3x2 六格非人形设定板：上排头部三视角特写+下排全身三视角+尺寸标注——怪兽/灵宠/机甲/大型道具的形体锁定件，与形态矩阵（状态轴）正交互补（R9-20261006-7） |
| **分镜图总控大师**（Storyboard Master · R10） | 视频生成之前的分镜图生产总关卡角色——对"每个镜头先出什么图、图与图如何保一致"负全责，产出《分镜图生产单》作为 R5 开工令（R9-20261007-14） |
| **分镜图生产单**（Storyboard Production Order） | R10 产出的开工令文档：镜组划分＋组模式＋参考图分配表＋一致性链声明＋分段方案＋抽卡预算——无此单 R5 不得逐镜生图 |
| **镜组四模式**（4 Group Modes A/B/C/D） | R10 的镜组路由模式：A 多分镜宫格组（同场连续镜一次生成）／B 单帧+尾帧锚（S 级双锚）／C 接力链（超上限长镜）／D 多图参考组（长镜多机位轨迹锚） |
| **一致性链**（Consistency Chain） | 每个镜组的锚点传递路径声明：垫哪些参考图→组内如何同源→跨组复用哪个锚——没有一致性链的生产单=未完成 |
| **按叙事设计、按上限分段**（Design by Story, Split by Limit） | 长视频宪法：镜头时长由叙事决定（10s/20s/30s 自由设计），平台上限只是生产参数——分段公式 ⌈时长÷上限⌉ 自动切接力链，永不迁就上限砍叙事 |
| **多分镜宫格组**（Multi-Shot Grid Group） | 同场 ≥3 连续镜合成一张宫格（2x2~5x4）一次生成全部分镜图——格间同源互锚，逐格裁切即首帧，抽卡预算约为逐镜独立生产的 1/10~1/3 |
| **多图参考组**（Multi-Reference Group） | 用机位库子图作多图参考的关键帧轨迹锚——长镜内镜头从机位A视角渐变到机位B视角，用两（三）张机位图锁运动轨迹 |
| **统一资产 DNA**（Unified Asset DNA） | 一致性六法之首：先固化角色/场景参考图资产（主图/三视图/机位库），所有分镜图生产必须挂这些锚——一致性是工作流产物不是模型赠品（KB_14 二节） |
| **运镜图鉴**（Camera Movement Atlas · KB_15） | 47 式运镜案例图鉴（编号+定义+适用+风险），R2 选运镜/R6 选动态词/R10 评估渐变合法性的选型速查册——选型查 KB_15、写法查 KB_11、冲突以 KB_11 为准（R9-20261007-15） |

## 二、影视视听术语速查（15 条 · 详解指回 KB_11/KB_12）

| 术语 | 白话释义 | 详解 |
|---|---|---|
| **切出缓冲镜**（Cutaway） | 临时切离主体拍 1~2 秒相关物/反应再切回——情绪垫、遮瑕疵、埋伏笔（⚠️非工程"剖面图"） | KB_11 |
| **声音先入**（J-Cut） | 下一镜的声音提前半秒进入本镜尾，听觉先导引转场 | KB_12 七节 |
| **声音延出**（L-Cut） | 本镜声音延续到下一镜头画面，余韵不断 | KB_12 七节 |
| **拟音**（Foley） | 后期补录的动作音效（脚步/衣料/落针叮响），剪映音效库直搜 | KB_12 五节 |
| **副镜头素材**（B-Roll） | 主线外的补充画面素材（空镜/细节），Cutaway 的素材来源 | KB_11 |
| **极限特写**（Macro） | 微距大特写（睫毛颤/指尖触针尖），算力专注单点画质极高 | KB_11 |
| **正反打**（Shot/Reverse Shot） | 对话双方交替各拍一方的标准剪辑法 | KB_11 |
| **180度轴线**（180° Axis） | 同场对话 imaginary 连线，摄像机只在轴线一侧半圆活动，越轴＝观众方位混乱 | KB_11 |
| **景别系列**（Shot Size） | 远景/全景/中景/近景/特写/大特写六级取景范围 | KB_11 |
| **关键帧插值**（Keyframe Interpolation） | 向视频模型同时喂首/中/尾多张关键帧图，锁定运动轨迹 | KB_08 五节 |
| **尾帧接力**（Tail-to-Head Relay） | 上一段视频截最后一帧修复后作下一段首帧，链式续接长镜头 | KB_08 五节 |
| **匹配剪辑**（Match Cut） | 接缝两侧保持同一运动方向延续，剪点不被察觉 | R8 技能 4.5 |
| **过肩镜头**（Over-the-Shoulder） | 越过一方肩膀拍另一方的对话构图 | KB_11 |
| **声画先行**（Audio-First / Pre-lay） | 先按字数语速精算音频时长与重音点，再倒推画面秒级动作 | KB_08 |
| **蒙太奇**（Montage） | 多个短镜头快速组接表达时间流逝/情绪累积的剪辑手法 | KB_12 |

## 三、平台与工程术语（10 条）

| 术语 | 白话释义 |
|---|---|
| **图生视频**（I2V · Image-to-Video） | 上传一张首帧图＋运动描述生成视频——静态信息全在图里 |
| **文生视频**（T2V） | 纯文字生成视频（无底图盲抽），一致性弱，仅特定空镜用 |
| **首尾帧**（First/Last Frame） | 视频模型同时喂起点图和终点图，只生成中间过渡 |
| **素材位/参考位**（Reference Slots） | 即梦/豆包等平台上传参考图的栏位（人物/场景各占位） |
| **垫图**（Reference Image） | 生图/生视频时上传的参考图——垫对锦上添花，垫错透视缝合 |
| **基准图**（Base Image） | 资产的官方标准图（人物主图/场景全景），后续一切生成以它为参照 |
| **文生图盲抽**（ Blind Gen） | 无任何参考图纯文字出图——地貌易幻觉，需防穿帮法则保护 |
| **LUT / 滤镜**（Look-Up Table） | 统一调色预设——接力段全链必须同一 LUT 复制粘贴 |
| **G 表 / V 表**（G1~G12 / V1~V12） | R7 评分官的生图 12 项/视频 12 项扣分检查表编号 |
| **修复/高清放大**（Upscale & Restore） | 截帧模糊时用 AI 提质（接力尾帧的标配处理） |
