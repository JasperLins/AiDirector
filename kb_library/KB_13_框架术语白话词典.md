# KB_13 框架术语白话词典（中英对照 · 面向人类导演的唯一术语总入口）

> 用途：全框架术语的**唯一权威白话源**——每个术语＝中文主导名（英文括注）＋一句白话。所有面向人类阅读的产出文档头部「📖 术语速查」精简行均出自本典（可按文档实际用词裁剪）；镜区块标题英文术语一律**中文主导＋英文括注**格式。
> 分工去重：框架自造术语以本典为唯一权威；影视后期术语（转场/变速/混音 dB）详解在 KB_12；镜头语言与运镜详解在 KB_11——本典只给一句白话并指回。
> 使用铁律：新术语入框架（R9 立法/新技法命名）必须同步在本典登记，未登记术语不得进入面向人类的产出文档。

## 一、框架自造术语（67 条 · 本典唯一权威 · 2026-10-25 对账：R9-20261025-49 新增 3 条〔三视图锚点合一参考图/辨识度降序/性格气质转化〕；R9-20261025-48 对标吸收新增 5 条〔结束态锚定/声音事件层/空气层/拍点表/声桥生成位〕）

| 术语 | 白话释义 |
|---|---|
| **画风锁**（Style Lock） | 项目级画风常量字符串（≤35 字），挂在每条 Prompt 末尾逐字复用，防止画风漂移；按人物/场景/道具分三级 |
| **光位常量**（Lighting Lock） | 每个场景定义的固定光方向描述（≤25 字），同场景所有镜头一致挂载，防止光影跳变 |
| **风格预设包**（PACK-01~04） | 一套打包好的画风方案：媒介词＋尾锁矩阵＋光影轨道＋禁词表＋年龄基线＋传染协议六件套，新剧整包取用 |
| **八层黄金语序**（8-Layer Golden Order） | 生图 Prompt 的固定层序：①句首媒介词→②表情+构图→③身份年龄记忆点→④服饰→⑤姿态手部→⑥空间三层→⑦光影轨道→⑧尾锁规格——层序错乱＝画风崩 |
| **差分编译**（Delta Prompting · 20/80） | 视频 Prompt 只写 20% 人物锚点＋80% 运动变化——长相衣服全在底图里，重复描写反而崩 |
| **无损膨胀**（Lossless Expansion） | 一句剧本含多个连续动作时拆成多个独立单镜（拆 1 为 3），细节零删减 |
| **信息守恒**（Info Conservation） | 剧本里的情感铺垫/情节推动细节必须 100% 变成分镜，禁止为省镜头数删戏 |
| **单镜时空唯一性**（One Shot One Spacetime） | 一条视频 Prompt 只描述一个 3~5 秒连续时空——AI 不会剪辑，塞两个机位＝像素融化 |
| **蒙太奇拆镜防崩**（Montage Split） | "关键动作"与"细腻表情"禁止同框——拆成 A 纯动作特写＋B 纯面部特写两个镜 |
| **蒙太奇B计划**（Montage Plan B） | 高危交互镜（抓腕/夺物等）必配的 3 切快剪救场方案：起势特写→接触点定格微距→结果反应，主方案废片即切换 |
| **接力段（R 镜号）**（Relay Segments · 02R-A/B/C） | 伪一镜到底的分段渲染标记——剧本连贯段落拆 A/B/C 段生成，剪辑后视觉无缝 |
| **一镜到底拆解重组**（Long-Take Recomposition） | 长镜高阶管线：多图参考锁轨迹＋尾帧接力分段＋剪辑拼接，突破 5 秒限制 |
| **中帧锚**（Mid-Keyframe Anchor） | 三段接力的中段关键帧图（首帧同源改三点产出）——有它才能安全接力 3 段，没有则最多 2 段 |
| **同框关系锚**（Pairing Anchor） | 双人同框时的身份关系描述（高差量化＋服色关系＋气质关系），让观众一眼读出人物关系 |
| **年龄双向锚**（Age Bidirectional Anchor） | 年龄防漂移双保险：女主型防"上浮变熟"配稚气词；丫鬟型防"塌缩变幼"配"及笄/已长开/矮半个头"三件套 |
| **三图试金石**（3-Shot Litmus Test） | 新剧绑定风格包后必先跑的 3 张校准图（主角三视图锚点图/跨时代配角/主场景空镜），全过才准批量 |
| **四道闸门**（4-Gate Pipeline） | 生产流水线四关卡：①试金石定锚→②资产扩展→③样板分镜图/样板段→④全集放行——严禁跳闸批量 |
| **双擎联审**（L1+L2 Dual Gate） | 质量门禁双签字：L1＝Python 机检查语法（禁词/格式），L2＝R7 智检查视听语义——L1 不过强制 0 分 |
| **崩坏编号**（Defect No.01~50） | 黑名单里登记的 50 类 AI 生成翻车类型编号（手部融化/串脸/穿模等），质检与归因按编号对号入座（EVO-01 问题直通） |
| **画风基准传染**（Style Contagion） | 全剧首张人物基准图作为画风标尺，后续资产生图全部垫它作画风参考 |
| **垫图透视排他**（Reference Perspective Exclusion） | 分镜机位与垫图机位冲突时禁止垫图（俯瞰图垫平视镜＝缝合怪），宁盲抽不垫错图 |
| **群组绑定**（Group Binding） | 写多人 NPC 群组（使者/守卫）必须先绑相对距离（"并肩紧凑而立"）再给全局坐标，否则被随机打散 |
| **S·A·B 分级**（Shot Tiering） | 镜头算力分档：S 级奇观核心镜用顶级资源，A 级常规，B 级零视频（静态图＋剪映关键帧） |
| **切出缓冲镜配额**（Cutaway Quota） | 每 2~3 个主镜头配 1 个 1~2 秒插入镜的节奏缓冲定额（≥15%） |
| **状态快照**（State Diff） | 每集结束时的人物/道具/时间/情绪登记表，下集开拍前核对防穿帮 |
| **场景机位库**（Scene Camera Grid） | 一张 3x3（室内可 2x2）宫格图同时产出同一场景多个机位视角（俯瞰/平视/仰拍/纵深等），逐格裁切补高清后作各分镜垫图弹药库，减少垫图透视排他冲突下的盲抽（R9-20261006-6） |
| **头身分区设定板**（Head-Body Split Sheet） | 3+3 六格人物设定板：上排三角度头像满分辨率特写+下排无头人台正侧背服饰——头部细节不因全身等比缩小而丢失；只锁设定禁入参考位（R9-20261006-7） |
| **非人形分区轮转板**（Creature Turnaround Grid） | 3x2 六格非人形设定板：上排头部三视角特写+下排全身三视角+尺寸标注——怪兽/灵宠/机甲/大型道具的形体锁定件，与形态矩阵（状态轴）正交互补（R9-20261006-7） |
| **分镜图总控大师**（Storyboard Master · R10） | 视频生成之前的分镜图生产总关卡角色——对"每个镜头先出什么图、图与图如何保一致"负全责，产出《分镜图生产单》作为 R5 开工令（R9-20261007-14） |
| **分镜图生产单**（Storyboard Production Order） | R10 产出的开工令文档：镜组划分＋组模式（含 A-1/A-2 通道选道理由）＋参考图分配表＋一致性链声明＋分段方案＋视频段分组＋抽卡预算——无此单 R5 不得逐镜生图 |
| **镜组四模式**（4 Group Modes A/B/C/D） | R10 的镜组路由模式：A 分镜序列组（内部双通道 A-1 宫格/A-2 逐镜序列·R9-20261007-16）／B 单帧+尾帧锚（S 级双锚）／C 接力链（超上限长镜）／D 多图参考组（长镜多机位轨迹锚） |
| **一致性链**（Consistency Chain） | 每个镜组的锚点传递路径声明：垫哪些参考图→组内如何同源→跨组复用哪个锚——没有一致性链的生产单=未完成 |
| **按叙事设计、按上限分段**（Design by Story, Split by Limit） | 长视频宪法：镜头时长由叙事决定（10s/20s/30s 自由设计），平台上限只是生产参数——分段公式 ⌈时长÷上限⌉ 自动切接力链，永不迁就上限砍叙事 |
| **多分镜宫格组**（Multi-Shot Grid Group · A-1 通道） | 同场 ≥3 连续镜合成一张宫格（2x2~5x4）一次生成全部分镜图——格间同源互锚，逐格裁切即首帧，抽卡预算约为逐镜独立生产的 1/10~1/3（模型强/宫格实测通过时选道，弱模型改走 A-2·R9-20261007-16） |
| **逐镜序列通道**（Per-Shot Sequence Channel · A-2） | 分镜序列组的双通道之一：每镜独立满分辨率生成分镜图（原首帧），跨镜一致性靠三重序列约束（同源垫图/全序列同画风锁+光位常量/相邻镜渐变声明）保证而非宫格同源——弱模型/宫格两轮废片时默认选道（R9-20261007-16） |
| **序列同源垫图**（Sequence-Consistent Referencing） | A-2 通道三重约束的核心：每镜垫"图1 人物主图@资产+图2 场景机位库对应格"——人物与场景同图生成，占位天然匹配场景，解决弱模型场景不一致与人物占位漂移（IMG-02 4.4） |
| **分镜序列长视频**（Storyboard-Sequence Long Video · 技法⑤） | VID-02 第五技法（R9-20261010-18 曾设默认→2026-10-18 降格**实验路径**＝段级直出·仅用户明示启用·黑名单45 复测②）：段内各镜分镜图（默认 4~6 张）作多图参考+时间轴分段视频提示词，单条 Prompt 直出整段视频（即梦首选/豆包同源备选）——段内必须连续渐变/节拍递进，段边界跳切由分镜图锚定合法；两次用户裁决（2026-10-10 设默认/2026-10-18 降格实验·黑名单 45 复测②），首跑按 KB_14 五节附校准协议留痕 |
| **段级直出**（Segment Direct-Out · 段） | 实验路径⑤的视频生产范式（R9-20261010-18 曾设默认→2026-10-18 降格实验·黑名单45 复测②）：按剧情切段（默认 4~6 镜/段）→ 每镜一张分镜图 → N 图作多图参考+一条时间轴分段视频提示词 → 单条直出整段视频（如 30 秒/6 图）——默认主路径已回滚为"每镜分镜图→单镜 I2V 查表编译" |
| **分镜图**（Storyboard Frame · 原首帧基准图） | 每个镜头一张的画面基准图（R9-20261010-18 由"首帧基准图"更名）：默认单镜 I2V 时即视频第一秒画面；实验路径⑤段级直出制下对应时间轴区间的画面锚——由 IMG-02 按八层语序编译、R5 按《分镜图生产单》生产 |
| **时间轴分段视频提示词**（Timeline-Segmented Video Prompt） | 实验路径⑤段级直出的 Prompt 形态（KB_08 二节实验路径子节 V2 五件套）：开篇风格句＋总起句（"严格按上传的N张分镜参考图顺序推进，共X秒"）＋`[0-5秒] 图N`逐段推进＋整体节奏句＋负面提示词行 |
| **段边界跳切**（Segment-Boundary Cut · 实验路径⑤口径） | 跳切合法位重划（R9-20261010-18 立·2026-10-18 随段级降格仅实验⑤适用）：段与段之间的机位切换由各镜独立分镜图锚定，合法且即剪辑点；段内仍禁跳切与并发多主动作（单镜时空唯一性铁律缩小到段内执法） |
| **视频段分组**（Video-Segment Grouping） | R10 生产单的组成字段（实验路径⑤启用时产出）：把每场分镜切成"一条长视频直出单元"（段号+镜号序列+分镜图清单+组内时长≤平台上限）——技法⑤的输入契约（R9-20261007-16 立） |
| **冗余覆盖制（3机位×3条）**（Coverage Insurance · 2026-10-18 立） | 传统拍摄"每镜每机位拍完整片段供后期失误补救与剪辑"的 AI 化生产制度：S 级=3机位×3条（Master 主镜+2 覆盖机位，条数全留存）/A 级=2机位×2条/B 级=1机位×1条+Cutaway 兜底（KB_14 七节·VIS-01 4.2 冗余档列·成本未经实测首跑留痕）。**消歧铁律：禁用裸"3+3"称呼本制**——"3+3"已固定指人物头身分区设定板（KB_06 母版⑨/KB_07 六节），撞名必混 |
| **Master 主镜**（Master Shot） | 覆盖整场叙事的全景长镜＝整场剪辑保底镜（覆盖镜废片时可整段顶替）——One-Take First 产物转岗（KB_11 七节附/VIS-01 4.6） |
| **覆盖镜**（Coverage Shot） | 主镜之外逐机位补拍的镜（中景/特写/正反打），给后期剪辑自由度与失误补救——R2 场次覆盖调度表登记（KB_11 七节附） |

| **多图参考组**（Multi-Reference Group） | 用机位库子图作多图参考的关键帧轨迹锚——长镜内镜头从机位A视角渐变到机位B视角，用两（三）张机位图锁运动轨迹 |
| **统一资产 DNA**（Unified Asset DNA） | 一致性六法之首：先固化角色/场景参考图资产（主图/三视图/机位库），所有分镜图生产必须挂这些锚——一致性是工作流产物不是模型赠品（KB_14 二节） |

| **声音事件层**（Sound Event Layer · R9-20261025-48） | 把音效链（因果时序）/环境底噪/静默节拍/台词截断当时间轴事件写进生成 Prompt——声音与动作同级的提示词一等维度（KB_08 二节/三节·未经实测推荐槽） |

| **拍点表**（Beat Sheet · 长镜编排 · R9-20261025-48） | 10 秒+ 长镜的作者层编号格式：每拍=时间区间+主线推进一句+层挂事件，overlap 滚动标记合法，主线唯一主动作链不破（KB_08 四节5/VID-02 ④·未经实测推荐槽） |
| **声桥生成位**（J-Cut In-Prompt · R9-20261025-48） | J-Cut/L-Cut 由两镜 Prompt 各写半句直接生成（前镜"开口瞬间切入·词音跨切点延续"，后镜"承接上镜词音落定"），拼接即得免手工剪；生成不达标回落 KB_12 七节剪辑位（KB_08 三节·未经实测推荐槽） |
| **三视图锚点合一参考图**（Turnaround Anchor Sheet · VIS-06 · R9-20261025-49） | 人物基准资产新形态（简称三视图锚点图）——一张图＝左侧头肩正脸特写＋右侧正面/九十度侧面/背面三张等高全身视图（头顶脚底对齐），替代旧"主图+三视图+面部特写"三件（黑名单 48：单张主图主角像路人） |
| **辨识度降序**（Identity-First Describing · VIS-06） | 人物描述顺序铁律——身份锚点（年龄感/性别感/体态+履历气质）最前置→五官→发型→服装→配饰，最高辨识度特征放最前（治"主角像路人"的正手） |
| **性格气质转化**（Personality-to-Look Translation · VIS-06） | 禁性格词直书（"泼辣/沉稳"模型渲染不了）——必须转化为外在可见的年龄感/体态/神情/皮肤状态词，且须有履历出处（词源=圣经小传+世界视觉档案四区） |
